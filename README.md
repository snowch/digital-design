# Digital Design: From Bits to a Working Computer

An interactive, browser-based course that teaches from signals to a working CPU, built on a
reusable interactive learning platform.

**Status: Prompt A, Phase 1.** The inventory of the existing interactive work is written and
awaits the author's review before any code is started. Read it first:

- [`docs/inventory.md`](docs/inventory.md): the corpus as found, its tests run, every interaction
  catalogued against the shared vocabulary (inspect, predict, step, experiment, break, explain,
  drill down, replay), the proposed layering and shared primitives, the reuse decision for each
  tutorial, the toolchain continuity case, and the open questions for Checkpoint 1.

Nothing else exists yet. The companion repository `snowch/learning-platform` holds the proposed
platform contract and will hold the cross-book regression job.
