## switchAfter (shown once the run has ended, 60 to 90 words)

Facts: at the first `tick`, C3 is `81` and C2 holds the address of the gap program's `goto gap`,
the instruction not yet run; the switch stores it at `588`. A switch is 60 instructions: 9 up to
and including the write to the timer, then 51. With a count of 80, each program runs 29
instructions a turn. The run is cut off after 5,000 instructions; the report has ended with record
0, and the gap was shown 65 times.

## c1Task (Markdown, 90 to 130 words)

Facts: the kernel and the two programs as in the figures, the timer at 80. The timer stops the
report before `R11 <= R11 - 1`, at address `210`, and the kernel switches to the gap program. Give
three answers:
1. the word the switch stores in the report's C2 word, as three hexadecimal digits;
2. the address of the word that holds the report's R13, as three hexadecimal digits;
3. the report's C1 word as its two bits, bit 1 then bit 0.
Give the save area's layout: the report's save area starts at `5A0`; R0 to R15 come first, one
word (8 bytes) each, then C1, then C2, then the record.

## c1Hints (five, in order, each 1 to 3 sentences)

1. The concept: an interrupt's return point is the instruction not yet run.
2. A common mistake: counting a register's word from `5A0` in steps of 1 or 4; each word is 8
   bytes.
3. A smaller example, no part of the answer: the gap program's R3 is at `500` plus 3 times 8, `518`.
4. Part of the answer: the C2 word is `210`.
5. The whole answer: `210`; `608` (`5A0` plus 13 times 8, which is 104, `68` in hexadecimal); `10`,
   user mode with interrupts on, as the start wrote it.

## shortExplain (shown after commit, 50 to 80 words)

Facts: the display shows 0: the gap is never shown. The timer counts the kernel's own
instructions. With 40, it reaches 0 inside the kernel, and the interrupt is taken at the edge after
`resume`, before the program runs an instruction. So the kernel switches again at once.

## shortAfter (shown once the run has ended, 50 to 80 words)

Facts: after the gap program's first stretch, neither program runs another instruction. The lanes
show only the handler's. The run is cut off after 5,000 instructions, with 83 timer interrupts.
With this kernel, any count of 51 or less does it. The switch costs instructions, the timer counts
them, and a count must be longer than the switch.
