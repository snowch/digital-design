# Brief 1L: lesson `traps` (Module 12, lesson 1), its labels

Read `00-module.md` (the shared fact sheet) first; it applies here. You may use **trap** and
**handler** everywhere in these labels except the title and the question's heading, which come
before the lesson defines them. No bold in labels.

Keys to write, each a short label (a title or heading is a few words, no full stop; an objective
starts with a verb; a caption is one sentence naming what the figure shows, with a full stop):

- `title`: the lesson's question, as a question: what if the machine went to a program of its own
  instead of halting? (no "trap" or "handler" in it)
- `objectives.1` to `objectives.4`:
  1. say which registers change at the edge where an instruction traps, and what each takes;
  2. read the cause and the return point in a handler;
  3. skip a faulting instruction by adding 4 to C2 before `resume`;
  4. write a handler that treats one cause differently from the others.
- Section headings, `titles.question` to `titles.reflection` (ten): the night program halting (no
  trap or handler words); a program of the machine's own; C2 after the trap; the trap, edge by
  edge; the registers after a trap, worked out; a handler that only resumes; the return point;
  one handler for every cause; skipping refused stores; what the handler must leave alone.
- `challengeTitles.c1`: the registers after a trap. `challengeTitles.c2`: skipping refused stores.
- Captions:
  - `captions.halts`: the night program with no handler, in the debugger.
  - `captions.predict`: the night program with a handler, listed, with a question about C2.
  - `captions.timeline`: the night program's run with its handler, edge by edge.
  - `captions.quizListing`: a program whose word load faults, which the lesson does not run.
  - `captions.answers`: four questions about the registers after that trap.
  - `captions.noSkip`: the night program with a handler that only resumes, in the debugger.
  - `captions.debugger`: the night program with its handler, in the debugger, with the control
    registers.
  - `captions.skip34`: a handler that skips refused stores, and its tests.
- `fields.c2`: C2 after the trap. `fields.c3`: C3 after the trap. `fields.c1`: C1 after the trap.
  `fields.pc`: the PC after the trap.
- `skip34Labels.1` to `skip34Labels.4`, the four tests, each a short phrase: two refused stores;
  a store to the ROM; a word that is not an instruction; a word load not at a multiple of 8.
