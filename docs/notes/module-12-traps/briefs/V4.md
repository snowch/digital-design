# Brief V4: Module 12's shared strings, after the second reading

Read `00-module.md` first, including both "Decisions" sections. These strings appear on several
Module 12 pages, from lesson 1 to lesson 8, so use no term a lesson introduces except **trap** and
**handler**. Write each from its facts alone. Keep every `{placeholder}` exactly as given. No
backticks: these strings are shown as plain text.

Keys: `nameShared`, `atTrap`, `ownFault`, `dataAdded`, `assembled`, `listingCaption`, `stateNow`,
`storedTitle`, `skip34Labels.4`.

## nameShared (one or two sentences; a failed test's message)

`{name}` is a line name; `{test}` is a test's name, such as "two refused stores".

1. Your text names a line `{name}`.
2. The lines the test {test} adds after your text use the same name, so the assembler cannot tell
   the two apart, and the test does not run.
3. Give your line another name.

## atTrap (a short phrase, no full stop)

Used inside a list such as "The run left R5 at the last trap: 7 (007 ...)". `{name}` is a register,
such as R5. Say: that register as the program left it at its last trap.

## ownFault (one sentence; a failed test's message)

`{address}` is three hexadecimal digits; `{cause}` two. Facts: an instruction of the learner's own,
in the start or the handler, at that address, faulted with that cause. (Not one of the tests'
lines.)

## dataAdded (a heading over code, ending with a colon)

The tests add these lines after your start and handler. (Module 11 says "after your program";
Module 12's learner writes a start and a handler, and the tests add the program.)

## assembled (one sentence)

`{n}` is a number of instructions; `{bytes}` a number of bytes. The assembler made {n}
instructions; everything in the listing, instructions and words of data together, takes {bytes}
bytes of ROM. (Module 11 says "the program and its data"; here the listing holds a start, a handler
and a program.)

## listingCaption (a caption, no full stop)

The listing as the assembler made it: the start, the handler and the program together.

## stateNow (one short sentence)

`{state}` is the controller's state, such as READ. The controller is in that state now.

## storedTitle (a memory panel's title over one word, no full stop)

The word at 500, where the tests' program stores R1 after its count: R1 as the interrupts left it.

## skip34Labels.4 (a test's name, lower case like "a word that is not an instruction")

A load from an address where there is no memory.
