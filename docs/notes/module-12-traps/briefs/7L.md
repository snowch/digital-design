# Brief 7L: lesson `trap-hardware` (Module 12, lesson 7), its labels

Read `00-module.md` (the shared fact sheet) first; it applies here. No bold in labels. Headings and
labels start with a capital letter.

Keys to write, each a short label (a title or heading is a few words, no full stop; an objective
starts with a verb and ends with a full stop; a caption is one sentence naming what the figure
shows, with a full stop):

- `title`: the lesson's question: where in the machine does a trap happen?
- `objectives.1` to `objectives.4`:
  1. name the parts that make a trap's edge, and what each does;
  2. count the edges a trap, a `call system`, a `resume` and an interrupt take;
  3. say which cause the trap logic chooses when there are several;
  4. write the trap logic.
- Section headings (keys `question`, `motivation`, `prediction`, `investigation`, `construction`,
  `failureExperiment`, `explanation`, `generalisation`, `challenge`, `reflection`, under
  `titles.`): a trap, edge by edge; four parts and a rule; the PC after the trapping edge; the
  night program on this machine; counting edges, worked out; a broken trap; which cause wins;
  a trap costs no state; the trap logic; a handler for the shop.
- `challengeTitles.c1`: counting edges. `challengeTitles.c2`: the trap logic.
- Captions:
  - `captions.edges`: a timing diagram of a program that traps within 12 edges.
  - `captions.predict`: the machine's drawing, stopped before the store's last edge, with a
    question about the PC.
  - `captions.night`: the night program on the machine of several edges, with its control
    registers.
  - `captions.answers`: four questions about the edges a trap takes.
  - `captions.faults`: the night program with a fault you choose.
  - `captions.traplogic`: the trap logic to write, and its tests.
- `faults.trapLow`: TRAP stuck at 0. `faults.cwenLow`: the control registers' write enable stuck
  at 0.
- `fields.call`: edges of a call system. `fields.resume`: edges of a resume. `fields.interrupt`:
  edges of an interrupt. `fields.store`: edges of a refused store. (Plain text: no backticks.)
