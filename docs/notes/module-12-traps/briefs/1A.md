## motivation (about 170 words; a short list allowed)

1. Instead of halting, the machine can go to a program of its own. That program is a
   **handler**: a program the machine runs when an instruction faults.
2. Going to the handler in place of halting is a **trap**. The store traps instead of halting the
   machine.
3. Control register C4 holds the handler's address. A program sets it first, with `C4 <= R1`.
4. At the edge that ends the instruction that faults, five registers take new words, and nothing
   else changes (list them):
   - C2 takes the return point: where to go back to;
   - C1 takes C0, the status, as it was;
   - C0 takes `01`;
   - C3 takes the cause;
   - the PC takes C4, so the next instruction is the handler's first.
5. The instruction that faulted changes nothing else: no register, no memory, no device.
6. The handler reads the cause with `R5 <= C3`. It goes back with `resume`, which sets the PC to
   C2.
7. C0 and C1 say more in lesson 3. In this lesson C0 is `01` throughout.

## p1Question (one sentence)

Just after the store to room B's sensor traps, what does C2 hold?

## p1Explain (about 70 words)

1. C2 holds `014`: the address of the store that faulted, not the next instruction.
2. After a fault, the return point is the instruction that faulted, so a handler can mend what
   went wrong and run it again.
3. `018` is the instruction after it. `024` is the handler's address, which the PC takes.
4. The next figure runs the program edge by edge.
