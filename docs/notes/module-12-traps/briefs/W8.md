# Brief W8: lesson `system-call-mechanism` (lesson 8), after the second reading

Read `00-module.md` first, including both "Decisions" sections. You may use **trap**, **handler**,
**user mode**, **system mode**, **system call** and **interrupt**, not bold. Each key replaces the
page's text. Write each from its facts alone.

Keys: `motivation` (its first paragraph and the list only; the three paragraphs after the list
stay as they are), `c1Task`, `c1Hints.2`.

## motivation: first paragraph and list (about 170 words)

1. The text you write has five parts: the start, which runs from reset, and four parts of the
   handler, the lines at the address C4 holds. (A list of five follows.)
2. The start sets C4 to the handler's address, then runs the program whose number the word at
   `480` holds, counting from 0. It finds the program's address in the table `programs`, which
   the tests add after your text: its first word is how many programs, then each program's
   address. It runs the program in user mode with interrupts off, by writing C1 and C2, then
   running `resume`.
3. The choice, the handler's first part, reads C3 to tell a system call from a fault, and R1 to
   find the job.
4. The jobs: job 1 shows R2; job 2 puts a room's reading in R1; job 3 sets the lamps from R2's
   bits 2 to 0; job 4 ends the program.
5. The end of a program stores its record, at `400` plus 8 times its number. Then it moves to the
   next number and goes back to the start.
6. The stop comes after the last program, and it stops the machine.

## c1Task (a numbered list)

1. Write a handler that runs each program the table `programs` names, in order, in user mode with
   interrupts off. The tests add the table and the programs after it.
2. Offer jobs 1 to 4 by `call system`. Job 1 shows R2. Job 2 puts a room's reading in R1: R2 is 0
   for room A and 1 for room B, and any other R2 puts 0 in R1. Job 3 sets the lamps from R2's bits
   2 to 0. Job 4 ends the program.
3. A program that faults ends there. For program k, counting from 0, store its record in the word
   at `400` plus 8 times k. Write it as `word[R1 + 0x400]`, with 8 × k in R1: 0 if it ended with
   job 4, or its cause itself if it faulted.
4. A job may change R1 and R2 only. After the last program, the handler runs `stop`.
5. There are 7 tests. Room A reads -184 and room B -250. Each checks the words shown, the lamps,
   each program's record, C1 at the end (the last program's status at its last trap, `00`: user
   mode, interrupts off), and that the run ends at the handler's `stop`.
6. Run 6's second program puts a word of its own in R0 and in each of R3 to R15. Its test also
   checks those registers as the program left them at its last trap, the call for job 4.
