## motivation (about 180 words; a short list and a short table allowed)

1. The program asks the handler, which runs in system mode, to do the job for it, with the line
   `call system`.
2. `call system` traps on purpose, with cause `41`. User mode allows it.
3. A trap a program makes to ask the handler for a job is a **system call**.
4. The program says which job in R1, and gives the job's words in R2 to R4. The handler leaves the
   result in R1. These are the calling convention's registers, as for a function whose first
   argument names the job.
5. The jobs are numbered (give this as a table, two columns, R1 and what the handler does):
   1 shows R2 on the display; 2 reads a room's sensor: R2 is 0 for room A, 1 for room B, and the
   reading comes back in R1; 3 sets the lamps from R2's bits 2 to 0; 4 ends the program.
6. The handler reads C3 to tell a system call from a fault, then R1 to choose the job. It runs the
   job, then `resume`.
7. This lesson's handler offers jobs 1 and 4.

## p1Question (one sentence)

Just after the `call system` at `064` traps, what does C2 hold?

## p1Explain (about 70 words)

1. C2 holds `068`, the instruction after the call.
2. A system call's return point is the next instruction, not the call: the job is done, and the
   program goes on from the next line.
3. After a fault, the return point is the instruction that faulted, `064` here.
4. `01C` is the handler's address, which the PC takes.
