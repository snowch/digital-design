# Brief 3L: lesson `user-mode` (Module 12, lesson 3), its labels

Read `00-module.md` (the shared fact sheet) first; it applies here. You may use **trap**,
**handler**, **user mode** and **system mode**, except in the title and the question's heading,
which come before the lesson defines the two modes. No bold in labels.

Keys to write, each a short label (a title or heading is a few words, no full stop; an objective
starts with a verb; a caption is one sentence naming what the figure shows, with a full stop):

- `title`: the lesson's question: how can the machine keep a program away from the shop's devices?
- `objectives.1` to `objectives.4`:
  1. say what user mode refuses, and the cause of each refusal;
  2. start a program in user mode with `resume`;
  3. say what the machine protects and what it does not;
  4. tell from C1 which mode a program was in when it trapped.
- Section headings, `titles.question` to `titles.reflection` (keys `question`, `motivation`,
  `prediction`, `investigation`, `construction`, `failureExperiment`, `explanation`,
  `generalisation`, `challenge`, `reflection`): ALARM switched off; two modes; C1 after the trap;
  a program in user mode; what user mode refuses, worked out; the RAM is not protected; the memory
  map in user mode; what the machine protects; starting a program in user mode; showing a reading.
- `challengeTitles.c1`: what user mode refuses. `challengeTitles.c2`: starting a program in user
  mode.
- Captions:
  - `captions.system`: a program that clears the lamps by mistake, in the debugger.
  - `captions.predict`: the same program started in user mode, listed, with a question about C1.
  - `captions.timeline`: the program started in user mode, edge by edge, with the mode after each.
  - `captions.answers`: four lines, each to be judged in user mode.
  - `captions.ram`: a user program that writes the handler's count, in the debugger.
  - `captions.map`: the memory map, each part with what user mode does with each access.
  - `captions.user`: a handler that starts a program in user mode, and its tests.
- `fields.load`: `R2 <= word[sensorA]`. `fields.ram`: `word[0x400] <= R2`. `fields.stop`: `stop`.
  `fields.timer`: `R3 <= word[timer]`. (These are labels: give them as written, with the backticks.)
- `ramTitle`: the handler's count at 410.
- `userLabels.1` to `userLabels.4`: a store to the lamps; stop; a load from a sensor; a control
  register read.
