# Brief 8L: lesson `system-call-mechanism` (Module 12, lesson 8), its labels

Read `00-module.md` (the shared fact sheet) first; it applies here. No bold in labels. Headings and
labels start with a capital letter.

Keys to write, each a short label (a title or heading is a few words, no full stop; an objective
starts with a verb and ends with a full stop; a caption is one sentence naming what the figure
shows, with a full stop):

- `title`: the lesson's question: can you write the handler that runs the shop's programs?
- `objectives.1` to `objectives.4`:
  1. run a table of programs one after another, each in user mode;
  2. offer jobs 1 to 4 by `call system`;
  3. end a program that faults, and record why;
  4. keep the handler's own state where no program can change it by accident.
- Section headings (keys `question`, `motivation`, `prediction`, `investigation`, `construction`,
  `failureExperiment`, `explanation`, `generalisation`, `challenge`, `reflection`, under
  `titles.`): a handler for the shop; the handler's parts; a program's record; the whole handler
  at work; building it in steps; a handler that skips; two ways to end; the program that runs the
  others; the shop's handler; one machine, top to bottom.
- `challengeTitles.c1`: the shop's handler.
- Captions:
  - `captions.asks`: the six runs the tests use, with what a guided start leaves.
  - `captions.predict`: the whole handler and two programs, listed, with a question about a
    record.
  - `captions.walk`: the whole handler running two programs, in the debugger.
  - `captions.skipping`: the six runs, with a handler that skips faulting instructions.
  - `captions.run`: the shop's handler to write, and its tests.
- `checks.shown`: words shown. `checks.lamps`: lamps. `checks.first`: first program's record.
  `checks.second`: second program's record. `checks.end`: how the run ends.
- `runLabels.1` to `runLabels.6`: two programs that end with job 4; a program that stores to the
  display itself; the lamps, then a program that runs stop; a word kept in R10 across a job;
  room 5, and a program that is not instructions; no programs.
- `runNotes.1` to `runNotes.6`, one sentence each, what the run's programs do: one shows 25, one
  shows room B's reading; one stores 7 to the display, one shows 8; one lights NIGHT, one runs
  stop; one keeps 77 in R10 and shows 5, then 77; one asks job 2 for room 5 and shows R1, then the
  table names a word that is not an instruction; the table names no program.
- `recordsTitle`: the records at 400 and 408. `numberTitle`: the program's number at 480.
