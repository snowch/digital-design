# Brief 2L: lesson `saving-state` (Module 12, lesson 2), its labels

Read `00-module.md` (the shared fact sheet) first; it applies here. You may use **trap** and
**handler**. No bold in labels.

Keys to write, each a short label (a title or heading is a few words, no full stop; an objective
starts with a verb; a caption is one sentence naming what the figure shows, with a full stop):

- `title`: the lesson's question: what must a handler leave as it found it?
- `objectives.1` to `objectives.4`:
  1. say why a handler must leave every register as it found it;
  2. save a register with an absolute store and put it back before `resume`;
  3. say why a handler does not save on the program's stack;
  4. judge whether a handler leaves a program's registers alone.
- Section headings, `titles.question` to `titles.reflection` (ten; keys `question`, `motivation`,
  `prediction`, `investigation`, `construction`, `failureExperiment`, `explanation`,
  `generalisation`, `challenge`, `reflection`): a reading spoiled; save, then put back; the word at
  408; a handler that saves R5; four handlers judged; a stack in the ROM; where a handler keeps
  its words; every register kept; a handler that keeps every register; keeping a program away from
  the devices.
- `challengeTitles.c1`: four handlers. `challengeTitles.c2`: a handler that keeps every register.
- Captions:
  - `captions.spoiled`: a program that keeps room A's reading in R5, with lesson 1's handler, in
    the debugger.
  - `captions.predict`: the same program with a handler that saves R5, listed, with a question
    about the word at 408.
  - `captions.saved`: the same program with a handler that saves R5, in the debugger.
  - `captions.choices`: four handlers, each to be judged.
  - `captions.stack`: a handler that saves R5 below a stack in the ROM, in the debugger.
  - `captions.timeline`: the run with the saving handler, edge by edge.
  - `captions.save`: a handler that keeps every register, and its tests.
- `choiceFields.a` to `choiceFields.d`: "Handler A" to "Handler D".
- `choiceOptions.leaves`: leaves every register as it was. `choiceOptions.changes`: changes a
  register.
- `saveLabels.1` to `saveLabels.3`: one refused store; two refused stores; a stack at the ROM.
