# Brief V2: Module 12's grader words (what a failed test says)

Read `00-module.md` (the shared fact sheet) first; it applies here, with one change: you may use
**trap**, **handler**, **user mode**, **system mode**, **system call** and **interrupt** in these
words, never bold. Placeholders in braces stay exactly as given.

## Answer details: one sentence each, shown when an answer is wrong

Module 11's form, which these follow: "{actual} is not the address. Each instruction takes 4 bytes
from 000; a word starts at a multiple of 8." The sentence says what is wrong and the fact that
leads to the right answer, never the answer itself.

- `trapC2`: `{actual}` is not C2 after the trap. Fact: after a fault, C2 holds the address of the
  instruction that faulted.
- `trapC3`: not C3. Fact: C3 takes the fault's cause, two hexadecimal digits; the first digit
  says which step failed.
- `trapC1`: not C1. Fact: C1 takes C0 as it was; in lesson 1, C0 is `01` throughout.
- `trapPc`: not the PC. Fact: the PC takes C4, the handler's address, as three hexadecimal digits.
- `saveChoice`: `{actual}` is not it for this handler. Fact: check every register the handler
  writes: is it saved before it is written, and put back from the same word before `resume`?
- `userRefusal`: `{actual}` is not the cause for this line. Fact: user mode refuses a load or store
  at a device's address (from `7C0`) with `32`, and `resume`, the control-register jobs and `stop`
  with `22`; give 0 if user mode runs the line.
- `callRegister`: `{actual}` is not it. Fact: read it from the table of jobs: R1 names the job, R2
  gives its word, and the result comes back in R1.
- `nextEdge`: `{actual}` is not what the next edge does. Fact: it traps only when C0's bit 1 is 1
  and a bit of "waiting" is set; the timer's `81` goes before the door's `82`; give 0 if the
  instruction runs.
- `nestC1`: not C1 after the door's interrupt. Fact: C1 takes C0 as it is when the interrupt comes,
  and job 5 wrote C0 for its loop.
- `nestC3`: not C3. Fact: C3 takes the event's cause.
- `nestSaved`: not the word at `418`. Fact: job 5 saved C2 there when it began, the return point
  of the program's `call system`.
- `nestC0`: not C0 after the door part's `resume`. Fact: `resume` copies C1 into C0.
- `edgesCall`, `edgesResume`, `edgesInterrupt`, `edgesStore`: `{actual}` is not the number of
  edges. Facts, one per key: `call system`'s cause comes in READ, and that edge ends it; `resume`
  goes READ to WRITE, as a control-register job does; an interrupt is taken at the edge that would
  fetch, and that edge is all it takes; a store traps at its MEMORY edge, its last.

## A program's task, in one sentence each: shown when a program's test fails

Module 11's form: "The display must show how many readings are warmer than the limit, ALARM must
be on when that is not 0, and the words at 400 and 408 must hold the lowest and highest readings."

- `skip34`: the handler must count each refused store (cause `34`) in the word at `400` and skip
  it, and run `stop` on any other cause.
- `saveRegisters`: the handler must count and skip each refused store, and leave every register
  the program used as it was before the trap.
- `startUser`: the handler start must run `program` in user mode; the handler must keep the cause
  in the word at `400` and stop.
- `sensorService`: job 2 must put room R2's reading in R1, room A for 0 and room B for 1, and the
  handler must put R8 and R9 back before `resume`.
- `doorTimer`: the timer's part must clear the timer's bit and light ALARM only if the door is
  still open; the program must still show 30 and end.
- `waitDoor`: job 5 must let the door and the timer in while it waits, and the program must go on
  after the wait as before.
- `shopHandler`: the handler must run each program in the table in user mode, offer jobs 1 to 4,
  leave each program's record (0 for job 4, else its cause) at `400` plus 8 times its number, and
  stop after the last.

## The grader's names for what a run left (lower case, they follow "Your program left")

Module 11's: "the display", "what the display showed, in order", "how the run ended".

- `checks.mode`: the mode at the end. `checks.traps`: how many traps went to the handler.
  `checks.causes`: the causes, in order. `checks.waiting`: the waiting events.
  `checks.timer`: the timer's count.

## The assembler's refusal

- `controlRegister`: the assembler refuses a control register outside C0 to C4. `{name}` is what
  the line wrote (such as C7). Module 11's form: "{name} is a word the language uses, so it cannot
  name a line." Fact: the machine has five control registers, C0 to C4.
