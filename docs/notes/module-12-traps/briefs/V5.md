# Brief V5: the button under a box of rows (B12)

Read `docs/style.md`. These two strings are a button's words, on Module 11's and Module 12's pages.
Use no term a lesson introduces. No full stop. Plain text, no backticks.

Keys: `rowsAll`, `rowsFewer`.

The debugger's listing of a program, a region of memory, the stack's frames and a timeline's edges
each sit in a short box that scrolls, and keeps the line about to run (or the current row) in
view.

- `rowsAll`: the button under such a box, before it is pressed. Pressing it makes the box show
  every row at once, with no scrolling inside the box. A few words, an instruction, such as a
  verb and what it shows.
- `rowsFewer`: the same button once the box is open. Pressing it brings back the short box. A few
  words, the counterpart of `rowsAll`, built the same way.
