# Brief 5L: lesson `interrupts` (Module 12, lesson 5), its labels

Read `00-module.md` (the shared fact sheet) first; it applies here. You may use **trap**,
**handler**, **user mode**, **system mode**, **system call** and **interrupt**, except
**interrupt** in the title and the question's heading, which come before the lesson defines it.
No bold in labels.

Keys to write, each a short label (a title or heading is a few words, no full stop; an objective
starts with a verb and ends with a full stop; a caption is one sentence naming what the figure
shows, with a full stop):

- `title`: the lesson's question: how can the machine answer the door while a program runs?
- `objectives.1` to `objectives.4`:
  1. say when the machine takes an interrupt, and with which cause;
  2. give an interrupt's return point;
  3. clear an event's bit in a handler;
  4. write a handler's part that answers the timer.
- Section headings (keys `question`, `motivation`, `prediction`, `investigation`, `construction`,
  `failureExperiment`, `explanation`, `generalisation`, `challenge`, `reflection`, under
  `titles.`): a door nobody watches; an event between two instructions; C2 after the door's
  interrupt; the door and the timer, edge by edge; the next edge, worked out; an event never
  cleared; three ways into the handler; answering without asking; the door left open; a trap
  inside the handler.
- `challengeTitles.c1`: the next edge. `challengeTitles.c2`: the door left open.
- Captions:
  - `captions.unseen`: lesson 4's handler and a counting program while the door opens, in the
    debugger.
  - `captions.predict`: the handler for the door and the timer, with the counting program, listed,
    with a question about C2.
  - `captions.timeline`: the run with the door opening, edge by edge, with the mode and interrupts
    after each.
  - `captions.answers`: four cases of C0 and "waiting".
  - `captions.noClear`: a handler that does not clear the door's bit, in the debugger.
  - `captions.debugger`: the handler and the counting program in the debugger, with the door's
    time to choose.
  - `captions.timer`: a handler whose timer part you write, and its tests.
- `fields.door`: C0 10, waiting 10. `fields.off`: C0 00, waiting 10. `fields.both`: C0 10,
  waiting 11. `fields.handler`: C0 01, waiting 01. (Labels render as plain text: no backticks.)
- `timerLabels.1` to `timerLabels.4`: the door left open; the door closed in time; the door shut
  all night; the door opened late and left open.
