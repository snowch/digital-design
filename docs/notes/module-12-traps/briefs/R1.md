## motivation (about 170 words; the list stays a list)

1. The machine refuses some instructions, such as the store to room B's sensor. Say that such an
   instruction **faults**: say the instruction first and the word second, so the sentence reads
   right the first time.
2. Instead of halting, the machine can go to a program of its own. A program the machine goes to
   when an instruction faults is a **handler** (bold, introduced here).
3. Going to the handler in place of halting is a **trap** (bold, introduced here). The store
   traps instead of halting the machine.
4. Control register C4 holds the handler's address. A program sets it first, with `C4 <= R1`.
5. At the edge that ends the instruction that faults, five registers take new words (a list):
   - C2 takes the return point, where to go back to;
   - C1 takes C0, the status, as it was;
   - C0 takes `01`;
   - C3 takes the cause;
   - the PC takes C4, so the next instruction is the handler's first.
6. The instruction that faulted changes nothing else: no register, no memory, no device.
7. The handler reads the cause with `R5 <= C3`. It goes back with `resume`, which sets the PC to
   C2.
8. C0 and C1 say more in lesson 3. In this lesson C0 is `01` throughout.

## investigation (about 70 words)

1. The figure is a timeline of the night program and its handler.
2. It lists the run's edges one at a time. On this machine each edge is one instruction run, or

3. Each edge says what ran, or that it trapped, and lists the transfers it makes, each with the

## explanation (about 170 words; a short list allowed)

1. The return point is the address C2 holds, and `resume` goes there. After a fault, the return
   point is the instruction that faulted.
2. The handler then has two choices (a list of two):
   - mend what went wrong and run the instruction again, with C2 as it is;
   - skip the instruction, by adding 4 to C2 before `resume`.
3. The night program's store cannot be mended: room B's sensor is read only, so the store would
   fault every time it ran. Its handler skips it, with `R5 <= C2`, `R5 <= R5 + 4` and
   `C2 <= R5`.
4. A control register is only copied to or from an R register: `R5 <= C2` copies C2 into R5, and
   `C2 <= R5` copies R5 into C2. So the handler adds 4 in R5, between the two copies. The same
   two lines copy C0, C1, C3 and C4.
5. The assembler refuses a control register anywhere else, such as in `R5 <= C2 + 4`, a load or a
   store, and says why.
6. With C4 at 0, as at reset, there is no handler: an instruction that faults halts the machine
   with its cause, as in Modules 8 to 11. Every program in those modules ran with C4 at 0.
7. An instruction that faults at the address C4 holds also halts the machine instead of going to
   the handler. Otherwise a handler that faults on its own first line would go back to that line
   for ever.

## c2Task (a numbered list)

1. Write a handler that skips every store the machine refuses, cause `34`, and counts them in the
   word at `400`, which you write `word[0x400]`.
2. On any other cause, the handler runs `stop`, so the run stops there.
3. The starting text sets C4, sets the count to 0 and goes to `program`. Its handler only resumes.
4. There are 4 tests. Each adds its own program after yours, named `program`, and runs the whole

5. Each test checks the count, the display, how many traps went to the handler, the causes in
   order, and where the run stops: at the program's `end`, or at the handler's `stop` after any
   other cause. Where the program carries on after a refused store, the test also checks that C2
   holds the address of the line after the store, which the program names `after`.

## modelVsReality (about 80 words)

1. Real machines go to a handler as this one does: a register for the return point, one for the
   cause, and the handler's address.
2. Many keep a table of handler addresses in memory, one for each cause.
3. This machine takes one edge for a trap, as it does for each instruction.
4. A real machine takes several clock edges for most instructions, and more for a trap. Module 9's
   machine of several edges does the same; lesson 7 counts a trap's edges there.
