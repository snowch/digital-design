# Brief W4: lesson `system-calls` (lesson 4), after the second reading

Read `00-module.md` first, including both "Decisions" sections. You may use **trap**, **handler**,
**user mode**, **system mode** and **system call**, not bold. Each key replaces the page's text.
Write each from its facts alone.

Keys: `answersLead`, `c1Task`, `c1Hints.3`, `c2Task`.

## answersLead (one or two sentences, about 40 words)

The construction's three answers each come from a different place:

1. the word for job 3, from the table of jobs in the motivation;
2. what the display shows, from the table of jobs and the program in the task;
3. what C2 holds, from the return point the prediction asked about.

Then run the tests.

## c1Task (a numbered list)

1. Give, as decimal numbers:
   - what R2 holds for job 3 to light NIGHT and CLASH together, and no other lamp;
   - what the display shows when the program below has run, with room A reading -184 and room B
     -250.
2. Give, as three hexadecimal digits: what C2 holds just after a `call system` at `0A0` traps.
3. The program uses only jobs 1 and 2. This handler changes only R1 and R2 for a job, so the word
   the program puts in R5 is still there after its second call.
4. There are 3 tests, one for each answer. The program follows.

## c1Hints.3 ("Part of the answer:", two short sentences)

1. The program's first job 2 reads room B; the reading comes back in R1, and the program copies it
   to R5.
2. Its second job 2 reads room A into R1.

## c2Task (a numbered list)

1. The starting text's handler offers two jobs: job 1 shows R2, and job 4 ends the program. Add
   job 2, which reads a room's sensor. The room is in R2: 0 for room A, 1 for room B. The reading
   comes back in R1.
2. A system call may change only R1 and R2. The handler must put R8 and R9 back before `resume`,
   and leave every other register as it was.
3. There are 3 tests. Each adds a program after yours, named `program`. Each program first puts
   a word of its own in R0 and in each of R3 to R15, a different set in each test. It reads rooms
   with job 2 and shows words with job 1, then ends with job 4. Room A reads -184 and room B -250.
4. Test 2 copies room B's reading into R5, and test 3 copies room A's into R6; each test expects
   that word there.
5. Each test checks the words the display showed, in order; R0 and R3 to R15 as the program left
   them at its last trap, the call for job 4; the causes in order, every one `41`; and that the
   run ends at the handler's `stop` for job 4.
