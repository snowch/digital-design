motivation: C0's bit 0 sets the mode. When it is 1, the machine runs every instruction, as every program so far has run. That is **system mode**.

When bit 0 is 0, the machine refuses some instructions. That is **user mode**. In user mode, these instructions fault with the cause shown:

- `resume`, the two control-register jobs, and `stop`: cause `22`;
- every load or store at a device's address, `7C0` and up: cause `32`.

Every other instruction runs as before, in the ROM and the RAM.

A trap's edge sets C0 to `01`, so the handler always runs in system mode. C1 keeps the mode the program was in.

The handler starts a program in user mode with lesson 1's `resume`. It writes 0 to C1 and the program's address to C2, the return point, then runs `resume`. C0 takes C1, and the PC takes C2.

A user program cannot change C0 back: the line that would do it, `C0 <= R1`, is refused.
