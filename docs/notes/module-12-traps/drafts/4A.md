A trap that a program makes on purpose to ask the handler for a job is a **system call**.

The program says which job it wants in R1, and gives the job's words in R2 to R4. The handler leaves the result in R1. These are the calling convention's registers, as for a function whose first argument names the job.

A system call's return point is the next instruction, not the call: the job is done, and the program goes on from the next line.
