motivation: A handler runs in the middle of another program. That program did not call it and cannot tell it ran.

So the handler must leave every register as it found it. It saves each register it writes, and puts each one back before `resume`.

An absolute store needs no register to hold its address. So the handler can make it before it has changed any register.

The handler keeps its saved words in RAM, at addresses it chooses. Here it uses `400` for the cause and `408` for R5.
