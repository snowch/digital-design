motivation: Bit 0 of C0 sets the mode.

When bit 0 is 1, the machine refuses only what Module 8's machine refused. That is **system mode**. Every program so far ran in it.

When bit 0 is 0, the machine refuses more. That is **user mode**. In user mode these instructions fault, with these causes:

- every line that reads or writes a control register, `resume`, and `stop`: cause `22`;
- every load or store at a device's address, `7C0` to `7F7`: cause `32`.

Every other instruction runs as before. That includes its accesses to the ROM and the RAM.

A trap's edge sets C0 to `01`, so the handler always runs in system mode. C1 takes C0 at that edge, so C1 holds the mode the program was in.
