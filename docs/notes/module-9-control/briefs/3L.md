# Brief 3L: lesson `several-edges` (Module 9, lesson 3), the labels

Read `00-module.md` (the shared fact sheet) first; it applies here, except that a label is short
and need not be a sentence. "control unit", "illegal instruction" and "instruction register" are
allowed.

Keys to write, each one line. Objectives and captions end with a full stop; headings do not.
Headings start with a capital letter and are short labels, 2 to 6 words, never the descriptions
below. Never use "your".

- `title`: a question a learner would ask, ending in "?", at most 9 words: how one instruction
  can use one memory twice.
- `objectives.1` to `objectives.4`, each starting with a verb, at most 12 words: predict how
  many edges a load takes; trace an instruction's edges through the controller's states; write
  the memory's address and the instruction register; write the controller's next-state logic.
- Ten headings, `titles.question` to `titles.reflection` in the order question, motivation,
  prediction, investigation, construction, failureExperiment, explanation, generalisation,
  challenge, reflection. They hold: one memory, one address; several edges an instruction; a
  load's edges; which room is colder, edge by edge; one port for two jobs; a stuck address and a
  lost row; the controller's states; each kind's edges; the next state written as text; held
  words and the next question.
- `challengeTitles.c1`: the memory's address and the instruction register, in the style "Memory
  checks, written". `challengeTitles.c2`: the controller's next state, same style.
- `captions.predictLoadEdges`: predict the load's edges, then check.
  `captions.colderEdges`: run the program edge by edge.
  `captions.writeFetchport`: write the address and the register and run the tests.
  `captions.edgeFaults`: choose a fault and run the margin.
  `captions.controller`: set the decoder's signals and clock the controller.
  `captions.kindEdges`: each kind's states, read off the controller.
  `captions.writeStates`: complete the next-state logic and run the tests.
- `options.p1One`: 1 edge, as in Module 8. `options.p1Three`: 3 edges. `options.p1Five`: 5
  edges. Each at most 6 words.
- `faults.fetchingHigh`: "FETCHING stuck at 1". `faults.memoryRowLow`: "Row 4 stuck at 0".
  Return them as given.
