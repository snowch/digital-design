# Brief 5L: lesson `new-instruction` (Module 9, lesson 5), the labels

Read `00-module.md` (the shared fact sheet) first; it applies here, except that a label is short
and need not be a sentence. Every Module 9 term is allowed.

Keys to write, each one line. Objectives and captions end with a full stop; headings do not.
Headings start with a capital letter and are short labels, 2 to 6 words, never the descriptions
below. Never use "your".

- `title`: a question a learner would ask, ending in "?", at most 9 words: what it takes to add
  an instruction to the machine.
- `objectives.1` to `objectives.4`, each starting with a verb, at most 12 words: predict how many
  edges the new instruction takes; follow a call through a register edge by edge; add kind 9 to
  the decoder's text; run the whole machine with the new instruction.
- Ten headings, `titles.question` to `titles.reflection` in the order question, motivation,
  prediction, investigation, construction, failureExperiment, explanation, generalisation,
  challenge, reflection. They hold: one new instruction; a call through a register; the new
  instruction's edges; choosing a room at run time; a new column in the decoder; two ORs made
  ANDs; the call and the jump together; what a new instruction needs; the whole machine written
  as text; two machines, one list of instructions.
- `challengeTitles.c1`: the decoder with kind 9, in the style "Memory checks, written".
  `challengeTitles.c2`: the whole machine with kind 9, same style.
- `captions.callAndJump`: the decoder's columns for a call and a jump.
  `captions.predictCallEdges`: predict the new instruction's edges, then check.
  `captions.choose`: run the program that chooses a room.
  `captions.writeDecoder`: add kind 9 and run the tests.
  `captions.callFaults`: choose a fault and run the program.
  `captions.newColumn`: the new column beside the call's and the jump's.
  `captions.newEdges`: the edges of a call, a jump and the new instruction.
  `captions.writeMachine`: change the machine's text and run it.
- `options.p1Three`: 3 edges, as a call. `options.p1Four`: 4 edges, with an ALU edge.
  `options.p1Five`: 5 edges, as a load. Each at most 7 words.
- `faults.callAnd`: "orCall made an AND". `faults.jumpAnd`: "orJump made an AND". Return them as
  given.
