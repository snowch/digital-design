# Brief 2L: lesson `illegal-instructions` (Module 9, lesson 2), the labels

Read `00-module.md` (the shared fact sheet) first; it applies here, except that a label is short
and need not be a sentence. "control unit" and "illegal instruction" are allowed.

Keys to write, each one line. Objectives and captions end with a full stop; headings do not.
Headings start with a capital letter and are short labels, 2 to 6 words, never the descriptions
below. Never use "your".

- `title`: a question a learner would ask, ending in "?", at most 9 words: what the machine does
  with a word that is no instruction.
- `objectives.1` to `objectives.4`, each starting with a verb, at most 12 words: name the three
  reasons a word is illegal; predict the cause the decoder gives for a system job; write the
  check on a control register's number; write the whole check as text.
- Ten headings, `titles.question` to `titles.reflection` in the order question, motivation,
  prediction, investigation, construction, failureExperiment, explanation, generalisation,
  challenge, reflection. They hold: a word that is no instruction; three reasons to refuse; a
  stop with a number; the checks opened; the number written as text; two checks stuck at 0;
  every kind and job; a line per kind, a check per kind; the whole check written as text; one
  memory, used twice.
- `challengeTitles.c1`: the check on the number, in the style "Memory checks, written".
  `challengeTitles.c2`: the whole check, same style.
- `captions.kindMap`: every kind and job, read off the decoder.
  `captions.predictNumber`: predict the cause, then check.
  `captions.checksOpen`: open the checks and try other words.
  `captions.writeOutside`: write OUTSIDE and run the tests.
  `captions.checkFaults`: choose a fault and run the checks.
  `captions.writeChecks`: write ILLEGAL and run the tests.
- `options.p1Stop`: CAUSED `00`: the stop stops the machine. `options.p1Illegal`: CAUSED `21`:
  the word is illegal. Each at most 8 words.
- `faults.noKindLow`: "NOKIND stuck at 0". `faults.numberLow`: "BADNUMBER stuck at 0". Return
  them as given.
- The checks' names, each at most 6 words: `checks.zeros` (a word of all zeros),
  `checks.kindNine` (kind 9, job 0), `checks.jobEight` (kind 1, job 8), `checks.numberFive`
  (kind 8, job 2, c 5), `checks.numberMinusOne` (kind 8, job 3, c -1), `checks.numberFour`
  (kind 8, job 2, c 4), `checks.add` (kind 1, job 2: an add).
