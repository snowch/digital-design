## question (about 70 words)

1. Lesson 2 ended on a question: what if the machine had one memory reached by one address, as
   Module 6's memory was? How could one instruction use it twice?
2. Module 8's machine reaches memory twice in one edge: the fetch at the PC, and a load's or a
   store's word at the ALU's result.
3. One address can name one place at a time.
4. End on the question: how can one instruction fetch itself and then load a word, through one
   address?

## motivation (about 170 words, a list allowed)

1. The instruction takes more than one edge. At one edge the memory's address is the PC, and the
   instruction comes in. At a later edge the address is the ALU's result, and the word comes in.
2. The instruction must be kept while the address moves on. So IR is now a register. It takes
   the word at the PC at the fetch edge and keeps it until the next fetch. A register that holds
   the instruction while it runs is the **instruction register**. Introduce the term here.
3. Any word that one edge works out and a later edge uses must be held too. Four registers hold
   them:
   - HA and HB, the words of registers A and B;
   - HR, the ALU's result;
   - HM, the word a load reads.
4. A controller says which edge the instruction is at. It is Module 5's state machine. Its five
   states are named for what the edge does: FETCH, READ (the registers), ALU, MEMORY, WRITE
   (register Y).
5. Each kind passes through only the states it needs. The decoder's signals choose them.
6. The PC keeps the instruction's address until the instruction's last edge. At that edge it
   takes the next PC, as in Module 8.

## p1Question (one or two sentences)

The PC is `000`, the load R2 ← memory[`7D8`]. How many edges does the load take, from its fetch
to the edge where the PC moves on?

## p1Explain (about 100 words, a list allowed)

1. The load takes 5 edges, one in each state:
   - FETCH: IR ← memory[PC];
   - READ: HA and HB take R0's word, twice, as A and B both name R0; the load uses neither, as
     its address is the constant alone;
   - ALU: HR ← 0 + c, the address `7D8`;
   - MEMORY: HM ← word[HR], room A's reading;
   - WRITE: R2 ← HM, and the PC moves on to `004`.
2. In Module 8's machine the same load took 1 edge.

## colderEdgesAfter (below the figure; about 100 words, a list allowed)

1. The program stops after 23 edges. The display shows -250: room B is colder.
2. Module 8's machine ran the same program in 6 edges.
3. Each of the two loads takes 5 edges. The branch takes 3: it writes no register. R2 ← R3 takes
   4. The store takes 4: it writes no register.
4. The stop takes 2 edges: its fetch, and the edge at which it halts the machine, in READ.
5. In the timing diagram, PCEN is 1 once per instruction, at its last edge. IREN is 1 at every
   FETCH.
