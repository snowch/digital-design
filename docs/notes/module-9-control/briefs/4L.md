# Brief 4L: lesson `micro-operations` (Module 9, lesson 4), the labels

Read `00-module.md` (the shared fact sheet) first; it applies here, except that a label is short
and need not be a sentence. "control unit", "illegal instruction", "instruction register" and
"micro-operation" are allowed.

Keys to write, each one line. Objectives and captions end with a full stop; headings do not.
Headings start with a capital letter and are short labels, 2 to 6 words, never the descriptions
below. Never use "your".

- `title`: a question a learner would ask, ending in "?", at most 9 words: what each edge of an
  instruction does.
- `objectives.1` to `objectives.4`, each starting with a verb, at most 12 words: predict which
  register an edge writes; follow one edge in four linked views; write the controller's output
  logic; write the whole controller as text.
- Ten headings, `titles.question` to `titles.reflection` in the order question, motivation,
  prediction, investigation, construction, failureExperiment, explanation, generalisation,
  challenge, reflection. They hold: what each edge does; transfers edge by edge; the third edge;
  four views of one run; each signal from the state; a moving PC and a lost store; signals that
  wait for the edge; a list of micro-operations; the whole controller written as text; the
  control unit, complete.
- `challengeTitles.c1`: the output logic, in the style "Memory checks, written".
  `challengeTitles.c2`: the whole controller, same style.
- `captions.predictTook`: predict the register the next edge writes, then check.
  `captions.fourViews`: clock edges and watch the four views move.
  `captions.writeOutputs`: write the output logic and run the tests.
  `captions.signalFaults`: choose a fault and run the margin.
  `captions.writeController`: complete the controller and run the tests.
- `options.p1Ir`: IR, the instruction register. `options.p1Hr`: HR, the ALU's result.
  `options.p1R1`: R1, the instruction's Y. Each at most 6 words.
- `faults.pcenHigh`: "PCEN stuck at 1". `faults.mstoreLow`: "MSTORE stuck at 0". Return them as
  given.
