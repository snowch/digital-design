## `c1Hints.2`, in lesson `micro-operations` (9.4)

Its current text, in `content/lessons/micro-operations.prose.ts`:

> A common mistake: leaving GO out of WREG. Then a halting edge in WRITE still writes register Y.

The machine never halts at a WRITE edge: the stop logic halts it only at a FETCH, READ or MEMORY
edge. Facts:

1. Keep "A common mistake: leaving GO out of WREG."
2. The tests run every state with GO at 1 and with GO at 0.
3. With GO left out, WREG is 1 in WRITE while GO is 0, and those tests fail.
4. The rule is the same for every signal that lets a register take a word, whichever state it
   belongs to: the state's line, AND what the kind needs, AND GO.
