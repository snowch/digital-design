explanation: The ILLEGAL signal is the OR of three checks on the K, J and C fields. One checks K: if the kind has no decoder line, the check is 1. One checks J: if the kind does not define the job, the check is 1. One checks C: for certain kinds and jobs, the constant must be in range; otherwise, the check is 1. These checks are gates, like the control signals, and settle at the same edge. When ILLEGAL is 1, the cause block outputs `21`. The stop logic halts the machine. An illegal instruction changes no register and no memory word.

generalisation: A decoder that knows its kinds can refuse any word that does not match. Each kind has a decoder line; a word with no line is illegal. The job check also refuses jobs the kind does not define. To add a new kind, give it a decoder line. The kind check then passes it through, and the job check learns which of its jobs exist. Words can reach the decoder by mistake: a jump to a wrong address runs whatever word sits there. The three checks catch it, halt the machine, and report cause `21`, instead of running on.
