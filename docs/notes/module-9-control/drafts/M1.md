reflection: Every word now either runs as an instruction or stops the machine with cause `21`. The control unit is the decoder of Module 8's machine. It now reads K, J and C, where Module 8's read K and J only. It works out the control signals and ILLEGAL. The machine runs each instruction in one edge. It reaches memory twice in that edge: once at the PC for the fetch, and once at the ALU's result for a load or store. What if the machine had one memory reached by one address, as Module 6's was? How could one instruction use it twice?

c1Hints.2: A common mistake: leaving GO out of WREG. If you do, WREG is 1 in WRITE while GO is 0, and the tests fail. Each signal that lets a register take a word needs: the state's line, AND what the kind needs, AND GO.
