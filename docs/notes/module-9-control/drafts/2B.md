construction: C is a 12-bit signed number. Values 0 to 4 are valid: bits 11 to 3 are all 0, and bits 2 to 0 are `000` to `100`. 

C is outside this range if any of bits 11 to 3 is 1. This catches negative numbers and values `800` to `FFF`. 

C is also outside the range if bit 2 is 1 with bit 1 or bit 0. This gives 5, 6 and 7.

You check both conditions.
