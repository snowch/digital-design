c2Hints.5: The whole `always_comb`:

```
always_comb begin
  case (state)
    FETCH: next = READ;
    READ: begin
      if (CALL) next = WRITE;
      else next = ALU;
    end
    ALU: begin
      if (MEM) next = MEMORY;
      else if (WRITEY) next = WRITE;
      else next = FETCH;
    end
    MEMORY: begin
      if (WRITEY) next = WRITE;
      else next = FETCH;
    end
    default: next = FETCH;
  endcase
end
```

modelVsReality: A clock's edges must leave time for the slowest path from one register to the next.

In Module 8's machine, one edge held a load's whole path: the fetch, the decoder, the register file, the ALU, the memory, and back to the register file.

Here each edge holds one part, so a real clock could run faster.

Whether the program then takes less time depends on how the parts' times compare. Real designers split the work so each edge's path takes about the same time.

The course's settle model counts steps, not time.
