# Brief X0: the drawings' shared strings (Modules 11 and 12)

Read `docs/style.md` first. These strings appear on Module 11's and Module 12's pages, so use no
rationed term except where a key says which module it is on. No backticks. Keep every
`{placeholder}` exactly as given. Write each from its facts alone.

Keys: `lanes.title`, `lanes.move`, `lanes.doorOpens`, `lanes.timerReaches`, `lanes.systemBand`,
`lanes.userBand`, `lanes.nextMove`, `boxes.label`, `boxes.changed`, `boxes.saves`,
`boxes.stackLabel`, `boxes.roomsLabel`, `boxes.roomAgain`, `boxes.roomsKey`.

## The run drawn as lanes

The drawing has one column (a lane) for each part of the program that runs, such as the main
program and a function, or the start, the handler and the program. Time runs down the page. A
bar in a lane is the run inside that part. An arrow across from one lane to another is the run
moving there, labelled with what that move writes, such as `R15 ← 00C` or `C2 ← 014, C3 ← 34`.

- `lanes.title`: the drawing's name for a screen reader (Modules 11 and 12): the run drawn as
  lanes, one for each part of the program that runs, with the moves between them. One short
  sentence fragment, no full stop.
- `lanes.move`: for a screen reader, one move: `{from}` and `{to}` are two lanes' names (such as
  "Main program", "overBy"); `{transfer}` is what the move writes, such as `R15 ← 00C`. Say: from
  {from} to {to}, writing {transfer}. Short, no full stop.
- `lanes.doorOpens` (Module 12, lesson 5 on): a label beside a mark in the drawing: the freezer's
  door opens here, between two instructions. Two or three words, lower case, no full stop.
- `lanes.timerReaches` (Module 12, lesson 5 on): the same for the timer: the timer reaches 0
  here. A few words, lower case, no full stop.
- `lanes.systemBand`, `lanes.userBand` (Module 12, lesson 3 on): the key under the drawing for a
  band beside the lanes that is one colour while the machine is in system mode and another in
  user mode. Each names its mode, such as "system mode". No full stop.
- `lanes.nextMove`: a button beside "Next edge" on the trap timeline (Module 12). It runs on, edge
  by edge, to the next arrow between lanes. Two or three words, capitalised as a button is ("Next
  edge", "Step back").

## Memory drawn as boxes, the stack, and the rooms (Module 11)

- `boxes.label`: `{title}` is a memory view's title, such as "Log". For a screen reader: that view
  drawn as words in boxes at their addresses, with an arrow from each register that holds an
  address. No full stop.
- `boxes.changed`: a line under such a drawing: the box with the thick outline is the word the
  last step stored. One short sentence.
- `boxes.saves`: beside a word on the stack: `{reg}` is the register whose word a push stored
  there, such as R15. Say it is that register's word, saved: two or three words, such as "saves
  {reg}". No full stop.
- `boxes.stackLabel`: the stack's drawing's name for a screen reader: the stack drawn as words in
  boxes, from the top of the RAM down, grouped by the call that pushed them. No full stop.
- `boxes.roomsLabel`: the cold store's drawing's name for a screen reader: the rooms reachable
  from the hall, each with its reading and its two doors. No full stop.
- `boxes.roomAgain`: `{name}` is a room a door leads back to, already drawn above. A few words:
  {name}, drawn above. No full stop.
- `boxes.roomsKey`: a line under the rooms drawing. Each room is a box with its name and reading.
  Its two doors are circles to its right: a circle with 1 or 2 is a door to a room, which is drawn
  below it, joined by a line; a dashed circle with 0 is a door that leads nowhere. The room the
  current call is about, the room whose address R1 holds, is lit. Two short sentences.
