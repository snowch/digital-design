mode, user mode; lesson 4 `system-calls`: system call; lesson 5 `interrupts`: interrupt; lesson 6
`nesting`. On these pages "the program" means the user program only; the start and the handler are
not parts of it. Write each key from its facts alone. Answer in the form `key: text`. A key marked
"(replaces ...)" gives the exact words it replaces: write only the new words. Code names
(addresses, lines, `resume`, `stop`) go in backticks in prose, as the existing text does.

Where the trap timeline's drawing sits: beside the list of edges on a wide screen, above it on a
narrow one. Do not say "above the list" alone. Where a debugger's drawing sits: under the listing
on a wide screen; on a narrow one, before the control registers' panel.
