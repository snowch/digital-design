Read `docs/style.md` first. Module 12's terms: lesson 1: trap, handler; lesson 3: system mode, user
mode; lesson 4: system call; lesson 5: interrupt. Write each key from its facts alone. Answer in
the form `lesson/key: text`. A key marked "(replaces ...)" gives the exact words it replaces: write
only the new words. Code names go in backticks in prose; in a program's comments (keys ending in
`.comment`) write plain text after `// ` on each line, no backticks, each line under 100 characters.

Facts about 12.8's check, from the code: the tests now check that the run ends at a `stop` among the
start's lines, which are the lines above the line named `handler`. A text with no line named
`handler`, or whose run ends at a `stop` at or after that line, fails, and the feedback says which.
The handler's first line must be named `handler:`; the start's lines, its `stop` included, go above
it.
