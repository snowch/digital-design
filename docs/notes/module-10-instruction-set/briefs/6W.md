# Brief 6W: lesson 1's opening figure, the two machines' parts

Read `00-module.md` (the shared fact sheet) first; it applies here, except that a label is short
and need not be a sentence. No Module 10 term appears here: the figure stands in the lesson's
motivation, before the lesson introduces any.

The figure is a table in the motivation of lesson 1. It has one row for each part the motivation
names, and one column for each machine: Module 8's machine and Module 9's machine. Each cell says
what that machine's circuit has for the part. The figure reads this from the two circuits.

full stop. No backticks, no quotes round values.
