# Brief 1L: lesson `instruction-set` (Module 10, lesson 1), the labels

Read `00-module.md` (the shared fact sheet) first; it applies here, except that a label is short
and need not be a sentence. Do not use "instruction set" or "microarchitecture" in any label
except `titles.explanation` may use "instruction set".

Keys to write, each one line. Objectives and captions end with a full stop; headings do not.
Headings start with a capital letter and are short labels, 2 to 6 words, never the descriptions
below. Never use "your".

- `title`: a question a learner would ask, ending in "?", at most 9 words: what every machine
  that runs the course's programs must agree on.
- `objectives.1` to `objectives.4`, each starting with a verb, at most 12 words: compare two
  machines after every instruction of one program; say which parts every machine must agree on;
  tell a fault that keeps the agreement from one that breaks it; write a circuit whose jobs take
  3 edges.
- Ten headings, `titles.question` to `titles.reflection` in the order question, motivation,
  prediction, investigation, construction, failureExperiment, explanation, generalisation,
  challenge, reflection. They hold: two machines, one program; the parts the machines share; the
  middle of an instruction; the two machines side by side; what instructions can name; two faults
  in Module 9's machine; the instruction set; a third circuit; jobs in three edges; what the
  layout costs.
- `challengeTitles.c1`: sorting the parts, in the style "Memory checks, written".
  `challengeTitles.c2`: the machine with jobs in 3 edges, same style.
- `captions.predictMid`: predict what the machines differ on, then check.
  `captions.sideBySide`: run both machines and compare them.
  `captions.sortParts`: sort each part and run the tests.
  `captions.compareFaults`: choose a fault and run the program.
  `captions.writeShortJobs`: change the machine's text and run it.
- `options.p1Nothing`: nothing. `options.p1R2`: R2. `options.p1Pc`: the PC. Each at most 3 words,
  starting with a capital.
- `sort.set`: "Every machine agrees on it". `sort.own`: "One circuit's own". Return as given.
- `parts.r7` to `parts.timer`, each at most 5 words, starting with a capital: R7; the PC; the IR;
  HR; the controller's state; the word at `400`; the display; HA; the timer's count.
- `faults.holdr`: "HOLDR stuck at 1". `faults.pcen`: "PCEN stuck at 1". Return as given.
