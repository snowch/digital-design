# Brief 3A: lesson `immediates` (Module 10, lesson 3), first part

Read `00-module.md` (the shared fact sheet) first; it applies here. "Instruction set",
"microarchitecture" and "opcode" are allowed. This lesson introduces **immediate**, but only in
the explanation, which another brief writes: "immediate" must not appear in these keys.

Keys to write: `question`, `motivation`, `rangeLead`, `prediction`, `p1Question`, `p1Explain`.

## question (about 70 words)

1. Lesson 2 ended on three questions. The layout keeps every field in place and pays with a 12-bit
   constant. What can one instruction say in 12 bits? How far can a branch reach? What does a
   program do with a number too wide for the constant?
2. End on the question: is 12 bits enough for what programs need to say?

## motivation (above the figure; about 150 words)

1. The constant is digits 2 to 0: 12 bits, read signed, widened to 64 bits by copying bit 11. It
   holds -2048 to 2047.
2. The memory has 2 KB, at addresses `000` to `7FF`. `7FF` is 2047, the largest number the
   constant holds. The course's machine was given this much memory so that every address fits in
   one instruction's constant.
3. So an absolute load or store reaches any part of the memory in one instruction, with no
   register holding the address. R2 ← memory[`7D8`] is `380027D8`.
4. A branch's constant counts instructions, not bytes: the target is PC + 4c. So a branch reaches
   2047 instructions forward and 2048 back.
5. The ROM holds 256 instructions, so every branch reaches the whole ROM.

## rangeLead (above the figure; about 40 words)

1. The figure widens three constants: `7FF` (2047, the largest), `800` (-2048, the smallest) and
   `FFF` (-1).
2. Bit 11 is copied into bits 63 to 12.

## prediction (above the figure; about 100 words)

1. A branch's conditions are: equal, differs, less, and not less, with less and not less read
   signed or unsigned. There is no "greater than".
2. A program needs to go to a target if R1 > R2, read signed.
3. The figure has three pairs of words for R1 and R2: 5 and -3; -3 and 5; 5 and 5.
4. Choose the branch that is taken for every pair exactly when R1 > R2.
5. Press "Check my prediction". The figure then shows a table of every comparison and the branch
   that says it.

## p1Question (one sentence)

Which branch is taken exactly when R1 > R2, read signed?

## p1Explain (about 100 words)

1. "if R2 < R1, signed": the machine's "less than", with the two registers swapped. R1 > R2 says
   the same as R2 < R1.
2. "if R1 >= R2" is taken when R1 equals R2. With 5 and 5, R1 > R2 is false, but that branch is
   taken.
3. "if R2 >= R1" is taken when R1 is less. With -3 and 5, R1 > R2 is false, but that branch is
   taken.
