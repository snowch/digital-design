# Brief 1A: lesson `instruction-set` (Module 10, lesson 1), first part

Read `00-module.md` (the shared fact sheet) first; it applies here. This lesson introduces
**instruction set** and **microarchitecture**, but only in the explanation, which another brief
writes: neither word may appear in these keys. No Module 10 term appears here.

Keys to write: `question`, `motivation`, `prediction`, `p1Question`, `p1Explain`.

## question (about 80 words)

1. Module 9 ended on a question: which instructions a machine has is a choice, and so is how
   their words are laid out. Why are the course's instructions the ones they are?
2. Two machines in the course already run the same programs. Module 8's takes one edge for each
   instruction. Module 9's takes 3 to 5, with one memory port, an IR register and held words.
3. Both ran the colder-room program and showed -250 on the display.
4. End on the question: what is the same between the two machines? What can a program rely on,
   whichever machine runs it?

## motivation (about 130 words, a list allowed)

1. The two machines have different parts.
   - Module 9's machine has an IR register, the held words HA, HB, HR and HM, and the controller's
     state.
   - Module 8's machine has none of these. Its IR is a bus: the ROM's output at the PC.
   - Both have R0 to R15, the PC, the memory (the ROM and the RAM) and the shop's devices.
2. A program's instructions name some parts and not others. A field names a register; a load or a
   store names an address; a branch, a call or a jump moves the PC.
3. No field of any instruction names the IR, a held word or the controller's state.
4. The course's tests ran Module 8's 37 programs on Module 9's machine. After every instruction
   they compared it with a model of the machine that runs one instruction at a time.

## prediction (above the figure; about 70 words)

1. The figure runs the colder-room program on both machines side by side.
2. Module 9's machine has made 3 edges of the first instruction, the load R2 ← memory[`7D8`]:
   FETCH, READ and ALU. It is in MEMORY.
3. Module 8's machine takes its one edge for an instruction when Module 9's machine ends that
   instruction. So it has not run the load yet.
4. Choose an answer and press "Check my prediction". The figure then shows its tables and its
   buttons.

## p1Question (one sentence)

Of the PC, R2, R3 and the display, what do the two machines differ on now?

## p1Explain (about 100 words)

1. Nothing. Both PCs hold `000`. R2 and R3 are X on both machines. Both displays show 0.
2. Module 9's machine has changed only its own parts: its IR holds `380027D8`, the load, and HR
   holds `7D8`, the address.
3. The load writes R2 at its last edge, WRITE. The PC moves at that edge too.
4. In Module 9's machine, every change a program can see happens at the edge that ends the
   instruction: a register written, the memory or a device written, the PC moved.
