# Brief 5A: lesson `design-an-instruction` (Module 10, lesson 5), first part

Read `00-module.md` (the shared fact sheet) first; it applies here. Every Module 10 term is
allowed: "instruction set", "microarchitecture", "opcode", "immediate". This lesson introduces no
term.

Keys to write: `question`, `motivation`, `shorterLead`, `shorterAfter`, `prediction`,
`p1Question`, `p1Explain`.

## question (about 80 words)

1. Lesson 4 ended on two questions: which instruction would you add, and how would you show it is
   worth what it costs the circuit?
2. This lesson adds "set if": RY ← 1 if RA and RB meet a condition, else RY ← 0.
3. You design it against the layout's rules, justify it with a program it shortens, and build it
   into your copy of Module 9's machine, where kind 9 holds the call through a register.
4. End on the question: what does set if need from the machine?

## motivation (above the figure; about 110 words)

1. Set if keeps a comparison as a number, 1 or 0, in a register.
2. Its job digit is a branch's condition: equal, differs, and less and not less, read signed or
   unsigned.
3. With job 6, less read signed: R5 ← 1 if R2 < R1, read signed, else 0.
4. Its word is `A6215000`: kind A, job 6, A is R2, B is R1, Y is R5, the constant unused.

## shorterLead (above the figure; about 100 words, a list allowed)

1. Two programs count how many rooms are colder than the limit, -200, and show the count.
   - The first uses branches, on the course's machine. For each room, a branch skips the count
     when the room is not colder.
   - The second uses set if, on your copy with kind A: R5 ← 1 if R2 < R1, R6 ← 1 if R3 < R1, then
     R4 ← R5 + R6.
2. Room A reads -184 and room B -250.
3. Press "Run the programs".

## shorterAfter (below the figure, shown once the programs have run; about 70 words)

1. Both display 1. Room B, at -250, is colder than -200; room A, at -184, is not.
2. The branches: 10 instructions written, 9 run.
3. Set if: 8 instructions written, 8 run, and no branch, so the same instructions run whatever the
   readings.
4. R5 holds 0 and R6 holds 1.

## prediction (above the figure; about 80 words)

1. Set if subtracts RB from RA, as a branch does, and writes register Y, as a register job does.
2. In Module 9's machine a register job takes FETCH, READ, ALU and WRITE. A branch takes FETCH,
   READ and ALU.
3. The figure runs the decoder's signals for kind A through the controller.
4. Choose an answer and press "Check my prediction". The figure then shows each kind's edges.

## p1Question (one sentence)

How many edges does set if take in your copy of Module 9's machine?

## p1Explain (about 100 words)

1. 4 edges: FETCH, READ, ALU, WRITE, as a register job.
2. The decoder sets WRITEY, and not MEM or CALL, so the controller goes from READ to ALU, then to
   WRITE. The controller does not change.
3. At the WRITE edge the condition is worked out again. HA, HB and the IR keep their words from
   READ, so the ALU's flags and MET are the same as at ALU.
4. Register Y takes MET as a word.
