# Brief 4B: lesson `room-to-grow` (Module 10, lesson 4), second part

Read `00-module.md` (the shared fact sheet) first; it applies here. "Instruction set",
"microarchitecture", "opcode" and "immediate" are allowed. No new term.

Keys to write: `investigation`, `multiplyLead`, `multiplyAfter`, `construction`, `sortWordsLead`,
`c1Task`, `c1Hints.1` to `c1Hints.5`, `newWordsLead`, `newWordsAfter`.

## investigation (one or two sentences, above the figure)

The machine has no multiplication. The figure compares two programs that work out 7 × 5.

## multiplyLead (above the figure; about 110 words, a list allowed)

1. The first program adds 7 into R3 five times, in a loop. R2 counts down from 5. The branch goes
   back while R2 differs from R0.
2. R0 holds 0. The machine has no comparison with zero, so the program keeps 0 in a register.
3. The second program doubles 7 twice and adds 7 once: 7 + 7 is 14, 14 + 14 is 28, 28 + 7 is 35.
   It works only for a factor known when the program is written.
4. Press "Run the programs".

## multiplyAfter (below the figure, shown once the programs have run; about 70 words)

1. Both display 35.
2. The loop: 9 instructions written, 21 run. Doubling: 6 written, 6 run.
3. The loop runs 3 instructions each time round. For 7 × n it runs 4 + 3n + 2 instructions, the
   stop among them.

## construction (about 80 words)

1. In the course's machine, kinds 9 to F are free: seven kinds. In your copy of Module 9's machine,
   kind 9 holds the call through a register, and kinds A to F are free.
2. Every word of a free kind is illegal today.
3. So the machine stops at it, with cause `21`, rather than doing something nobody chose.

## sortWordsLead (one sentence)

Say what the course's machine does at each word.

## c1Task (about 80 words, a list allowed)

1. For each of six words, choose what the course's machine does when it reaches it: it runs it;
   it stops at it, as `stop`; or it stops with cause `21`.
2. The words: `00000000`; `9040F000`, your copy's call through R4; `18123000`; `51000000`;
   `84000000`; `22102064`.
3. There are 6 tests, one for each word.

## c1Hints (five, in this order)

1. The idea: read K, then J. Is the kind one of 1 to 8? Is the job one its kind defines?
2. A common mistake: `9040F000` runs in your copy of the machine, not in the course's machine,
   which refuses kind 9.
3. A smaller example: `00000000` is kind 0, so the machine stops with cause `21`.
4. Part of the answer: `51000000` is a branch whose job, 1, is "never". It runs and does nothing.
   `18123000` is a register job with job 8, which kind 1 does not define.
5. The whole answer: cause `21`, cause `21`, cause `21`, runs, `stop`, runs.

## newWordsLead (above the failure figure; about 90 words)

1. The program that chooses a room, from Module 9's last lesson, uses your copy's call through a
   register at `004`: `9040F000`.
2. The figure runs it twice: on your copy, which knows kind 9, and on the course's machine, which
   does not.
3. Before you run them, say what each displays. Then press "Run the programs".

## newWordsAfter (below the figure, shown once the programs have run; about 90 words)

1. Your copy displays -184, room A's reading. R15 holds `008`, and it stops at its stop.
2. The course's machine stops at `004` with cause `21`, and its display shows 0.
3. A new instruction makes words an older machine refuses.
4. The other way round, programs written for the course's machine run on your copy: every word
   they use means the same there.
