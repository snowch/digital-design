# Brief 3L: lesson `immediates` (Module 10, lesson 3), the labels

Read `00-module.md` (the shared fact sheet) first; it applies here, except that a label is short
and need not be a sentence. Do not use "immediate" in any label except `titles.explanation`.

Keys to write, each one line. Objectives and captions end with a full stop; headings, choice
labels and field labels do not. Headings start with a capital letter and are short labels, 2 to 6
words. Never use "your". Where this brief says "return as given", return the text exactly.

- `title`: a question a learner would ask, ending in "?", at most 9 words: what one instruction
  can say.
- `objectives.1` to `objectives.4`, each starting with a verb, at most 12 words: give the
  constant's range and a branch's reach; say greater than with the machine's branches; build a
  number too wide for the constant; write greater than from the ALU's subtraction.
- Ten headings, `titles.question` to `titles.reflection` in the order question, motivation,
  prediction, investigation, construction, failureExperiment, explanation, generalisation,
  challenge, reflection. They hold: what 12 bits can say; every address in one instruction; no
  greater than; comparisons and a wide number; working out a reach; a room at the limit; the
  immediate; numbers too wide; greater than, written; what the machine leaves out.
- `challengeTitles.c1`: numbers worked out, in the style "Memory checks, written".
  `challengeTitles.c2`: greater than, same style.
- `captions.range`: choose a constant and see it widened.
  `captions.predictGreater`: predict the branch, then check.
  `captions.comparisons`: choose a pair and read each comparison's branch.
  `captions.wide`: run two ways of making 5000.
  `captions.workReach`: work out each number and run the tests.
  `captions.equalTrap`: run two counts of the warm rooms.
  `captions.writeGreater`: write the module and run the tests.
- Return as given: `constants.most`: "7FF, the largest". `constants.least`: "800, the smallest".
  `constants.minusOne`: "FFF, which is -1".
- Return as given: `options.p1Swap`: "if R2 < R1 (signed)". `options.p1NotLess`:
  "if R1 >= R2 (signed)". `options.p1NotLessSwap`: "if R2 >= R1 (signed)".
- Return as given: `pairs.larger`: "R1 5, R2 -3". `pairs.smaller`: "R1 -3, R2 5". `pairs.equal`:
  "R1 5, R2 5". `pairs.overflow`: "R1 the largest signed number, R2 -1".
- Return as given: `programs.sums`: "5000 from three constant jobs". `programs.word`: "5000 as a
  word in the ROM". `programs.right`: "Not warmer: if R1 >= R2". `programs.wrong`:
  "Colder: if R2 < R1".
- Return as given: `reach.largest`: "The largest number one constant job puts in a register".
  `reach.back`: "The constant of a branch at 01C to 008". `reach.furthest`: "The highest address a
  branch at 000 names".
