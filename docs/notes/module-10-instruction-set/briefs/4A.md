# Brief 4A: lesson `room-to-grow` (Module 10, lesson 4), first part

Read `00-module.md` (the shared fact sheet) first; it applies here. "Instruction set",
"microarchitecture", "opcode" and "immediate" are allowed. This lesson introduces no term.

Keys to write: `question`, `motivation`, `mapLead`, `prediction`, `p1Question`, `p1Explain`.

## question (about 70 words)

1. Lesson 3 ended: kinds 0 and 9 to F say nothing.
2. End on the questions: what does the machine do with a word it has no instruction for? What else
   does it leave out, and what would each cost to add?

## motivation (above the figure; about 130 words, a list allowed)

1. A word is an illegal instruction when:
   - its kind is 0, or 9 to F;
   - its job is one its kind does not define;
   - it is a system job 2 or 3 naming a control register outside 0 to 4.
2. Of the 256 pairs of K and J, 37 are instructions whatever the constant. Two more, kind 8's jobs
   2 and 3, are instructions only when the constant is 0 to 4.
3. At an illegal instruction the machine stops with cause `21` (Module 9).
4. A word of all zeros, `00000000`, is kind 0: illegal.
5. After a program and its data, every byte of the ROM is 0.

## mapLead (above the figure; about 50 words)

1. The map runs every kind and job through the decoder, with the constants 0 and 5.
2. A ✓ marks an instruction, a dot a word that is not one, and a c an instruction only for some
   constants.

## prediction (above the figure; about 80 words)

1. The program has two instructions: R1 ← 66, then memory[`7C0`] ← R1, which shows R1 on the
   display.
2. It has no stop. After it, the ROM holds 0s.
3. Choose an answer and press "Check my prediction". Then press "Run the programs" to run it.

## p1Question (one sentence)

After the store at `004`, how does the run end?

## p1Explain (about 90 words)

1. It stops at `008` with cause `21`. The word at `008` is `00000000`, kind 0: an illegal
   instruction.
2. The display shows 66: both instructions ran.
3. A word of all zeros is illegal on purpose. A program that runs off its end stops at the first
   word of zeros, not wherever its next zeros would lead.
4. If data followed the program in the ROM, the machine would run the data's words as
   instructions first.
