# Brief 4L: lesson `room-to-grow` (Module 10, lesson 4), the labels

Read `00-module.md` (the shared fact sheet) first; it applies here, except that a label is short
and need not be a sentence.

Keys to write, each one line. Objectives and captions end with a full stop; headings, choice
labels and field labels do not. Headings start with a capital letter and are short labels, 2 to 6
words. Never use "your". Where this brief says "return as given", return the text exactly.

- `title`: a question a learner would ask, ending in "?", at most 9 words: what the machine leaves
  out.
- `objectives.1` to `objectives.4`, each starting with a verb, at most 12 words: say which words
  are illegal and why; predict how a program without a stop ends; weigh what a left-out
  instruction costs and saves; count the instructions a loop runs.
- Ten headings, `titles.question` to `titles.reflection` in the order question, motivation,
  prediction, investigation, construction, failureExperiment, explanation, generalisation,
  challenge, reflection. They hold: words with no instruction; illegal words; a program without a
  stop; multiplying without multiplication; the free kinds; a new kind on an old machine; what
  each left-out instruction costs; room for later; counting a loop; choosing an instruction.
- `challengeTitles.c1`: what the machine does with each word, in the style "Memory checks,
  written". `challengeTitles.c2`: the loop's count, same style.
- `captions.map`: every kind and job, read off the decoder.
  `captions.predictNoStop`: predict how the run ends, then check.
  `captions.multiply`: run two programs that work out 7 × 5.
  `captions.sortWords`: choose what the machine does at each word.
  `captions.newWords`: run the same program on two machines.
  `captions.countLoop`: count the instructions and run the tests.
- Return as given: `does.runs`: "Runs it". `does.stop`: "Stops at it: stop". `does.illegal`:
  "Stops with cause 21".
- Return as given: `options.p1Illegal`: "It stops at 008, cause 21". `options.p1RomEnd`: "It runs
  to the ROM's end and stops, cause 11". `options.p1Never`: "It never stops".
- Return as given: `programs.noStop`: "Two instructions, no stop". `programs.loop`: "7 × 5 in a
  loop". `programs.doubling`: "7 × 5 by doubling". `programs.copy`: "The copy with kind 9".
  `programs.course`: "The course's machine".
- Return as given: `words.zeros`: "00000000". `words.kind9`: "9040F000 (call through R4)".
  `words.job8`: "18123000". `words.never`: "51000000". `words.stop`: "84000000". `words.add`:
  "22102064".
- Return as given: `counts.times9`: "Instructions run for 7 × 9". `counts.times50`: "Instructions
  run for 7 × 50".
