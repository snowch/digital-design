# Brief 5L: lesson `design-an-instruction` (Module 10, lesson 5), the labels

Read `00-module.md` (the shared fact sheet) first; it applies here, except that a label is short
and need not be a sentence.

Keys to write, each one line. Objectives and captions end with a full stop; headings, choice
labels, field labels and step labels do not. Headings start with a capital letter and are short
labels, 2 to 6 words. Never use "your". Where this brief says "return as given", return the text
exactly.

- `title`: a question a learner would ask, ending in "?", at most 9 words: how to design and build
  a new instruction.
- `objectives.1` to `objectives.5`, each starting with a verb, at most 12 words: justify a new
  instruction by a program it shortens; predict the edges the new instruction takes; check a design
  against the layout's rules; add a kind to the decoder's text; give the datapath a new source for
  register Y.
- Ten headings, `titles.question` to `titles.reflection` in the order question, motivation,
  prediction, investigation, construction, failureExperiment, explanation, generalisation,
  challenge, reflection. They hold: one instruction to add; a comparison kept as a number; set if's
  edges; a new source for register Y; the design and its column; SET stuck; what set if changed;
  what a new instruction needs; the whole machine; programs written by hand.
- `challengeTitles.c1`: the design, in the style "Memory checks, written". `challengeTitles.c2`:
  kind A in the decoder, same style. `challengeTitles.c3`: the whole machine with set if, same
  style.
- `captions.shorter`: run the count of cold rooms two ways.
  `captions.predictEdges`: predict set if's edges, then check.
  `captions.yWord`: press the inputs and watch the word register Y takes.
  `captions.newColumn`: kind A's column beside a register job's and a branch's.
  `captions.design`: make each choice and run the tests.
  `captions.writeDecoder`: add kind A and run the tests.
  `captions.setFaults`: choose a fault and run the checks.
  `captions.writeMachine`: change the machine's text and run it.
- Return as given: `options.p1Three`: "3 edges, as a branch". `options.p1Four`: "4 edges, as a
  register job". `options.p1Five`: "5 edges, as a load".
- Return as given: `programs.branches`: "Branches, on the course's machine". `programs.setIf`:
  "Set if, on the copy with kind A".
- Return as given: `faults.setLow`: "SET stuck at 0". `faults.setHigh`: "SET stuck at 1".
- Return as given: `run.setOne`: "set if, MET 1". `run.setZero`: "set if, MET 0". `run.job`: "a
  register job". `run.load`: "a load".
- Return as given, the design's field labels: `design.kind`: "The kind". `design.result`: "The
  field that names the register written". `design.condition`: "Where the condition comes from".
  `design.program`: "The program it shortens". `design.cost`: "What it costs the circuit".
- Return as given, the choices: `choices.kind.0`: "0". `choices.kind.5`: "5". `choices.kind.9`:
  "9". `choices.kind.A`: "A". `choices.result.y`: "Y, digit 3". `choices.result.b`: "B, digit 4".
  `choices.result.new`: "A new digit of its own". `choices.condition.job`: "The job digit, as a
  branch's". `choices.condition.constant`: "The constant". `choices.condition.new`: "A new field".
  `choices.program.count`: "The count of the cold rooms". `choices.program.colder`: "The display
  of the colder room". `choices.program.times`: "7 × 5". `choices.cost.column`: "A decoder column
  and its checks only". `choices.cost.source`: "A new source for register Y and a control signal".
  `choices.cost.part`: "A new part beside the ALU".
