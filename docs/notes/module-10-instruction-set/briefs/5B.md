# Brief 5B: lesson `design-an-instruction` (Module 10, lesson 5), second part

Read `00-module.md` (the shared fact sheet) first; it applies here. Every Module 10 term is
allowed. No new term.

Keys to write: `yWordLead`, `yWordAfter`, `newColumnLead`, `construction`, `designLead`,
`c1Task`, `c1Hints.1` to `c1Hints.5`, `writeDecoderLead`, `c2Task`, `c2Hints.1` to `c2Hints.5`,
`setFaultsLead`, `faultSetLow`, `faultSetHigh`.

## yWordLead (above the first figure; about 110 words)

1. The figure is the block that chooses the word register Y takes, with set if's new input.
2. Module 9's block chooses HR, the held result; HM, a load's word, when LOAD is 1; or PC + 4, when
   CALL is 1.
3. The new input is MET, the branch condition, as a 64-bit word: 63 zeros above it. When SET is
   1, register Y takes that word.
4. Press LOAD, CALL, SET and MET, and watch YIN.

## yWordAfter (below the first figure; about 50 words)

1. With SET at 1, YIN is MET as a word: 1 when MET is 1, 0 when MET is 0, whatever HR, HM, LOAD
   and CALL hold.
2. SET's selector comes last, so SET wins over LOAD and CALL.

## newColumnLead (above the second figure; about 60 words)

1. The table is read off your copy's decoder with kind A, beside a register job's column and a
   branch's.
2. Kind A's column has WRITEY as a register job has it, OP1 and OP0 (subtract) as a branch has
   them, BRANCH 0, and SET 1.

## construction (about 100 words)

1. A design is checked against the layout's rules from lessons 2 to 4:
   - a kind that is free in the machine it goes into;
   - each register named by the field every instruction uses for it, so the decoder never moves a
     field;
   - what it shortens, counted on a program;
   - what it costs the circuit, set against what it saves.
2. The first challenge checks set if's design against these rules. The second builds its decoder
   column.

## designLead (one sentence)

Check set if's design against the layout's rules.

## c1Task (about 110 words, a list allowed)

1. Make five choices:
   - the kind, one of 0, 5, 9 and A;
   - the field that names the register written;
   - where the condition comes from;
   - the program set if shortens;
   - what set if costs the circuit.
2. There are 5 tests, one for each choice.

## c1Hints (five, in this order)

1. The idea: a free kind; each register in the field every instruction uses for it; a cost set
   against what it saves.
2. A common mistake: choosing kind 9. It is free in the course's machine, but in your copy it holds
   the call through a register.
3. A smaller example: every instruction that writes a register names it in Y, digit 3, so the
   register file's write address needs no selector.
4. Part of the answer: the condition is the job digit, as a branch's, so the condition block built
   in Module 8 serves both. The program is the count of the cold rooms.
5. The whole answer: kind A; Y, digit 3; the job digit, as a branch's; the count of the cold rooms;
   a new source for register Y and a control signal.

## writeDecoderLead (one sentence)

Add kind A to your copy's decoder.

## c2Task (about 150 words, a list allowed)

1. The text is your copy's decoder, from Module 9's last lesson. Inputs K, J and C; outputs the
   control signals, MEM, SET, STOP and CAUSED.
2. The start declares SET and sets it to 0, and still refuses kind A.
3. Make three changes:
   - add an arm `4'hA:` to the `case`, setting WRITEY, OP1, OP0 and SET;
   - in ILLEGAL's first term, stop refusing kind A;
   - refuse kind A's jobs 8 to F, as kinds 1, 2 and 5 refuse theirs: add kind A to the term that
     refuses job bit 3.
4. The tests cover every kind and job with the constant 0, and jobs 2 and 3 of kind 8 with three
   constants: 262 tests. The start fails 16. The first failure is "K A, J 0".

## c2Hints (five, in this order)

1. The idea: kind A's column is a register job's WRITEY, a branch's subtract, and SET.
2. A common mistake: leaving kind A's jobs 8 to F legal. The term that refuses job bit 3 for kinds
   1, 2 and 5 must refuse it for kind A too.
3. A smaller example, the arm:
   `4'hA: begin WRITEY = 1'b1; OP1 = 1'b1; OP0 = 1'b1; SET = 1'b1; end`
4. Part of the answer, ILLEGAL's first term:
   `(K == 4'h0) | (K[3] & (K != 4'h8) & (K != 4'h9) & (K != 4'hA))`
5. The whole answer: the arm in hint 3, the term in hint 4, and
   `(((K == 4'h1) | (K == 4'h2) | (K == 4'h5) | (K == 4'hA)) & J[3])`.

## setFaultsLead (above the failure figure; about 100 words, a list allowed)

1. The fault lab runs the block that chooses register Y's word through four cases: a set if with
   MET at 1; a set if with MET at 0; a register job; a load.
2. HR holds `42` (66), HM holds `7`, and PC + 4 is `10`.
3. Two faults to choose:
   - "SET stuck at 0": the new input is never chosen;
   - "SET stuck at 1": it is chosen for every instruction.
4. Choose a fault and run the checks. Before you do, say which cases each fault breaks.

## faultSetLow (shown once that fault has run; about 60 words)

Start with the fault's name in bold: **SET stuck at 0**.

1. Both set if cases give `42`, HR, the subtraction, not 1 or 0.
2. The register job and the load are right.
3. This is your copy before the datapath's change: set if would write RA - RB.

## faultSetHigh (shown once that fault has run; about 60 words)

Start with the fault's name in bold: **SET stuck at 1**.

1. The set if cases are right.
2. The register job gives 1, not `42`. The load gives 1, not `7`.
3. Every instruction that writes register Y would write its condition.
