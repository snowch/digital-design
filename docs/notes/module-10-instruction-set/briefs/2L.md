# Brief 2L: lesson `encoding` (Module 10, lesson 2), the labels

Read `00-module.md` (the shared fact sheet) first; it applies here, except that a label is short
and need not be a sentence. Do not use "opcode" or "immediate" in any label.

Keys to write, each one line. Objectives and captions end with a full stop; headings do not.
Headings start with a capital letter and are short labels, 2 to 6 words. Never use "your".

- `title`: a question a learner would ask, ending in "?", at most 9 words: why every field of an
  instruction is a whole digit.
- `objectives.1` to `objectives.4`, each starting with a verb, at most 12 words: say what the
  course's layout gives and what it costs; compare it with a packed layout; write instructions as
  eight hexadecimal digits; write the selector a packed layout needs.
- Ten headings, `titles.question` to `titles.reflection` in the order question, motivation,
  prediction, investigation, construction, failureExperiment, explanation, generalisation,
  challenge, reflection. They hold: a layout is a choice; one layout for every instruction; a
  packed layout; two layouts and an explorer; writing an instruction's word; packed words read the
  course's way; what a layout costs; choosing an encoding; a field that moves; what 12 bits say.
- `challengeTitles.c1`: instruction words, in the style "Memory checks, written".
  `challengeTitles.c2`: the packed layout's Y digit, same style.
- `captions.oneLayout`: choose an instruction and read its fields.
  `captions.predictMoved`: predict which field moves, then check.
  `captions.layouts`: choose an instruction and compare the two layouts.
  `captions.explorer`: take a word apart, and run the ALU.
  `captions.writeWords`: write each word and run the tests.
  `captions.packedRead`: choose a packed word and read what the machine makes of it.
  `captions.writeYdigit`: write the module and run the tests.
- `options.p1Y`: "Y". `options.p1A`: "A". `options.p1None`: "None". Return as given.
- Choice labels, each at most 8 words, starting with the word's digits or transfer:
  `words.subtract`: "13123000: R3 ← R1 - R2". `words.addConstant`: "22102064: R2 ← R1 + 100".
  `words.load`: "380027D8: R2 ← memory[7D8]". `words.branch`: "56230002: the colder-room branch".
  `words.call`: "6000F005: a call, R15 ← PC + 4". `words.jump`: "70F00000: a jump, PC ← R15".
  `words.stop`: "84000000: stop". `words.zeros`: "00000000: a word of zeros".
  `words.packedAdd`: "22120064: R2 ← R1 + 100, packed". `words.packedLoad`:
  "380207D8: R2 ← memory[7D8], packed". `words.packedCall`: "60F00001: a call, packed".
  Return these as given.
- `encode.sub`: "R5 ← R2 - 7 (subtract)". `encode.load`: "R4 ← memory[R1 + 16] (a word)".
  `encode.branch`: "if R3 != R6, PC ← PC + 4 × (-3)". Return as given.
- `fieldNotes.K` to `fieldNotes.C`, each at most 7 words, what the field says: the kind; the job;
  the register read as A; the register read as B; the register written; a constant of 12 bits.
