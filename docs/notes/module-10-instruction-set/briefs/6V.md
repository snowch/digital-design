# Brief 6V: Module 10's figures, their own words

Read `00-module.md` (the shared fact sheet) first; it applies here, except that a label is short
and need not be a sentence. Every Module 10 term is allowed.

These are the words the figures write: status lines, notes, messages and verdicts. Each key below
says what the text must say. Keep every slot in braces, such as `{k}` or `{address}`, exactly as
written: the figure puts a number or a word there. Do not add a slot. A text that is a full
sentence ends with a full stop; a label does not.

Return each key as `key: text`, one per line.

## The two machines compared (lesson 1)

- `ownNote`: under the table of Module 9's machine's own parts: Module 8's machine has none of these
  parts.
- `logNone`: in the table of instructions run, before any has finished: no instruction has finished
  yet.
- `statusIn`: Module 9's machine is in the middle of an instruction: it has made `{k}` edges of the
  instruction at `{address}`.
- `statusBetween`: both machines are between two instructions.
- `statusStopped`: both machines have stopped.
- `statusGaveUp`: `{n}` instructions have run and the machines have not stopped.
- `answer`: after a prediction, what the machines differ on: `{answer}` (a list of parts, or
  "nothing").
- `nothing`: the word for no part at all, lower case: "nothing".
- `agree`: one word, lower case, in a row whose two machines hold the same value: "same".
- `differsMark`: one word, lower case, in a row where they differ: "differs".
- `disagree`: after an instruction, the parts the machines differ on: `{names}`. Short, lower case,
  starting "differ".
- `stops`: one word, lower case, for the row of the instruction the machines stop at.

## The two layouts (lesson 2)

- `layoutRange`: the constant's width and range in a layout: `{bits}` bits, `{min}` to `{max}`.
  Start with "Constant:".
- `layoutMoved`: the fields that sit in other digits than in the course's layout: `{names}`.
  Start with "Moved:".
- `layoutStill`: no field moves.
- `layoutAnswer`: after a prediction: the fields the packed layout moves: `{answer}`.

## The explorer and the calculator (lesson 2 on)

- `wordHelp`: under the word's box: type a word, or choose one below.
- `wordProblem`: when the box does not hold a word: an instruction has `{n}` hexadecimal digits.
- `illegal.kind`: the word is not an instruction: kind `{k}` is not one of the machine's kinds; the
  machine stops with cause 21.
- `illegal.job`: the word is not an instruction: kind `{k}` has no job `{j}`; the machine stops with
  cause 21.
- `illegal.number`: the word is not an instruction: C`{c}` is not a control register; the machine
  stops with cause 21.
- `widened`: the constant `{c}` widens to the 64-bit word `{w}`, which read signed is `{n}`.
- `fromWordNone`: after the button "Take the job and B from the word" on a word that is not a
  register job or a constant job: only a register job or a constant job gives the ALU a job.
- `tookJob`: after that button: the job is the word's J, `{job}`.
- `tookB`: after that button, for a constant job: B is the word's constant, widened.
- `entryEmpty`: a box for A or B is empty: type a word.
- `entryNotHex`: `{char}` is not a hexadecimal digit.
- `entryHexLong`: a word this wide has at most `{digits}` hexadecimal digits.
- `entryNotNumber`: `{char}` is not part of a number.
- `entryRange`: the number must be from `{min}` to `{max}`.

- `ran`: the instructions run, the stop among them: `{n}`. A label, starting "Instructions run".

- `registerAfter`: R`{n}` at the stop: `{value}`.
- `displayAfter`: the display at the stop: `{value}`.
- `stoppedAtStop`: the run stopped at the stop, at `{address}`.
- `stoppedCause`: the run stopped at `{address}`, with cause `{cause}`.
- `notStopped`: the run did not stop.
- `programAnswer`: after a prediction: the run gives `{answer}`.
