layoutsAfter: In the packed layout:
- A constant job and a load: a 16-bit constant (from -32768 to 32767), and Y moves to digit 4.
- A branch: a 16-bit constant, and nothing moves. The word stays `56230002`.
- A call: a 20-bit constant (from -524288 to 524287), and Y moves to digit 5.
- A jump: a 20-bit constant, and nothing moves.
- A register job: no change. It uses every register digit and leaves the constant unused.

construction: To write an instruction's word, write its fields in order, one digit each: K, J, A, B, Y. Then write the constant as three hexadecimal digits. A field the instruction does not use is written as 0. A negative constant is written as its 12-bit signed reading: -3 is `FFD`. Here is an example: R2 ← R1 + 100. This is kind 2 (constant job), job 2 (add), A is R1, B unused (written 0), Y is R2. The constant 100 in hexadecimal is `064`. The word is `22102064`.

packedReadAfter: Each word writes R0, not the register it was written for. The course's machine reads digit 3 as Y. In each packed word, digit 3 holds the constant's top digit, here 0. `22120064` reads as R0 ← R1 + 100. `380207D8` reads as R0 ← memory[`7D8`]. `60F00001` reads as R0 ← PC + 4 and PC ← PC + 4 × 1.
