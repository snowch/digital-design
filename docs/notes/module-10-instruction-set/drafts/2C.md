explanation: K and J together say what an instruction does: its kind and its job. The bits that choose what an instruction does are called its **opcode** (that is what books call them). In the course's layout, the opcode is digits 7 and 6.

Of the 256 pairs of K and J, 37 are instructions whatever the constant is. Two more pairs, kind 8's jobs 2 and 3, are instructions only when the constant is 0 to 4.

The packed layout gives longer constants: 16 bits for a constant job, a load, a store or a branch, and 20 bits for a call or a jump.

It pays with selectors. Y sits in digit 3, 4 or 5 by kind, so the register file's write address needs a selector chosen by K. The constant is 12, 16 or 20 bits, so the widening needs a selector too.

On the course's machine the longer branch buys nothing. The ROM holds 256 instructions, and a 12-bit constant reaches 2047 instructions forward. Every address fits in 12 bits.

Only the jobs' numbers would gain.

generalisation: Every instruction set chooses an encoding: how each instruction becomes bits.

One layout keeps the decoder and the register file simple, and a person can read a word.

Several layouts give longer constants, but they pay with selectors and with words that are harder to read.

The course's machine chose one layout of whole digits, for people to read.

The digits left unused are not all waste. Kinds 9 to F are free. A new instruction takes a free kind, as the call through a register took kind 9 in your copy.

c2Task: Write the module `ydigit`. It takes IR as input, 32 bits. It outputs WA, 4 bits: the register file's write address for a word in the packed layout.

WA is chosen by the kind:

- For kinds 2 and 3 (constant job and load), WA is digit 4, which is `IR[19:16]`.
- For kind 6 (call), WA is digit 5, which is `IR[23:20]`.
- For every other kind, WA is digit 3, which is `IR[15:12]`.

The starting point uses only the last rule: `assign WA = IR[15:12];`. That is the course's layout.

You may use `module`, ports, `logic`, multi-bit signals, `assign`, selects, `always_comb`, and `case`. The test suite has 11 tests. The starting point fails 6 tests. The first failing test is `22120064`.

c2Hints.1: The idea: WA is a selector, and the kind, `IR[31:28]`, chooses which digit it passes.

c2Hints.2: A common mistake: forgetting kind 3. A load writes register Y too, and leaves B unused, so its Y moves as a constant job's does.

c2Hints.3: A smaller example: inside `always_comb`, `case (IR[31:28])` with the arm `4'h6: WA = IR[23:20];`.

c2Hints.4: Part of the answer: `4'h2: WA = IR[19:16];`, `4'h3: WA = IR[19:16];` and `default: WA = IR[15:12];`.

```
  endcase
```
