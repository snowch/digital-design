p1Question: How many edges does set if take in your copy of Module 9's machine?

p1Explain: Set if takes 4 edges: FETCH, READ, ALU, WRITE, as a register job. The decoder sets WRITEY and not MEM or CALL, so the controller goes from READ to ALU, then to WRITE. The controller does not change. At the WRITE edge the condition is worked out again. HA, HB and the IR keep their words from READ, so the ALU's flags and MET are the same as at ALU. Register Y takes MET as a word.
