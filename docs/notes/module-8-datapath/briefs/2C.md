# Brief 2C: lesson `constants` (Module 8, lesson 2), the end

Read `00-module.md` (the shared fact sheet) first; it applies here. Use **instruction** and
**datapath** plainly. This lesson introduces no term.

Keys to write: `writeConstantsLead`, `c2Task`, `c2Hints.1` to `c2Hints.5`, `reflection`,
`modelVsReality`.

## writeConstantsLead (one sentence)

Add the selector to the datapath's text, so the ALU's B input can take the constant.

## c2Task (about 150 words, a list allowed)

1. Your module, `constants`, has inputs CLK, IR (32 bits), WRITEY and BCONST, and one output,
   RESULT (64 bits).
2. The starting text uses the course's register file as in the last lesson's challenge; works out
   WIDE as the widening challenge does, from `IR[11:0]`; uses the ALU with its B input from ALUB;
   and has `assign ALUB = QB;`.
3. Replace that assignment with a selector: ALUB is QB when BCONST is 0, and WIDE when BCONST is 1.
4. You may use what the widening challenge used, plus one module used inside another.
5. The tests are 8 steps. R1 starts at -184, R2 at -250, and every other register at X. The steps
   set IR, WRITEY, BCONST and CLK and check RESULT. One step changes IR and BCONST while the clock
   is high.

## c2Hints (five rungs)

1. ALUB takes one of two words, and BCONST chooses which.
2. A common mistake: choosing by `IR[11]`, the constant's bit 11, instead of BCONST.
3. The widening chose between two words with `case (C[11])`. This choice is the same shape.
4. Start with `always_comb`, `case (BCONST)` and the line `1'b0: ALUB = QB;`.
5. The whole answer: replace `assign ALUB = QB;` with

```
always_comb
  case (BCONST)
    1'b0: ALUB = QB;
    1'b1: ALUB = WIDE;
  endcase
```

## reflection (about 90 words)

1. A constant rides in the instruction's last three digits. "widen" makes it 64 bits by copying
   bit 11, and a selector set by BCONST gives it to the ALU's B input.
2. So far you put each instruction on IR by hand, and set WRITEY and BCONST yourself.
3. The shop's machine must do its jobs one after another, on its own.
4. End on the question: where does the machine keep its list of instructions, and how does it
   know which one comes next?

## modelVsReality (about 90 words)

1. The widening is wires and no gates. In a chip, bit 11's wire drives its own bit and the 52 bits
   above it, and a wire with many inputs to drive takes longer to change.
2. The selector is 64 two-way selectors. The model settles them in steps; in a chip they add delay
   on the way to the ALU.
3. You set BCONST by hand here. In the course's machine, a block works it out from K, as it does
   WRITEY; a later module builds that block's insides.
