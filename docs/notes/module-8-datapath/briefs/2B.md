# Brief 2B: lesson `constants` (Module 8, lesson 2), the middle

Read `00-module.md` (the shared fact sheet) first; it applies here. Use **instruction** and
**datapath** plainly (an earlier lesson introduced them). This lesson introduces no term.

Keys to write: `construction`, `writeWidenLead`, `c1Task`, `c1Hints.1` to `c1Hints.5`,
`constantsFaultsLead`, `constantsFaultsAfter`, `explanation`, `generalisation`, `hourLead`,
`hourAfter`.

## construction (about 70 words)

1. In text, the widening is an `always_comb` with a `case` on `C[11]`, choosing between two
   concatenations: `{52'h0, C}` when bit 11 is 0, and `{52'hFFFFFFFFFFFFF, C}` when it is 1.
2. `52'hFFFFFFFFFFFFF` is 52 bits of 1: thirteen hexadecimal digits F.
3. The challenge below writes it.

## writeWidenLead (one sentence)

Write the widening: 12 bits in, 64 bits out, the same number when read signed.

## c1Task (about 110 words, a list allowed)

1. Write a module called `widen`. Input: C, 12 bits. Output: W, 64 bits.
2. W's low 12 bits are C. Each bit above them is a copy of C's bit 11.
3. The starting text has `assign W = {52'h0, C};`, which is right only when bit 11 is 0. Replace
   it.
4. You may use what the digits challenge used, plus concatenation, `always_comb` and `case`.
5. There are 6 tests, each named by C in hexadecimal: `000`, `064`, `7FF`, `800`, `FFF` and `F06`.

## c1Hints (five rungs)

1. W's top 52 bits are all equal to `C[11]`.
2. A common mistake: filling the top with 0s. That is right for 0 to 2047 and wrong for every
   negative constant: `F06` becomes 3846.
3. A smaller example, 4 bits to 8: `case (C[3])` with `1'b0: W = {4'h0, C};` and
   `1'b1: W = {4'hF, C};`.
4. Start with `always_comb`, then `case (C[11])` and the line `1'b0: W = {52'h0, C};`. Add the line
   for 1 and `endcase`.
5. The whole answer:

```
always_comb
  case (C[11])
    1'b0: W = {52'h0, C};
    1'b1: W = {52'hFFFFFFFFFFFFF, C};
  endcase
```

## constantsFaultsLead (above the figure; about 100 words)

1. Two faults to choose.
2. "The copied bit held at 0": inside "widen", the wire that copies bit 11 into the 52 bits above
   it is 0. C's own 12 wires still arrive.
3. "BCONST held at 0": the selector always chooses QB.
4. Two instructions: `25003F06` (R3 ← -250) and `22103064` (R3 ← R1 + 100). R1 holds -184, R2
   holds -250, and R0 is X.
5. Choose a fault and an instruction and press "Clock edge". Say first what R3 will hold.

## constantsFaultsAfter (below the figure; about 100 words, a list allowed)

1. "The copied bit held at 0": `25003F06` writes 3846 into R3, which is `F06` read unsigned.
   `22103064` still writes -84: 100's bit 11 is 0, so the fault changes nothing for it. No
   constant from 0 to 2047 can show this fault.
2. "BCONST held at 0": both instructions write X. The ALU's B takes QB, the word of the register
   the B digit names. Both instructions have B digit 0, so QB is R0, which nothing has written.
   An X in gives an X out.

## explanation (about 110 words)

1. The selector carries out a choice the kind makes: a register job reads register B, a constant
   job reads the constant. BCONST is a second control signal, set by hand here.
2. Copying bit 11 keeps the number. `FFF` and `FFFFFFFFFFFFFFFF` both read -1, and `7FF` and
   `00000000000007FF` both read 2047.
3. The A input still comes from register A. Only B changes.
4. The constant's digits are wires to "widen", as the register digits are wires to the register
   file.

## generalisation (about 80 words)

1. Every job takes a constant: AND, XOR, add, subtract, OR and copy B. Count up and count down
   ignore it.
2. 12 bits hold -2048 to 2047. A larger number takes two instructions.

## hourLead (above the figure; about 70 words)

1. An hour has 3600 seconds, too many for a constant.
2. `25006708` is R6 ← 1800. `12666000` is R6 ← R6 + R6, a register job (BCONST 0).
3. Choose the first, press "Clock edge", then choose the second and press it again.

## hourAfter (below the figure; one or two sentences)

R6 holds 1800, then 3600: two instructions, two edges.
