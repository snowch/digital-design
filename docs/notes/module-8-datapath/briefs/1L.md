# Brief 1L: lesson `instructions` (Module 8, lesson 1), the labels

Read `00-module.md` (the shared fact sheet) first; it applies here, except that a label is short
and need not be a sentence. This lesson introduces **instruction** and **datapath**; labels may use
both, not in bold.

Keys to write, each one line:

- `title`: the lesson's title, as a question a learner would ask. It is about where the ALU's two
  words come from and how one word says what the ALU and the register file do. At most 9 words.
- `objectives.1` to `objectives.4`: what the learner can do after the lesson, each starting with a
  verb, at most 12 words: read an instruction's digits as the fields K, J, A, B, Y and C; predict
  what one edge of the register jobs' datapath writes; write the digits module with part selects;
  write the datapath as text from the course's register file and ALU.
- `titles.question`, `titles.motivation`, `titles.prediction`, `titles.investigation`,
  `titles.construction`, `titles.failureExperiment`, `titles.explanation`,
  `titles.generalisation`, `titles.challenge`, `titles.reflection`: section headings, each a
  label of 2 to 6 words that tells somebody scanning the page what the section holds. The
  sections hold: (question) where the ALU's words come from; (motivation) the office's readings
  and why each edge needs its own word; (prediction) what one edge writes; (investigation) the
  register jobs' datapath to clock; (construction) the digits written as text; (failureExperiment)
  a digit's wires held at 0; (explanation) one edge, one instruction, and WRITEY; (generalisation)
  every register job is the same circuit; (challenge) the datapath written as text;
  (reflection) what the lesson built and the next question.
- `challengeTitles.c1`: the digits challenge (the course's titles look like "Adder, written").
- `challengeTitles.c2`: the register jobs' datapath challenge, in the same style.
- `captions.predictDifference`: predict what R3 holds after one edge, then check.
- `captions.jobs`: choose an instruction and clock the datapath.
- `captions.writeDigits`: write the digits module and run the tests.
- `captions.jobsFaults`: choose a fault and an instruction, and clock it.
- `captions.writeJobs`: write the datapath and run the tests.
- `options.p1Sum`: the answer -434. `options.p1Difference`: the answer 66. `options.p1Other`: the
  answer -66. Each is the number alone.
- `instructions.subtract`, `instructions.add`, `instructions.copy`, `instructions.countUp`,
  `instructions.noWrite`: the five choices of instruction. Each is the word in backticks, a
  colon, then the transfer: `13123000`: R3 ← R1 - R2; `12123000`: R3 ← R1 + R2; `15024000`:
  R4 ← R2; `16101000`: R1 ← R1 + 1; and for noWrite, `13123000` with WRITEY at 0 (say so in a few
  words after the transfer).
- `faults.yLow`: the fault that holds the Y digit's four wires at 0. `faults.op0Low`: the fault that
  holds OP0 at 0. Each at most 6 words.
