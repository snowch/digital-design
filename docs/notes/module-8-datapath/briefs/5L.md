# Brief 5L: lesson `branches` (Module 8, lesson 5), the labels

Read `00-module.md` (the shared fact sheet) first; it applies here, except that a label is short
and need not be a sentence. PC, "program counter", "fetch" and "branch" are allowed.

Keys to write, each one line. Objectives and captions end with a full stop; headings do not.
Headings start with a capital letter and are short labels, 2 to 6 words, like "When 16 bits run
out" or "The carry, step by step", never the descriptions below. Never use "your".

- `title`: a question a learner would ask, ending in "?", at most 9 words: how a program chooses
  what to run next.
- `objectives.1` to `objectives.4`, each starting with a verb, at most 12 words: predict whether a
  branch is taken from the ALU's flags; step one edge of the whole datapath; write the condition
  block from the job digit and the flags; complete the datapath's text with the next PC.
- Ten headings, `titles.question`, `titles.motivation`, `titles.prediction`,
  `titles.investigation`, `titles.construction`, `titles.failureExperiment`,
  `titles.explanation`, `titles.generalisation`, `titles.challenge`, `titles.reflection`. They
  hold: in order no longer; the branch and its conditions; which room is colder; a loop that adds;
  the condition written as text; MET held at 1 and at 0; one edge, step by step; calls and jumps;
  the next PC written as text; the whole datapath and the next question.
- `challengeTitles.c1`: the condition block, in the style "Memory checks, written".
  `challengeTitles.c2`: the whole datapath, same style.
- `captions.predictBranch`: predict PC after the branch, then check.
  `captions.sum`: run the loop edge by edge.
  `captions.writeCondition`: write the condition block and run the tests.
  `captions.branchFaults`: choose a fault and run the loop.
  `captions.oneInstruction`: clock one edge and step through it.
  `captions.call`: run the call and the jump back.
  `captions.writeNext`: complete the text and run the tests.
- `options.p1Next`: PC is `00C`, not taken. `options.p1Target`: PC is `010`, taken. Each at most 6
  words.
- `faults.metHigh`: "MET held at 1". `faults.metLow`: "MET held at 0".
