# Brief 5A: lesson `branches` (Module 8, lesson 5), first half

Read `00-module.md` (the shared fact sheet) first; it applies here, with two changes: PC,
"program counter" and "fetch" are allowed (an earlier lesson introduced them), and this lesson
introduces **branch**, so "branch" is allowed from here on and set in bold where the brief says.
The machine so far: PC names the next instruction; the ROM gives it on the bus IR; a closed
"decoder" works out the control signals from K and J; a "stop logic" stops the machine at `stop`
or at anything it cannot run; loads and stores reach the RAM and the shop's devices: room A's
sensor at `7D8`, room B's at `7E0`, the display at `7C0`. The rooms read -184 and -250.

Keys to write: `question`, `motivation`, `prediction`, `p1Question`, `p1Explain`, `sumLead`,
`sumAfter`.

## question (about 70 words)

1. Every program so far runs its instructions in order, from `000` to its `stop`.
2. The office wants the lower of the two rooms' readings on the display. Which instruction runs
   next must depend on what the program finds.
3. End on the question: how can the next instruction depend on a comparison?

## motivation (about 110 words, a list allowed)

1. A **branch** is an instruction that chooses the next instruction: kind 5. Introduce the term
   here, plain meaning first.
2. It compares RA with RB: the ALU works out RA - RB, and its flags say how they compare. If the
   condition holds, PC ← PC + 4c; otherwise PC ← PC + 4. c counts instructions from the branch
   itself: c = 1 is the next instruction, c = -3 the third one back.
3. The job digit chooses the condition: 0 always, 1 never, 2 A equals B, 3 A differs from B, 4 A
   less than B read unsigned, 5 not less unsigned, 6 less signed, 7 not less signed.
4. Equal is ZERO at 1. Less, read unsigned, is COUT at 0. Less, read signed, is MINUS XOR OVER at 1
   (Module 7).

## prediction (above the figure; about 130 words, a list allowed)

1. The program is the office's question, which room is colder:
   - `000` `380027D8`: R2 ← memory[`7D8`] (room A)
   - `004` `380037E0`: R3 ← memory[`7E0`] (room B)
   - `008` `56230002`: if R2 < R3, read signed, PC ← PC + 4 × 2, which is `010`
   - `00C` `15032000`: R2 ← R3
   - `010` `480207C0`: memory[`7C0`] ← R2 (the display)
   - `014` `84000000`: stop
2. The figure has made two edges: R2 holds -184 and R3 -250, and PC is `008`, the branch.
3. Two new blocks: "condition" gives MET, 1 when the job's condition holds; "next PC" works out
   NEXT, the word PC takes at the next edge. The decoder's output BRANCH says the instruction is
   a branch.
4. Choose an answer and press "Check my prediction". The "Clock edge" button appears after.

## p1Question (one or two sentences)

PC is `008`, the branch, with R2 at -184 and R3 at -250. What is PC after the next edge?

## p1Explain (about 90 words)

1. PC is `00C`: the branch is not taken.
2. The ALU works out R2 - R3: -184 - (-250) = 66. MINUS is 0 and OVER is 0, so MINUS XOR OVER is
   0: R2 is not less than R3.
3. MET is 0, so NEXT is PC + 4.
4. The program goes on to `00C`, where R2 takes room B's -250, and the display shows -250. Room B
   is colder, at -25.0 degrees.
5. `010` is where PC would go if R2 were less than R3.

## sumLead (above the investigation's figure; about 140 words, a list allowed)

1. This program adds 5 + 4 + 3 + 2 + 1, with a branch that goes back:
   - `000` R1 ← 5
   - `004` R2 ← 0
   - `008` R0 ← 0
   - `00C` `12212000`: R2 ← R2 + R1
   - `010` `17101000`: R1 ← R1 - 1 (count down)
   - `014` `53100FFE`: if R1 differs from R0, PC ← PC + 4 × -2, which is `00C`
   - `018` memory[`7C0`] ← R2
   - `01C` stop
2. The constant `FFE` is -2, read signed: the target is two instructions back.
3. The table "Buses" shows RESULT, PC4 and NEXT. Press "Clock edge" to watch NEXT at each branch,
   or "Run until it stops".

## sumAfter (below the figure; about 70 words)

1. The program stops after 20 edges, and the display shows 15.
2. The branch is taken four times, while R1 is 4, 3, 2 and 1. When R1 reaches 0, it equals R0, the
   branch is not taken, and the program goes on to `018`.
3. A branch writes no register: the decoder sets WRITEY to 0 for it.
