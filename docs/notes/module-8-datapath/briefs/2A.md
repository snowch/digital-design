# Brief 2A: lesson `constants` (Module 8, lesson 2), first half

Read `00-module.md` (the shared fact sheet) first; it applies here. The lesson `instructions`
came before this one and introduced **instruction** and **datapath**; use both plainly. This
lesson introduces no term.

Keys to write: `question`, `motivation`, `prediction`, `p1Question`, `p1Explain`,
`constantsLead`, `constantsAfter`.

## question (about 80 words)

1. Every instruction in the last lesson worked on registers alone, and R1 and R2 held words the
   lesson gave them.
2. The shop needs numbers that no register holds: 100 to add to a reading, a mask that keeps a
   reading's low 8 bits, the limit -250 itself.
3. In the last lesson, the instruction's last three hexadecimal digits, C, went nowhere. They are
   12 bits.
4. End on the question: how do 12 bits inside the instruction become a 64-bit word the ALU can take
   as B?

## motivation (about 80 words)

1. Kind 2 is a constant job: `RY ← RA job c`, where c is the constant: the instruction's last 12
   bits, read signed, a number from -2048 to 2047.
2. `22103064` reads: kind 2, job 2 (add), A is R1, B is 0 and unused, Y is R3, and the constant
   `064`, which is 100. It is `R3 ← R1 + 100`.
3. The ALU's B input takes 64 bits, and the constant is 12. A negative constant must still be the
   same number at 64 bits.

## prediction (above the figure; about 90 words)

1. The figure adds two parts to the last lesson's datapath. The block "widen" turns C into a 64-bit
   word, the bus WIDE. A word selector, named pickB, gives the ALU's B input, the bus ALUB, either
   QB or WIDE.
2. BCONST is the selector's select input, set by hand here: 1 chooses WIDE, 0 chooses QB.
3. IR carries `25003F06`: kind 2, job 5 (copy B), Y is R3, and the constant digits `F06`. It is
   `R3 ← c`. WRITEY and BCONST are both 1.
4. Choose an answer and press "Check my prediction". The "Clock edge" button appears after.

## p1Question (one or two sentences)

`25003F06` is on IR, and its constant digits are `F06`. After one rising edge, what does R3 hold,
read signed?

## p1Explain (about 80 words)

1. R3 holds -250.
2. `F06` is the 12 bits `1111 0000 0110`. Read signed, bit 11 is worth -2048, and the word is
   -250. Read unsigned, it is 3846.
3. The widening copies bit 11, a 1, into all 52 bits above it. WIDE is `FFFFFFFFFFFFFF06`, which
   read signed is -250: the same number.
4. Copy B gives the ALU's B as its Y, so the edge writes -250 into R3.
5. X would mean the edge wrote an unknown word; it does not.

## constantsLead (above the investigation's figure; about 140 words, a list allowed)

1. "widen" holds no gates. Its 64 outputs are C's 12 wires and, 52 times over, the wire of C's
   bit 11.
2. pickB is Module 3's word selector at 64 bits, its select input BCONST.
3. The list of instructions, each with WRITEY and BCONST set for you (you can press their pins
   too):
   - `25003F06`: R3 ← -250
   - `22103064`: R3 ← R1 + 100
   - `201030FF`: R3 ← R1 AND `FF` (job 0)
   - `250047FF`: R4 ← 2047
   - `25004800`: R4 ← -2048
   - `12123000`: R3 ← R1 + R2, a register job, with BCONST at 0
4. R1 holds -184 and R2 -250. The table "Buses" shows QB, WIDE, ALUB and RESULT; the table
   "Registers" shows R1 to R4.

## constantsAfter (below the figure; about 100 words)

Each from the start:

1. The edges write -250, -84, 72, 2047, -2048 and -434.
2. 72 is -184's low byte, `48`: AND with `FF` keeps a word's low 8 bits.
3. 2047 is `7FF`, whose bit 11 is 0, so WIDE is `00000000000007FF`. -2048 is `800`, and WIDE is
   `FFFFFFFFFFFFF800`. These are the largest and the smallest constants.
4. With BCONST at 0, ALUB is QB, and the register job reads R2 as in the last lesson.
