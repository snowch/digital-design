# Brief 1B: lesson `instructions` (Module 8, lesson 1), the middle

Read `00-module.md` (the shared fact sheet) first; it applies here. This lesson introduces
**instruction** and **datapath**; brief 1A introduces them in the sections before these, so here
they are used plainly, not in bold.

Keys to write: `construction`, `writeDigitsLead`, `c1Task`, `c1Hints.1` to `c1Hints.5`,
`jobsFaultsLead`, `jobsFaultsAfter`, `explanation`, `generalisation`.

## construction (about 60 words)

1. The block "digits" is only wires. In SystemVerilog, a part select such as `IR[31:28]` names
   some of a bus's wires, and `assign K = IR[31:28];` gives K the instruction's leftmost digit.
2. Bit 31 is IR's leftmost bit, and bit 0 its rightmost.
3. The challenge below writes the digits module.

## writeDigitsLead (one sentence)

Write the module that splits an instruction into its six fields.

## c1Task (the task; about 120 words, a list allowed)

1. Write a module called `digits`. Input: IR, 32 bits. Outputs: K, J, A, B and Y, 4 bits each, and
   C, 12 bits.
2. Each output is its field's bits of IR: K is bits 31 to 28, J 27 to 24, A 23 to 20, B 19 to 16,
   Y 15 to 12, and C 11 to 0.
3. The starting text gives the module's first lines, K's assignment, and the other five outputs
   set to 0. Replace those five.
4. You may use `module`, ports, `logic`, multi-bit signals, `assign` and selects.
5. There are 9 tests. Each gives IR one 32-bit word, is named by that word's eight hexadecimal
   digits, and checks all six outputs. One of them, `FEDCBA98`, has every digit different.

## c1Hints (five rungs: the idea, a common mistake, a smaller example, part of the answer, the whole answer)

1. Each field is a range of IR's bits. No gates are needed: each output is wires.
2. A common mistake: counting from the left. Bit 31 is the leftmost bit, so `IR[3:0]` is the
   rightmost digit, not K.
3. `assign J = IR[27:24];` gives J the second digit from the left.
4. A is `IR[23:20]`, B is `IR[19:16]` and Y is `IR[15:12]`.
5. The whole answer, as a code block:

```
assign K = IR[31:28];
assign J = IR[27:24];
assign A = IR[23:20];
assign B = IR[19:16];
assign Y = IR[15:12];
assign C = IR[11:0];
```

## jobsFaultsLead (above the figure; about 110 words)

1. The same datapath, with two faults to choose. Each holds a group of wires at 0.
2. "The Y digit held at 0": the four wires from the digits block to the register file's WA are 0,
   whatever the instruction says.
3. "OP0 held at 0": the wire from J's bit 0 to the ALU's OP0 is 0.
4. Two instructions to choose: `13123000` (R3 ← R1 - R2) and `12123000` (R3 ← R1 + R2). R1 holds
   -184 and R2 holds -250, as before. The table shows R0 to R3.
5. Choose a fault and an instruction, then press "Clock edge". Before you press, say which
   register the edge will write, and what it will write.

## jobsFaultsAfter (below the figure; about 100 words, a list allowed)

1. "The Y digit held at 0": every result goes into R0. `13123000` writes 66 into R0, and
   `12123000` writes -434 into R0. R3 stays X.
2. "OP0 held at 0": subtract's code `011` becomes `010`, which is add. `13123000` writes -434 into
   R3, the same as `12123000`.
3. Add's code already has OP0 at 0, so `12123000` still writes -434. That instruction cannot show
   this fault.
4. A held digit changes which register an instruction names, or which job it chooses.

## explanation (about 130 words)

1. One edge does one instruction. The digits are wires to the register file and the ALU. These
   work out RESULT before the edge, and the edge writes it.
2. No part moves a field. A, B and Y are the register file's two read addresses and its write
   address, and J's low three bits are the ALU's code. The layout puts each field where its wires
   go.
3. WRITEY is a control signal: a bit that tells a part what to do at the next edge. Here you set
   it by hand.
4. Later lessons add instructions that write no register. For them WRITEY is 0.
5. In the course's machine, a block works out WRITEY and the other control signals from K and J.
   A later module builds that block's insides. (Do not name the block.)

## generalisation (about 100 words)

1. Every register job is this one circuit. There are 8 jobs and 16 choices for each of A, B and
   Y: 32,768 register jobs, and one datapath does them all.
2. Count up and count down read only A, and copy B reads only B. The other register's digit is
   ignored, and the course writes 0 there.
3. Y may name a register that A or B also names. `R1 ← R1 + 1` reads R1 before the edge and writes
   it at the edge, as every register transfer does.
4. The machine treats all 16 registers alike: R0 is a register like any other.
