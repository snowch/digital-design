# Brief 4L: lesson `memory-access` (Module 8, lesson 4), the labels

Read `00-module.md` (the shared fact sheet) first; it applies here, except that a label is short
and need not be a sentence. PC, "program counter" and "fetch" are allowed.

Keys to write, each one line. Objectives and captions end with a full stop; headings do not.
Headings start with a capital letter and are short labels, 2 to 6 words, like "When 16 bits run
out" or "The carry, step by step", never the descriptions below.

- `title`: a question a learner would ask, ending in "?", at most 9 words: how an instruction
  reads or writes a word in memory.
- `objectives.1` to `objectives.4`, each starting with a verb, at most 12 words: read a load's and
  a store's digits and their address; predict what a load writes into a register; write the
  checks the memory makes on a load or store; complete the datapath's text with its two new
  selectors.
- Ten headings, `titles.question`, `titles.motivation`, `titles.prediction`,
  `titles.investigation`, `titles.construction`, `titles.failureExperiment`,
  `titles.explanation`, `titles.generalisation`, `titles.challenge`, `titles.reflection`. They
  hold: words at addresses; loads and stores; a load from a sensor; the margin shown on the
  display; the memory's checks written as text; LOAD and STORE broken; one memory, two reads;
  bytes, the RAM and the devices; the datapath's text completed; what the machine can do now and
  the next question.
- `challengeTitles.c1`: the memory checks, in the style "Fetch checks, written".
  `challengeTitles.c2`: the datapath with loads and stores, same style.
- `captions.predictLoad`: predict what R2 holds after the next edge, then check.
  `captions.showMargin`: run the program and watch the memory.
  `captions.writeMemcheck`: write the checks and run the tests.
  `captions.memoryFaults`: choose a fault and run the program.
  `captions.writeMemory`: complete the text and run the tests.
- `options.p1Reading`: -184. `options.p1Address`: 2008. `options.p1Unknown`: X. Each the value
  alone.
- `faults.loadLow`: "LOAD held at 0". `faults.storeHigh`: "STORE held at 1".
