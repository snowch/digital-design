p2Question: The figure gives one edge with RST at 1, then GO at 1 for one edge. What is S, the state's code, after it?

p2Explain: S is `0000`. A reset loaded all zeros, but `0000` is not a state: no state's line is 1. No row applies, so every next-state bit is 0, and the register stays `0000` at every edge. The controller never starts.

Codes in which each state has a single 1, in its own bit, are called **one-hot**. One-hot codes need a reset that loads a state's code. The course's reset loads zeros, which is why the investigation gave IDLE `000`.
