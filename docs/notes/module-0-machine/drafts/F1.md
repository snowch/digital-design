motivation: The machine does not decide anything by itself. It runs a program: a list of instructions, numbered from 1, each saying one small thing to do. It runs one instruction at a time, in order, unless an instruction tells it to go to another instruction.

The machine keeps sixteen numbers, named R0 to R15. An instruction can set one of them, read a room, show a number on the display, or set the lamps.

The display shows how much warmer room A is than room B, in tenths of a degree. Each room stays at its own set temperature, and the gap between them is normally small. The shop treats a gap of 10.0 degrees or more as a sign that something is wrong, and wants GAP_ALARM to light.

The shop's program has 9 instructions:

1. R1 becomes room A's reading
2. R2 becomes room B's reading
3. R3 becomes R1 minus R2
4. Show R3 on the display
5. R4 becomes 100
6. If R3 is less than R4, go to instruction 9
7. R5 becomes 4
8. Set the lamps from R5
9. Stop

Running these instructions is all the machine does. The next figure asks you which of them it runs.
shopAfter: Room A at -18.4 degrees sends -184. Room B, the colder room at -25.0 degrees, sends -250. Each number is in tenths of a degree.
runAfter: With the rooms at -184 and -250, each instruction changed at most one thing. R1 became -184, R2 -250, R3 66, R4 100, then the display showed 66. Instructions 7 and 8 did not run and GAP_ALARM stayed dark, because 66 is less than 100.
runAfterChanged: With room A at -50, R3 becomes 200. 200 is not less than 100, so instruction 6 does not go to instruction 9. Instructions 7 and 8 run: R5 becomes 4 and GAP_ALARM lights. The program did not change. Only a reading changed, and the same instructions gave a different display and a lit lamp.
explanation: Where are the instructions while the machine runs them? In its memory. The machine keeps each instruction as one number there. R0 to R15 are kept apart from the memory, inside the machine. The rooms' readings come in from the sensors when an instruction reads them.

To run an instruction, the machine reads that instruction's number from memory, does what it says, and moves to the next instruction, unless the instruction says to go elsewhere.

Instruction 5, "R4 becomes 100", is kept as 620773476. The 100 is part of that number: change instruction 5's number to 101 and it is kept as 620773477. So changing the limit, as you did in the construction, changed one kept number. Not every part of an instruction is kept as written: instruction 6 keeps "go to instruction 9" as 3, the count of instructions from instruction 6 to instruction 9.
keptLead: The figure adds a column, "Kept as": the number the machine keeps each instruction as. A box shows instruction 5's number, which starts at 100. Change instruction 5's number, for example to 101, and watch instruction 5's row in "Kept as". Change a room's reading too. Run the program after each change.
keptAfter: Changing instruction 5's number changed one number in "Kept as": instruction 5's. With 101 it is 620773477. Changing a room's reading changed no number in "Kept as". A reading comes in while the program runs; the instructions stay as they are.
generalisation: This machine did four things. It read numbers from the rooms. It kept sixteen numbers, R0 to R15. It ran instructions of the program one at a time. It set the display and the lamps.

The same program with different readings gave different displays: 66, 200, -134. A different job needs a different program: different numbers in the machine's memory, put there before the program runs. The machine itself does not change between jobs.

Every computer, from this one to a phone, reads from outside, keeps numbers, runs programs and sets things outside. A phone runs many programs at once and does several things at once, but each program's instructions still take effect in their order.
modelVsReality: The figures on this page run the machine in the course's simulator. Every number a figure shows comes from the simulator and the program it runs: the numbers it keeps, the display, the lamps, and the number each instruction is kept as. The degrees in the text are the machine's tenths written as degrees: -184 tenths is -18.4 degrees. The machine works in tenths only.

Each press of "Run one instruction" runs one instruction. A real computer runs many millions of instructions a second. You see one instruction at a time here because the course is about how each instruction works.

The rooms' readings here are numbers you type. A real sensor's reading changes on its own. A real shop's computer would also run instructions for many other jobs. This machine runs one program, nine instructions long, and stops.

The gap check is a teaching example. A real cold-store watch checks each room against its own safe limits as well; a difference alone cannot say which room, or which part, is at fault.
