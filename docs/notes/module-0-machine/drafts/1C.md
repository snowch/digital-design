generalisation: This machine did four things. It read numbers from the rooms. It kept sixteen numbers, R0 to R15. It ran instructions of the program one at a time. It set the display and the lamps.

The same program with different readings gave different displays: 66, 200, -134. A different job needs a different program: different numbers in the machine's memory, put there before the program runs. The machine itself does not change between jobs.

Every computer, from this one to a phone, reads from outside, keeps numbers, runs programs and sets things outside. A phone runs many programs at once and does several things at once, but each program's instructions still take effect in their order.

reflection: A computer runs a program. The instructions are kept as numbers in its memory. It runs them one at a time.

The machine follows the instructions exactly. The program decides what the display means. When the program is wrong, the machine is wrong with it. The machine is a box. It runs instructions. But what is inside the box, and how does it work out 66?
modelVsReality: The figures on this page run the machine in the course's simulator. Every number a figure shows comes from the simulator and the program it runs: the numbers it keeps, the display, the lamps, and the number each instruction is kept as. The degrees in the text are the machine's tenths written as degrees: -184 tenths is -18.4 degrees. The machine works in tenths only.

Each press of "Run one instruction" runs one instruction. A real computer runs many millions of instructions a second. You see one instruction at a time here because the course is about how each instruction works.

The rooms' readings here are numbers you type. A real sensor's reading changes on its own. A real shop's computer would also run instructions for many other jobs. This machine runs one program, nine instructions long, and stops.

The gap check is a teaching example. A real cold-store watch checks each room against its own safe limits as well; a difference alone cannot say which room, or which part, is at fault.
