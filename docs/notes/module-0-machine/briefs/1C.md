# Brief 1C: lesson 0.1: generalisation, challenge, reflection, the model note

Read `00-module.md` (this folder) and `docs/style.md` first. Write these keys, in this order.

## generalisation (three short paragraphs, under 150 wds)

- Everything the machine did this lesson was one of four things: it read numbers from outside
  (the rooms), it kept numbers (R0 to R15), it ran lines one at a time, and it set things outside
  (the display, the lamps).
- The same program with different readings gave a different display: 66, 200, -134.
- A different program on the same machine would do a different job. The machine does not change;
  the numbers in its memory do.
- Every computer works this way, from this one to a phone: it reads, keeps numbers, runs lines
  of a program one at a time, and sets things outside. The parts and the speed differ.

## c2Task (one paragraph, under 90 wds)

- Room A reads -100 (-10.0 degrees) and room B reads -250.
- Type the number the display shows when the program stops, and choose whether CLASH is lit or
  dark then.
- The tests run the machine with these readings and compare its display and its lamp with your
  answers. There are 2 tests.

## c2Hints.1 to c2Hints.5 (in this order)

1. The concept: the display shows R3, which line 3 works out as room A's reading minus room B's.
2. The mistake: subtracting a negative number. -100 minus -250 is -100 plus 250.
3. A smaller example: with -184 and -250, R3 is 66 and CLASH stays dark, because 66 is less than
   100.
4. Part of the answer: R3 is 150.
5. The answer: the display shows 150, and CLASH is lit, because 150 is not less than 100.

## reflection (two short paragraphs, under 110 wds)

- A computer runs a program: lines kept as numbers in its memory, run one at a time. It reads the
  rooms, keeps sixteen numbers, and sets the display and the lamps.
- It follows the lines exactly. The program decides what the display means; when the program is
  wrong, the machine is wrong with it.
- End with the question the next lesson answers: the machine is a box that runs lines. What is
  inside the box, and how does it work out 66?

## modelVsReality (three short paragraphs, under 150 wds)

- The machine on this page runs in the course's simulator. Each press runs one line, and every
  number on the page is read from the simulator.
- A real computer runs many millions of lines a second. Here you see one line at a time, because
  the course is about how each line works.
- The rooms' readings are numbers you type. A real sensor's reading changes on its own.
- A real shop's computer would also run lines for many other jobs, and for itself. This machine
  runs one program, nine lines long, and stops.
