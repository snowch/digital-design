# Brief 1B: lesson 0.1: construction, failure experiment, explanation

Read `00-module.md` (this folder) and `docs/style.md` first. Write these keys, in this order.

## construction (one paragraph, under 70 wds)

- The shop's manager wants CLASH to light sooner: when room A is 5.0 degrees or more warmer than
  room B, not 10.0.
- Line 5 sets R4 to 100, and line 6 compares the gap in R3 with R4. So 100 is the limit, in
  tenths of a degree.
- You change the program by changing one number in one line.

## limitLead (one sentence, a lead above the challenge)

- The figure in the investigation runs the program with 100; you can try readings there first.

## c1Task (two short paragraphs, under 110 wds)

- Type the number line 5 should give R4 so that CLASH lights when room A is 5.0 degrees or more
  warmer than room B, and stays dark when the gap is less.
- The tests run the machine with your number in line 5 and room B at -250, for four readings of
  room A: -184 (a gap of 66), -190 (60), -200 (50) and -201 (49).
- CLASH must light for the gaps 66, 60 and 50, and stay dark for 49.
- There are 4 tests. The box starts at 100, the program as it is; with 100, three tests fail.

## c1Hints.1 to c1Hints.5 (one or two sentences each; in this order)

1. The concept: line 6 goes to line 9, past the lamp, when R3 is less than R4. CLASH lights only
   when R3 is not less than R4.
2. The mistake: a gap exactly equal to the limit is not less than it, so the lamp lights. Think
   about the gap of 50.
3. A smaller example: with 100 in line 5, a gap of 100 lights CLASH and a gap of 99 does not.
4. Part of the answer: 5.0 degrees is 50 tenths of a degree.
5. The answer: 50.

## roomBFailsLead (two short paragraphs, under 100 wds; a lead above the figure)

- Now room B's freezer fails. It warms to -5.0 degrees, so its sensor reads -50. Room A stays at
  -184.
- Room B is now 13.4 degrees warmer than room A. The shop would want CLASH to light: the two rooms
  are far apart.
- The figure runs the same program with these readings. Read the program again before you answer.

## p2Question (one sentence)

- Room A reads -184 and room B -50. When the program stops, is the CLASH lamp lit?

## p2Explain (two short paragraphs, under 110 wds; shown after the learner commits and runs)

- R3 becomes -184 minus -50, which is -134. The display shows -134.
- Line 6 compares -134 with 100. -134 is less than 100, so the machine goes to line 9. CLASH
  stays dark.
- The program checks one way only: whether room A is warmer than room B. When room B is the warmer
  one, the gap is below zero, and the lamp never lights.
- The machine did what the lines said. It cannot know what the shop meant. A wrong program gives a
  wrong answer, and the machine runs it without complaint.

## explanation (two short paragraphs, under 120 wds)

- Where are the lines while the machine runs them? In its memory, with the numbers the machine
  works on.
- The machine keeps each line as one number. The number says which thing to do and with which of
  R0 to R15. Line 1 is kept as 939530200.
- To run a line, the machine reads that line's number, does what it says, and moves to the next
  line, unless the line says to go elsewhere.
- So a program is numbers in memory, and changing the program, as you did in the construction,
  means changing a number.

## keptLead (one paragraph, under 60 wds; a lead above the figure)

- The figure adds a column, "Kept as": the number the machine keeps each line as.
- Run the program, then change a room's reading and run it again. Watch the "Kept as" column.

## keptAfter (one paragraph, under 50 wds; shown once the learner has run a line)

- The "Kept as" column did not change, whatever the rooms read. The readings and the numbers R0
  to R15 change as the program runs. The program's own numbers do not.
