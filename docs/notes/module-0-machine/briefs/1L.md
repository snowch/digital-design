# Brief 1L: lesson 0.1: title, objectives, headings, captions and labels

Read `00-module.md` (this folder) and `docs/style.md` first. Short labels: each a few wds, no
full stop at the end of a heading, label or caption unless it is a full sentence. Headings are
labels a scanning reader understands (see style rule 7). Write these keys:

- title: the lesson's question, "What does a computer do?" (keep it).
- objectives.1 to objectives.4, each starting with a verb, each one sentence:
  1. run a program a line at a time and say what each line changed;
  2. predict which lines of a program run for given readings;
  3. change a number in a line to change what the program does;
  4. explain that a program is lines kept as numbers in the machine's memory.
- titles.question, titles.motivation, titles.prediction, titles.investigation,
  titles.construction, titles.failureExperiment, titles.explanation, titles.generalisation,
  titles.challenge, titles.reflection: the ten section headings, each two to five wds, about:
  the shop and its machine; a program of lines; which lines run; running it a line at a time;
  changing the limit; room B fails; lines kept as numbers; what every computer does; a run worked
  out by hand; reading, keeping, running, setting.
- challengeTitles.c1 (changing line 5's limit), challengeTitles.c2 (working a run out by hand).
- captions (one short sentence each, a request or a description):
  - captions.shop: the shop's rooms, the machine, the display and lamps.
  - captions.predictLines: choose which lines run, then check.
  - captions.run: run the program a line at a time and change a reading.
  - captions.limit: type line 5's number and run the tests.
  - captions.roomBFails: predict the lamp with room B failing.
  - captions.kept: the program with the number each line is kept as.
  - captions.inYourHead: answer, then run the tests.
- scene.roomA: "Room A". scene.roomB: "Room B". scene.sensor: "Sensor". scene.machine: the
  machine's box, two or three wds. scene.display: "Display".
- scene.title: the drawing's name for a screen reader, a few wds. scene.summary: one or two
  sentences for a screen reader: each room's sensor sends its reading to the machine; the machine
  sets the office display and the ALARM, NIGHT and CLASH lamps.
- options.p1All: lines 1 to 9, all nine. options.p1Skip: lines 1 to 6, then line 9.
  options.p1Stop: lines 1 to 6, then it stops.
- options.p2Lit: "Lit". options.p2Dark: "Dark".
- cases.gap66, cases.gap60, cases.gap50, cases.gap49: each test's name, e.g. "A gap of 66: CLASH
  lit"; for 49, CLASH dark.
- cases.display: the display shows your number. cases.lamp: CLASH is as you said.
- fields.limit: the number line 5 gives R4. fields.display: the display's number when it stops.
  fields.lamp: the CLASH lamp when it stops. fields.lit: "Lit". fields.dark: "Dark".
