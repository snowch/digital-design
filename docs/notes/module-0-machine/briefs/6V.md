# Brief 6V: the wds inside Module 0's two figures

Read `00-module.md` (this folder) and `docs/style.md` first. These are the labels, buttons,
headings and status lines inside the figures "the machine at work" and "the ladder". A test checks
every one to the banned list: none may contain a banned term, in any form. Each is short. Keep every
`{slot}` exactly as given: the figure fills it. Write each key with its text.

## The program's lines in plain English (one sentence each, no full stop)

Slots: {y} is the number written to (R3), {a} and {b} are numbers or names (R1, 100), {n} a
number, {line} a line number, {device} a phrase from the list below.

- lines.copy: {y} takes {b}'s number. (Say it as "{y} becomes {b}".)
- lines.set: "{y} becomes {n}".
- lines.add: {y} becomes {a} plus {b}.
- lines.subtract: {y} becomes {a} minus {b}.
- lines.read: {y} becomes {device}.
- lines.show: show {b} on the display.
- lines.setLamps: set the lamps from {b}.
- lines.goto: go to line {line}.
- lines.nothing: do nothing.
- lines.ifEqual: if {a} equals {b}, go to line {line}.
- lines.ifDiffer: if {a} is not equal to {b}, go to line {line}.
- lines.ifLess: if {a} is less than {b}, go to line {line}.
- lines.ifNotLess: if {a} is not less than {b}, go to line {line}.
- lines.stop: stop.
- Each starts with a capital letter when the slot is not first (Show, Set, Go, Do, If, Stop).

## What a line reads ({device}), lower case, each a noun phrase

devices.sensorA: room A's reading. devices.sensorB: room B's reading. devices.signals: the DOOR
and WARM signals. devices.display: the display's number. devices.lamps: the lamps. devices.timer:
the timer's count.

## Labels and buttons

- readingsLegend: the legend over the two reading boxes: the rooms' readings, in tenths of a degree.
- roomA, roomB: "Room A", "Room B".
- programCaption: the program table's caption, two wds.
- line: column "Line". does: column "What it does". stored: column, the number each line is kept
  as (two wds). marks: column "Now".
- next: the mark on the line it runs next, one wd. stoppedHere: the mark on the line where the
  program stopped, one wd.
- step: button that runs one line ("Run one line"). run: button that runs to the end, one wd
  ("Run"). pause: "Pause". reset: button that starts the program again from line 1 ("Start
  again").
- status.next: "Next: line {line}." status.running: while a run goes on, with {line} the line it
  runs next. status.stopped: the program stopped at line {line}. status.trapped: it stopped
  because it could not run line {line}. status.gaveUp: it ran {lines} lines without stopping and
  paused before line {line}.
- numbersCaption: the caption of the table of R0 to R15, "The numbers it keeps". name: column
  "Name". number: column "Number". changed: the mark on a number the last line changed, one wd.
  notSet: shown for a number nothing has set yet, two wds.
- shopCaption: the table of the display and the lamps, "What the shop sees". display: "The
  display". lamp: a lamp's row, "{name} lamp". lit: "lit". dark: "dark".
- answer: after a prediction, "The machine's answer: {answer}." (keep).
- faultLegend: the legend over the choice of a stuck wire, two or three wds. healthy: the choice
  with nothing stuck, two wds.
- drawingTitle: the machine's drawing, for a screen reader, a few wds.

## The ladder

- ladder.paused: above the ladder: the machine is paused before line {line}, whose text is {text}.
  One sentence ending in a full stop, e.g. "Paused before line {line}: {text}."
- ladder.levelsName: the name of the row of buttons, for a screen reader, one or two wds.
- ladder.up: "Up a level". ladder.down: "Down a level". ladder.position: "Level {k} of {n}".
- ladder.builtIn: "Built in Module {module}: {name}" (keep).
- ladder.number: the number at this level: "{value}". ladder.digits: this level's 1s and 0s:
  "{digits}". ladder.high: the wire is high and stands for 1. ladder.low: the wire is low and
  stands for 0. Each a short sentence.
- ladder.drawingTitle: the drawing at this level, for a screen reader, a few wds.
