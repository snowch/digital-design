# Brief 2L: lesson 0.2: title, objectives, headings, captions and labels

Read `00-module.md` (this folder), the facts in `2A.md` to `2C.md`, and `docs/style.md` first.
Short labels: each a few wds, no full stop at the end of a heading or label. Write these keys:

- title: the lesson's question, "What is the machine made of?" (keep it).
- objectives.1 to objectives.4, each starting with a verb, one sentence each:
  1. go down the machine a level at a time, from a line of the program to one wire;
  2. read a number the part that adds gives as the 1s and 0s of its slices;
  3. explain how one stuck wire changes what the shop's display shows;
  4. trace one line: the number it changes, the new number, the next line and the part that works
     it out.
- titles.question ... titles.reflection, two to five wds each, about: where 66 comes from;
  parts inside parts; which slices give a 1; down the ladder; a number on the slices; one wire
  stuck; one machine at every level; the course's ladder; tracing one line; from the top to one
  wire.
- challengeTitles.c1 (the slices for a new number), challengeTitles.c2 (tracing line 3).
- captions, one short sentence each: captions.predictSlices (choose, then open the part that
  adds); captions.ladder (go down from line 3 to one wire); captions.slices (type the slices' 1s
  and 0s and run the test); captions.stuck (choose the stuck wire and run the program);
  captions.tracePaused (the machine paused before line 3); captions.trace (answer, then run the
  tests).
- levels.line, levels.parts, levels.adder, levels.four, levels.slice, levels.smallest,
  levels.wire: each level's title, two to four wds: the line; the machine's parts; the part that
  adds; four slices; one slice; the smallest parts; one wire.
- options.p1Two: the slices worth 64 and 2. options.p1One: one slice, worth 66. options.p1All:
  all 64 slices.
- faults.stuck: the choice's label, a few wds: the wire in the slice worth 2, stuck low.
- fields.slices: the eight lowest slices, 128 first. fields.changed: the number line 3 changes.
  fields.none: "None". fields.value: its new number. fields.next: the line it runs next.
  fields.part: the part that works it out. fields.memory: "The memory". fields.adder: "The part
  that adds".
- cases.slices: the eight slices' 1s and 0s. cases.changed, cases.value, cases.next, cases.part:
  each test's name, a few wds.
