## explanation (two or three short paragraphs, under 150 wds)

- Where are the lines while the machine runs them? In its memory. The machine keeps each line as
  one number there. R0 to R15 are kept apart from the memory, and the rooms' readings come in from
  the sensors when a line reads them.
- To run a line, the machine reads that line's number from memory, does what it says, and moves
  to the next line, unless the line says to go elsewhere.
- Line 5, "R4 becomes 100", is kept as 620773476. The 100 is part of that number: change line 5's
  number to 101 and it is kept as 620773477. So changing the limit, as you did in the
  construction, changed one kept number.
- Not every part of a line is kept as written: line 6 keeps "go to line 9" as 3, the count of lines
  from line 6 to line 9. (One example only; do not mention line 1.)
