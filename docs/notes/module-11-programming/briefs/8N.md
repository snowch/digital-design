# Brief 8N: the figure that runs a program on several logs (Module 11's `log-results`), one label

Read `00-module.md` (the shared fact sheet) first.

Key to write: `emptyLog`.

- Each log's card shows "Readings: " and then the log's readings, such as "-184, -190, -176".
- For a log with no readings, the card showed "Readings: None". Write the words that follow
  "Readings: " for a log that has no readings. The lessons call such a log "an empty log".
- Plain text, no Markdown, no full stop, lower case (it follows a colon), at most four words.
