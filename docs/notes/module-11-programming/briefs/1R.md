# Brief 1R: lesson `assembly` (Module 11, lesson 1), keys the reading review changes

Read `00-module.md` (the shared fact sheet) first; it applies here. You may use **assembly**,
**assembler** and **debugger** (not in bold). No later term.

Keys to write: `debuggerLead`, `mistakesLead`, `captions.listing`.

## debuggerLead (about 90 words, directly above the debugger figure)

1. The listing marks the line about to run with ▶.
2. Beside the listing on a wide screen, and below it on a narrow one, come the shop's devices the
   program uses: the display, the lamps and room A's sensor. Then R2, R3 and R4, the registers
   this program writes, and the PC. A register nothing has set shows X.
3. The buttons: "Step" runs one instruction, "Step back" goes back one, "Run to the end" runs until
   the program stops, "Reset" goes back to the start. The line under the buttons says what comes
   next, or how the run ended.
4. Press "Step" until the program stops. Watch which register each instruction writes, and which
   device each store changes: the lamps at `010`, the display at `014`.

## mistakesLead (about 70 words, a list allowed, directly above the figure)

1. The figure holds room A's program again, with three mistakes. You can change its text.
2. The assembler refuses three lines, each with its line's number and the reason: line 3,
   `R3 <= -18000`; line 4, `if R2 < R3 goto fine`; line 7, `word[dispaly] <= R2`.
3. Mend each line. When the assembler refuses no line, the listing and the debugger appear.
4. Once you have changed the text, a button "Put back the program" appears; it brings back the
   three mistakes.

## captions.listing (plain text, one sentence, a full stop; it sits under the lesson's first
figure, before the words "listing" and "assembler" are introduced, so use neither)

Each line of the colder-room program beside its address and the eight-digit word the machine runs.
