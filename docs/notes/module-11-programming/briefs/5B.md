## construction (about 40 words)

1. The challenge asks for another function that calls itself.

## colderLead (one sentence, above the challenge)

Write `colder`, step through its calls with the stack shown, then run the tests.

## c1Task (about 140 words, a list allowed)

1. Write the function `colder`. R1 holds the address of a list of readings, R2 how many it has,
   and R3 a limit. Show on the display, newest first, each reading colder than the limit: below it.
   A reading equal to the limit is not colder.
2. `colder` must call itself, once for each reading, as `newest` does.
3. The starting text's main program sets R14, puts `log`, `count` and `limit` in R1, R2 and R3,
   calls `colder` and stops. Its `colder` returns at once.
4. The tests add `count`, `limit` and `log` after your program. There are 6 tests, each a log, all
   with the limit -200:
   - -190, -181, -205, -170, -210
   - -205, -215, -190
   - -190, -180
   - -250
   - an empty log
   - -201, -200, -199, -300
5. Each checks the readings the display shows, in order; that the stack held at least as many
   words as the log has readings; and that the program ends at its `stop`.

## c1Hints (five, in this order)

1. The idea: `newest` with one more decision: show a reading only when it is colder than the limit.
2. A common mistake: deciding before the call. The reading must be shown after the call returns, or
   the order is oldest first.
3. A smaller example: for the log -190, -205 and the limit -200, only -205 is colder, and the
   display shows -205.
4. Part of the answer: after the pops and `R5 <= word[R1]`, `if R5 >= R3 signed goto none` skips
   the store when the reading is not colder.
5. The whole answer:

```
colder: R0 <= 0
        if R2 == R0 goto none
        R14 <= R14 - 8
        word[R14] <= R15
        R14 <= R14 - 8
        word[R14] <= R1
        R1 <= R1 + 8
        R2 <= R2 - 1
        call colder, R15
        R1 <= word[R14]
        R14 <= R14 + 8
        R15 <= word[R14]
        R14 <= R14 + 8
        R5 <= word[R1]
        if R5 >= R3 signed goto none
        word[display] <= R5
none:   goto R15
```

## failureExperiment (about 40 words)

1. The first figure runs `newest` without its last case: the line `if R2 == R0 goto none` is
   gone.
2. R2 goes on down past 0, and every call makes another.

## noLastLead (one sentence, directly above the figure)

Predict how the run ends, then press "Run to the end".

## noLastAfter (about 80 words, shown once the run has ended)

1. The machine halts with cause `34` at `01C`, the push of R15, after 486 instructions.
2. `newest` has been called 61 times, and none has returned.
3. Each call pushed 2 words. After 60 calls the stack filled the RAM down to `400`. The 61st call's
   push went to `3F8`, the ROM's last word, and the ROM refuses a store.
4. Nothing was shown.

## tooLongLead (about 60 words, above the second figure)

1. `newest` with its last case is right, but its stack has room for only so many readings.
2. The second figure counts the stack's words in a run on a log of 61 readings.
3. Each reading takes 2 words. 60 readings fill the RAM's 120 words exactly; the 61st reading's push
   reaches the ROM, and the machine halts with cause `34` at `020`.
