# Brief 2L: lesson `lists` (Module 11, lesson 2), titles, captions and short labels

Read `00-module.md` (the shared fact sheet) first; it applies here. Terms allowed: **assembly**,
**assembler**, **debugger**, **breakpoint** (not in bold here). No later term.

Short texts. A title or heading has no full stop. A caption is one short sentence with a full
stop. Option labels have no full stop.

Keys to write:

- `title`: the lesson's title, as a question: how does a program work through a list of readings
  kept in memory?
- `objectives.1` to `objectives.4`, each starting with a verb: walk a list of readings in memory
  with a register that holds an address and steps by 8, and a count; leave a loop early when it
  finds what it looks for; pause a run with breakpoints and watch registers and words change; say
  why readings of both signs need a signed comparison.
- `titles.question` … `titles.reflection`: one heading for each section, a few words. (question)
  a log of readings; (motivation) the same lines for every reading; (prediction) where R1 points;
  (investigation) watching the loop go round; (construction) leaving a loop early; (failureExperiment)
  readings above and below 0; (explanation) a loop's five parts; (generalisation) any list, the
  same shape; (challenge) the largest rise; (reflection) the same check twice.
- `challengeTitles.c1`: the first warm reading. `challengeTitles.c2`: the largest rise.
- `captions.logInMemory`: today's log as words in memory, with its count first.
- `captions.predict`: predict where R1 points at the fourth pause, then run the program.
- `captions.walk`: the loop in the debugger, with a breakpoint, a watch and a view of the log.
- `captions.first`: write the program and run the tests.
- `captions.signs`: the same loop, comparing signed and unsigned, on a log with a defrost.
- `captions.rise`: write the program and run the tests.
- `memoryTitle`: the heading of the view of the count and the log in memory.
- `logTitle`: the heading of the view of the log in memory.
- `options.at040`, `options.at058`, `options.at070`: three answers, each the address in backticks
  and a few words: `040` (the first reading); `058` (the fourth reading); `070` (just past the
  log).
- `programs.signed`, `programs.unsigned`: two programs' names: compared signed; compared unsigned.
- `logPrefix`: the word before a test's readings in its name: "Log".
- `limitPrefix`: the word before a test's limit in its name: "limit".
- `emptyLog`: a test's log with no readings: "empty".
- `details.firstWarmer`: one sentence a failed test adds: the display must show the position, from
  1, of the first reading warmer than the limit, or 0 when none is.
- `details.largestRise`: one sentence a failed test adds: the display must show the largest of the
  rises from each reading to the next, which may be below 0.
