# Brief 7B: lesson `log-report` (Module 11, lesson 7, the capstone), second part

Read `00-module.md` (the shared fact sheet) and brief `7A.md` (the report and `lowest`) first. You
may use every Module 11 term (not in bold). Spell "program"; say "starting text".

Keys to write: `investigation`, `walkLead`, `walkAfter`, `construction`, `failureExperiment`,
`fromZeroLead`, `fromZeroAfter`.

## investigation (about 30 words)

The figure runs `lowest` on log 5 with a breakpoint on `lowNext`, a watch on R5, R6 and R2, and the
log shown with the word R1 points at.

## walkLead (about 50 words, above the figure)

1. R5 holds the lowest reading so far, and R6 the reading just loaded.
2. Press "Run to a breakpoint" again and again, and watch R5: it changes only when a lower reading
   comes.

## walkAfter (about 40 words, below the figure; shown from the start)

1. R5 starts at -184 and keeps it past 35, -176 and 12. It takes -190 from the last reading.
2. The display shows -190.

## construction (about 160 words, a list allowed): the specification

The specification, for the program as a whole:

1. The main program starts with `R14 <= 0x7C0`, as every program that keeps the calling convention
   does.
2. It calls `lowest`, `highest` and `warmer` in turn, each with `R1 <= log` and
   `R2 <= word[count]`, and `R3 <= word[limit]` for `warmer`.
3. It stores the lowest with `word[0x400] <= R1` and the highest with `word[0x408] <= R1`.
4. It stores the count of warm readings to the display, and, if it is not 0, stores 1 to the
   lamps: bit 0 is ALARM.
5. `highest` is `lowest` with one comparison turned round.
6. `warmer` walks the list as lesson 2's count did, with the limit in R3.
7. Each function uses only R1 to R9, so it needs no stack: it changes no kept register and calls
   nothing. Each returns with `goto R15`.

## failureExperiment (about 40 words)

1. The figure runs a whole report whose `highest` starts its highest so far at 0, not at the first
   reading.
2. Predict which logs it gets wrong, then press "Run all".

## fromZeroLead (one sentence, directly above the figure)

Compare what the program leaves at `408` with what each log asks for.

## fromZeroAfter (about 60 words, shown once the program has run)

1. It leaves 0 at `408` for logs 1, 2, 3 and 6, where every reading is below 0, so none is higher
   than 0.
2. It is right for log 4, the empty log, and for log 5, whose highest is 35.
3. A start of 0 is a guess at the answer. Start from the first reading, as `lowest` does.
