## The failure experiment: a halt far from the mistake

A new program counts the warm readings, keeps the number in the RAM, and shows it:

```
000        R6 <= log            // where the number is kept
004        R1 <= log
...        (the counting loop, as before, with R3 the number of warm readings)
034 done:  word[R6] <= R3       // keep the number
038        word[display] <= R3
03C        stop
```

The log (-190, -181, -175, -170, limit -180) is after it, with `log` at `050`, in the ROM. The line
at `000` is wrong: it should be `R6 <= 0x400`, a word of the RAM. The run: the loop runs, then the
machine halts with cause `34` at `034`, a store to the ROM, after 33 instructions. R6 holds `050`,
the log's address. The display still shows 0: the store to it never ran.

Keys to write: `investigation`, `findLead`, `findAfter`, `construction`, `mendCountLead`,
`c1Task`, `c1Hints` (five), `failureExperiment`, `countToLogLead`, `countToLogAfter`.

## c1Hints (five, in this order; no hint before the fifth names the line to delete)

1. The idea: R2 counts the readings left. When the loop starts it must hold the number of
   readings, the word at `count`.
2. A common mistake: deleting the `R2 <= R2 - 1` inside the loop, at `02C`. That one counts each
   reading done; without it R2 never reaches 0, and the run walks on past the log.
3. A smaller example: for a log of one reading, the loop must go round once, so R2 must hold 1 when
   it reaches `next`.
4. Part of the answer: the mistake is in one of the lines before `next`, which run once.
5. The whole answer: delete the line at `008`, `R2 <= R2 - 1`, whose comment says the readings are
   numbered from 0.

## countToLogAfter (about 80 words, shown once the run has ended)

1. The machine halts with cause `34` at `034` after 33 instructions: a store to the ROM.
2. `034` is `word[R6] <= R3`. R6 holds `050`, the log's address, which is in the ROM.
3. The halt is at `034`, but the line that is wrong is at `000`: `R6 <= log` should put a word of the
   RAM in R6, such as `0x400`.
4. The display still shows 0: the store to it comes after the halt.
5. The instruction that halts used a value an earlier line set. Find that line.
