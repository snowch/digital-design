# Brief 2B: lesson `lists` (Module 11, lesson 2), second part

Read `00-module.md` (the shared fact sheet) first; it applies here. You may use **assembly**,
**assembler**, **debugger** and **breakpoint** (not in bold: introduced earlier on the page). No
later term (function, argument, calling convention, stack, frame, recursion) may appear.

The lesson's program counts the log's readings warmer than -180, with R1 the address of the next
reading, R2 the readings left, R3 the count, R4 the limit, R0 holding 0, and the lines `next`
(the test at the top), `skip` (`R1 <= R1 + 8`), and `done` (the store to the display). The log:
-184, -190, -176, -181, -172, -188.

Keys to write: `investigation`, `walkLead`, `walkAfter`, `construction`, `firstLead`, `c1Task`,
`c1Hints` (five), `failureExperiment`, `signsLead`, `signsAfter`.

## investigation (about 50 words)

1. The debugger now has two more tools.
2. A watch shows chosen values after every instruction, with what each was before if it changed
   since the run last paused (corrected after drafting: the watch first compared with one
   instruction back).
3. A view of the log shows its six words, and marks the word whose address a register holds.

## walkLead (about 80 words, above the figure; a short list allowed)

1. The watch starts with R1, R2, R3 and `word[R1]`, the reading R1 points at. Type a register, or
   `word[...]` with an address, and press "Watch" to add one.
2. A breakpoint is set on `next`.
3. Press "Run to a breakpoint" again and again. Each time round, R1 moves down the log by one
   word, and the view of the log marks the word it points at.
4. Watch R3 go up when the reading is warmer than -180.

## walkAfter (about 50 words, below the figure; shown from the start)

1. The run pauses at `next` seven times: once before each of the six readings, and once when R2
   reaches 0.
2. The display shows 2: -176 and -172 are warmer than -180.
3. 46 instructions run, and the program stops at `034`.
4. At the end R1 holds `070`, the address just past the log.

## c1Task (about 110 words, a list allowed)

1. Show on the display the position of the first reading warmer than the limit: 1 for the first
   reading in the log, 2 for the second, and so on. Show 0 if no reading is warmer.
2. A reading equal to the limit is not warmer.
3. The tests add three names after your program: `count`, a word holding how many readings the log
   has; `limit`, a word holding the limit; and `log`, the readings, one word each.
4. There are 7 tests, each a log and a limit:
   - -190, -181, -175, -170, limit -180
   - -190, -195, -200, limit -180
   - -170, -190, limit -180
   - -185, -180, -179, limit -180
   - an empty log, limit -180
   - -200, 25, -150, 30, limit -150
   - -181, -182, -183, -184, -185, -186, -170, limit -180
5. Each checks the display and that the program ends at its `stop`.
6. The starting text shows 0 and stops.

## c1Hints (five, in this order)

1. The idea: walk the log as the lesson's program does, counting positions, and leave the loop
   with a branch as soon as a reading is warmer.
2. A common mistake: leaving the loop when the count reaches 0 with the last position still in the
   register. If no reading is warmer, the display must show 0.
3. A smaller example: the lesson's program decides with `if R4 >= R5 signed goto skip`, where R4 is
   the limit and R5 the reading.
4. Part of the answer: with the limit in R3 and the reading in R5, `if R3 < R5 signed goto found`
   leaves the loop when the reading is warmer.
5. The whole answer:

```
       R1 <= log
       R2 <= word[count]
       R3 <= word[limit]
       R4 <= 0
       R0 <= 0
next:  if R2 == R0 goto none
       R4 <= R4 + 1
       R5 <= word[R1]
       if R3 < R5 signed goto found
       R1 <= R1 + 8
       R2 <= R2 - 1
       goto next
none:  R4 <= 0
found: word[display] <= R4
       stop
```

## failureExperiment (about 50 words)

1. In a defrost, a room warms above 0 for a while, so a log can hold readings of both signs.
2. The figure runs the lesson's program twice on such a log: -184, 35, -176, 12, -190.
3. The two programs differ in one word: the first compares `signed`, the second `unsigned`.

## signsLead (one or two sentences, directly above the figure)

Predict what each program shows, then press "Run the programs".

## signsAfter (about 80 words, shown once the programs have run)

1. The signed program shows 3: 35, -176 and 12 are warmer than -180.
2. The unsigned program shows 1.
3. Read unsigned, -180 is a very large number, since its top bit is 1. It is larger than 35 and
   12, so the program counts them as not warmer.
4. Two negative readings keep their order when read unsigned, so -176 still counts.
5. The readings are signed, so every comparison of readings must say `signed`.
