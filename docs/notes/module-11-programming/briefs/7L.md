# Brief 7L: lesson `log-report` (Module 11, lesson 7), titles, captions and short labels

Read `00-module.md` (the shared fact sheet) first; it applies here. Every Module 11 term is
allowed (never in bold here).

Short texts, plain text with no Markdown and no backticks. A title, a heading, an option or a name
starts with a capital letter and has NO full stop; after a colon, the words go on in lower case. A
caption is one short sentence with a full stop. An objective is a sentence starting with a verb,
with a full stop. Say "program", not "code".

Keys to write:

- `title`: the lesson's title, as a question: can you write a program the shop can use?
- `objectives.1` to `objectives.4`, each starting with a verb: write a program from requirements
  and tests; build it from functions that keep the calling convention; test each function alone
  and the whole program on logs that reach the edges; find and mend mistakes with the debugger.
- `titles.question` … `titles.reflection`: one heading each, a few words. (question) the day's
  report; (motivation) what the report must show; (prediction) the lowest of log 5; (investigation)
  the given function at work; (construction) the specification; (failureExperiment) a highest
  started at 0; (explanation) every lesson in one program; (generalisation) a program the shop can
  rely on; (challenge) three ways in; (reflection) when a program does wrong.
- `challengeTitles.c1`: the day's report.
- `captions.asks`: the starting text run on six logs, beside the report each asks for.
- `captions.predict`: predict what lowest returns for log 5, then run it.
- `captions.walk`: lowest on log 5, with a breakpoint and a watch.
- `captions.fromZero`: a report whose highest starts at 0, run on the six logs.
- `captions.report`: write the report and run the tests.
- `options.first`, `options.lowest`, `options.nearest`: three answers, each the number and a few
  words after a colon: -184: the first reading; -190: the last reading; 12: the reading nearest 0.
- `checks.display`, `checks.lamps`, `checks.lowest`, `checks.highest`: four names for what the
  report shows: Display; Lamps (as a number: 1 is ALARM on); Word at 400, the lowest; Word at 408,
  the highest.
- `logTitle`: "Log". `logPrefix`: "Log". `wholeProgram`: the whole program (after a log's name in a
  test's name).
- `details.report`: one sentence a failed whole run adds: the report must show the warm count on the
  display, ALARM when it is not 0, and the lowest and highest at 400 and 408.
- `details.report-lowest`, `details.report-highest`, `details.report-warmer`: one sentence each a
  failed call adds: R1 must hold the list's lowest reading (or 0 for an empty list) / its highest
  reading (or 0) / how many readings are warmer than the limit in R3, with R10 to R14 as they were
  and a return through R15.
