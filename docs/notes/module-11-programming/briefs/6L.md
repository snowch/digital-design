# Brief 6L: lesson `debugging` (Module 11, lesson 6), titles, captions and short labels

Read `00-module.md` (the shared fact sheet) first; it applies here. Every Module 11 term is
allowed (never in bold here). Do not use "bug" or "debug" as words of your own.

Short texts, plain text with no Markdown and no backticks. A title, a heading, an option or a name
starts with a capital letter and has NO full stop. A caption is one short sentence with a full
stop. An objective is a sentence starting with a verb, with a full stop. Say "program", not "code".

Keys to write:

- `title`: the lesson's title, as a question: how do you find the mistake in a program that runs
  and gives a wrong answer?
- `objectives.1` to `objectives.4`, each starting with a verb: find a mistake by saying what each
  part should leave and watching for the first value that differs; read how a run ended and where
  to look; choose test logs that reach the edges; mend a program with more than one mistake, one
  at a time.
- `titles.question` … `titles.reflection`: one heading each, a few words. (question) a count that
  is sometimes wrong; (motivation) a method in five steps; (prediction) what R2 should hold;
  (investigation) the reading never loaded; (construction) mending the count; (failureExperiment) a
  halt far from the mistake; (explanation) how a run ends; (generalisation) tests that reach the
  edges; (challenge) two mistakes; (reflection) a program the shop can use.
- `challengeTitles.c1`: mending the count. `challengeTitles.c2`: two mistakes in total.
- `captions.results`: the count run on five logs beside what each should show.
- `captions.predict`: predict R2 at the first pause, then run the program.
- `captions.find`: the count, run on log 1, with a breakpoint and a watch.
- `captions.mendCount`: mend the program and run the tests.
- `captions.stackInRom`: total with its stack started at 400.
- `captions.mendTotal`: mend both mistakes and run the tests.
- `options.four`, `options.three`, `options.zero`: three answers, each the number and a few words
  after a colon: 4: the count; 3: one less than the count; 0: nothing counted yet.
- `displayCheck`: the name of the thing the opening figure checks: "Display".
- `logTitle`: the heading of the view of the log in memory: "Log".
- `logPrefix`: "Log". `limitPrefix`: "limit". `emptyLog`: "empty".
- `roomPrefixA`: "Room A". `roomPrefixB`: "room B".
- `details.warmerCount`: one sentence a failed test adds: the display must show how many readings
  are warmer than the limit.
- `details.mendTotal`: one sentence a failed test adds: the display must show both rooms' amounts
  above their limits, added.
