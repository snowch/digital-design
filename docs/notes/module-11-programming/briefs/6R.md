## explanation (about 150 words, a list)

How a run ends tells you where to look. The debugger says one of these (keep each as a bold
lead-in and a sentence):

- **The program ran `stop`.** The run finished. Check what it left against what it should.
- **The debugger cut the run off.** A loop never ends, or a return address was lost, as in
  lesson 4.
- **The debugger paused: a register nothing has set.** A start is missing, such as
  `R14 <= 0x7C0`, or a line names the wrong register.
- **Cause `12`, an instruction's address not a multiple of 4.** A `goto R15` with the wrong word in
  R15, as when pops run in the wrong order (lesson 4).
- **Cause `21`, not an instruction.** The run went past the program's end into data or 0s: a
  missing `stop`, or a branch to the wrong name.
- **Cause `31`, no memory at the address.** An address register went too far: a list walked past
  its end, or more pops than pushes.
- **Cause `33`, a word's address not a multiple of 8.** An address stepped by a number that is not
  a multiple of 8.
- **Cause `34`, a store to the ROM or a sensor.** A stack started in the wrong place, or a store
  to the log, which is in the ROM.

The instruction that halts is rarely the one that is wrong. Find which earlier line set the value
it used.

## c2Hints (five, in this order)

1. The idea: run, read how the run ends, find the line, mend it. Then run every log again: the
   second mistake shows only once the first is mended.
2. A common mistake: stopping once the program reaches its `stop`. After the first mend it stops
   on every log, with a wrong count.
3. A smaller example: the readings are words, 8 bytes apart, so an address that walks them goes up
   by 8 each time round.
4. Part of the answer: the first run halts with cause `33` at `018`, the load, when R10 holds
   `074`. After that is mended, a breakpoint on `next` shows R11 holding 96 where the count is 4:
   `R11 <= count` puts the address of `count` in R11, not the word stored there.
5. The whole answer: change `R10 <= R10 + 4` to `R10 <= R10 + 8`, and `R11 <= count` to
   `R11 <= word[count]`.
