# Brief 5A: lesson `recursion` (Module 11, lesson 5), first part

Read `00-module.md` (the shared fact sheet) first; it applies here. You may use **assembly**,
**assembler**, **debugger**, **breakpoint**, **function**, **argument**, **calling convention**,
**stack** and **frame**. This lesson introduces **recursion**: set it in bold where it is first
used, in `motivation`, plain meaning first.

The lesson's program, as the figures show it:

```
000          R14 <= 0x7C0
004          R1 <= log
008          R2 <= word[count]
00C          call newest, R15
010          stop
// newest: R1 the address of a list, R2 how many readings it has.
// Shows the list's readings on the display, newest first.
014 newest:  R0 <= 0
018          if R2 == R0 goto none   // an empty list: nothing to show
01C          R14 <= R14 - 8
020          word[R14] <= R15        // push R15
024          R14 <= R14 - 8
028          word[R14] <= R1         // push this reading's address
02C          R1 <= R1 + 8
030          R2 <= R2 - 1
034          call newest, R15        // the rest of the list, newest first
038          R1 <= word[R14]         // pop this reading's address
03C          R14 <= R14 + 8
040          R15 <= word[R14]        // pop R15
044          R14 <= R14 + 8
048          R5 <= word[R1]
04C          word[display] <= R5     // then this reading
050 none:    goto R15
058 count:   word 4
060 log:     word -184, -190, -176, -181
```

Keys to write: `question`, `depthLead`, `motivation`, `prediction`, `p1Question`, `p1Explain`.

## question (about 80 words, above a figure)

1. Lesson 4 ended on a question: can a function call itself?
2. The office wants today's log shown on the display newest first. The log keeps its readings
   oldest first: -184, -190, -176, -181.
3. A loop that walks the log from its start meets the oldest reading first.
4. The figure counts the words on the stack in a run of a program that shows the log newest first.

## depthLead (about 50 words, directly above the figure)

1. The stack grows by 2 words four times, to 8 words, then shrinks by 2 words four times, back to
   empty.
2. The program shows one reading each time the stack shrinks.

## motivation (about 140 words, a short list allowed)

1. The function `newest` shows a list newest first. Its arguments are the list's address, in R1,
   and how many readings it has, in R2.
   - If the list is empty, it shows nothing and returns.
   - Otherwise it pushes R15 and the address of its first reading. It calls `newest` on the rest
     of the list: the address 8 bytes on, and one reading fewer. When that call returns, the rest
     has been shown newest first. It pops the address and R15, and shows its first reading last.
2. A function that calls itself is **recursion**.
3. The call on the empty list is the last case: it calls nothing, so the calls stop there.
4. Each call has its own frame, so each keeps its own return address and its own reading's
   address.

## prediction (above the figure; about 40 words)

1. The figure is the debugger on the program, with the stack shown.
2. Choose an answer and press "Check my prediction". The buttons then work.

## p1Question (one sentence)

In what order does the display show the readings?

## p1Explain (about 80 words)

1. The display shows -181, -176, -190, -184: the log newest first.
2. No call shows its reading until the call it makes for the rest returns.
3. The deepest call that shows a reading has the newest one, -181, so -181 is shown first; then
   each call shows its own reading as the calls return.
4. The first call, on the whole list, shows the oldest reading, -184, last.
