# Brief 6RL2: lesson `debugging` (Module 11, lesson 6), titles, captions and labels, after the review

Read `00-module.md` (the shared fact sheet) and brief `6R2A.md` (the words on this page: "count"
is only the word `count`; the program is "the counting program"; no "task") first.

Short texts, plain text, no Markdown, no backticks. A title or a label starts with a capital letter
and has NO full stop. A caption is one short sentence with a full stop that names what the figure
shows, never an instruction. Function names written as given.

Keys to write:

- `titles.question`: a counting program that is sometimes wrong.
- `titles.construction`: mending the counting program.
- `challengeTitles.c1`: mending the counting program.
- `challengeTitles.c2`: two mistakes in a program that counts readings above the limit.
- `challengeTitles.edge`: the log that shows the mistake.
- `captions.results`: the counting program run on five logs, beside what each should show.
- `captions.predict`: the counting program's listing with log 4, with a question about R2.
- `captions.find`: the counting program run on log 4, with a breakpoint and a watch.
- `captions.mendCount`: the counting program to mend, and its tests.
- `captions.countToLog`: a program that keeps its number of warm readings at the wrong address, in
  the debugger.
- `captions.edgeListing`: a counting program that counts a reading equal to the limit.
- `captions.edgeLog`: a question: which log shows that program's mistake.
- `captions.mendOver`: the program with two mistakes, and its tests.
- `edgeField`: the log that shows the mistake
- `edgeLogs.below`: -190 and -185. `edgeLogs.above`: -170, -175 and -160. `edgeLogs.equal`: -180
  and -190. `edgeLogs.empty`: an empty log.

## The figure that runs a program on several logs (Module 11's `log-results`), used in 11.6 and 11.7

- `asks`: the column of what each log should show ("Should show").
- `left`: the column of what the program left ("Program left").
- `matches`: one sentence: the program left what the log should show.
- `differs`: one sentence: the program left something else.
