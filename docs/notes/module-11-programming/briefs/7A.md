# Brief 7A: lesson `log-report` (Module 11, lesson 7, the capstone), first part

Read `00-module.md` (the shared fact sheet) first; it applies here. You may use every Module 11
term (not in bold). This lesson introduces no term. Spell "program"; say "starting text".

The day's report. The tests add three names after the program, as lesson 2's challenges did:
`count`, how many readings; `limit`, the warm limit; `log`, the readings. The report:

- the display shows how many readings are warmer than the limit (above it; equal is not warmer);
- ALARM is on when any reading is warmer, and no lamp is on otherwise;
- the word at `400` in the RAM holds the lowest reading, and the word at `408` the highest; both
  are 0 for an empty log;
- the program ends at its `stop`.

The work is done by three functions, each taking the list's address in R1 and its count in R2, and
leaving its result in R1: `lowest`, `highest`, and `warmer`, which also takes the limit in R3.

The function the lesson gives whole:

```
// lowest: R1 the address of a list, R2 how many readings.
// The lowest reading in R1, or 0 for an empty list.
lowest:   R0 <= 0
          if R2 == R0 goto lowNone
          R5 <= word[R1]        // the lowest so far: the first reading
lowNext:  R1 <= R1 + 8
          R2 <= R2 - 1
          if R2 == R0 goto lowDone
          R6 <= word[R1]
          if R5 < R6 signed goto lowNext
          R5 <= R6
          goto lowNext
lowDone:  R1 <= R5
          goto R15
lowNone:  R1 <= 0
          goto R15
```

Keys to write: `question`, `asksLead`, `asksAfter`, `motivation`, `prediction`, `p1Question`,
`p1Explain`.

## question (about 70 words, above a figure)

1. Lesson 6 ended on a question: can you write a program the shop can use?
2. The office wants a report on each day's log: how many readings were warmer than the limit, an
   alarm if any were, and the day's lowest and highest readings.
3. The figure gives six logs and the report each asks for.

## asksLead (one or two sentences, directly above the figure)

The figure runs the starting text on each log. Press "Run all" to see what it leaves beside what
each log asks for.

## asksAfter (about 60 words, shown once the program has run)

1. The starting text finds the lowest reading on every log: its `lowest` is whole.
2. It leaves 0 for the highest, 0 on the display and no lamp on, since its `highest` and `warmer`
   return 0. That is right only for the empty log, log 4, and for the counts of logs 2 and 6.
3. Your program must match every log.

## motivation (about 120 words, a list)

The report, as the tests check it:

- the display shows how many readings are warmer than the limit; a reading equal to it is not;
- ALARM is on when any reading is warmer, and no lamp is on otherwise;
- the word at `400` holds the lowest reading and the word at `408` the highest, both 0 for an empty
  log;
- the program ends at its `stop`.

The tests add `count`, `limit` and `log` after your program. Three functions do the work. Each
takes the list's address in R1 and its count in R2, and leaves its result in R1: `lowest`,
`highest`, and `warmer`, which also takes the limit in R3. The tests call each function alone, as
lesson 3's did.

## prediction (above the figure; about 40 words)

1. The figure runs the given `lowest` on log 5, -184, 35, -176, 12, -190, and shows its result on
   the display.
2. Choose an answer and press "Check my prediction". The buttons then work.

## p1Question (one sentence)

What does `lowest` return for log 5?

## p1Explain (about 60 words)

1. It returns -190, the last reading.
2. It starts with the first reading, -184, as the lowest so far. 35, -176 and 12 are not lower, so
   it keeps -184 past them. -190 is lower, and takes its place.
3. It reads the readings signed: read unsigned, 35 and 12 would be lower than every negative
   reading.
