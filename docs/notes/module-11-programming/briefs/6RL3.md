# Brief 6RL3: lesson `debugging` (Module 11, lesson 6), the edge-log question gains a second answer

Read `00-module.md` (the shared fact sheet) and brief `6R2A.md` (the words on this page: "count"
is only the word `count`; no "task"; "pause" only for a breakpoint) first.

## Facts

- The figure above the question lists another counting program with one line wrong: it counts a
  reading equal to the limit as warmer. A right program does not.
- The question gives four logs, each with the limit -180: -190 and -185; -170, -175 and -160; -180
  and -190; an empty log.
- It now asks two things: which one log would show the mistake; and what a right program shows on
  the log you chose.
- A tester does both: chooses an input, and says what the right answer is before the run.
- There are 2 tests, one for each answer.
- Do not give either answer (the hints do).

Keys to write:

## edgeLogLead (one sentence, directly above the question)

Choose the log that shows the mistake, say what a right program shows on it, then run the tests.

## edgeTask (about 70 words)

1. The four logs, as a list, each with the limit -180.
2. The two questions.
3. Why the second: a tester chooses an input and says what the right answer is before the run.
4. There are 2 tests, one for each answer.

## Labels (plain text, no Markdown, no full stop, capital first)

- `edgeShowsField`: the field for the second answer: what a right program shows on the log you
  chose.
- `captions.edgeLog`: one short sentence with a full stop, naming the figure: two questions, which
  log shows that program's mistake and what a right program shows on it.

## Feedback sentence (one sentence; shown when the second answer is wrong)

- `answers.details.edgeShows`: starts "{actual} is not it;" then the rule, not the answer: a right
  program counts only readings warmer than -180, and a reading equal to the limit is not warmer.
