# Brief 8K: what a failed test says about the registers a function keeps (Module 11)

Read `00-module.md` (the shared fact sheet) first. A failed test's sentence starts "Your program
left", then lists what the program left, separated by semicolons, for example "Your program left R1
0; R10 to R14 as they were; a return through R15." Each text below is one of those list items:
plain text, no Markdown, no capital at the start (except a register's name), no full stop.

Keys to write:

- `keptAll`: the kept registers, R10 to R14, all hold what they held before the call ("R10 to R14
  as they were").
- `keptNot`: some of them do not; {names} is a list such as "R10, R11, R14" and must appear as
  written ("{names} not put back").
- `returnedYes`: the function returned to the address in R15 ("a return through R15").
- `returnedNo`: it did not ("no return through R15").
