# Brief 5L: lesson `recursion` (Module 11, lesson 5), titles, captions and short labels

Read `00-module.md` (the shared fact sheet) first; it applies here. Every term up to
**recursion** is allowed (never in bold here).

Short texts, plain text with no Markdown and no backticks. A title, a heading, an option, a field
label or a name starts with a capital letter and has NO full stop. A caption is one short sentence
with a full stop. Say "program", not "code".

Keys to write:

- `title`: the lesson's title, as a question: can a function call itself?
- `objectives.1` to `objectives.4`, each starting with a verb: write a function that calls itself
  on the rest of a list; say what each call's frame holds and how deep the stack goes; give a
  function a last case that calls nothing; say what happens when the stack runs into the ROM.
- `titles.question` … `titles.reflection`: one heading each, a few words. (question) the log
  newest first; (motivation) a function that calls itself; (prediction) the order shown;
  (investigation) five calls, four frames; (construction) colder readings, newest first;
  (failureExperiment) a stack with no end; (explanation) why recursion works; (generalisation)
  when recursion fits; (challenge) how deep the stack goes; (reflection) a wrong answer.
- `challengeTitles.c1`: colder readings, newest first. `challengeTitles.c2`: how deep the stack
  goes.
- `captions.depth`: the stack's words over a run that shows the log newest first.
- `captions.predict`: predict the order of the readings, then run the program.
- `captions.frames`: newest's calls and frames in the debugger.
- `captions.colder`: write the function and run the tests.
- `captions.noLast`: newest without its last case.
- `captions.tooLong`: the stack's words over a run on a log of 61 readings.
- `captions.depths`: work out the answers and run the tests.
- `options.oldest`, `options.newest`, `options.one`: three answers, each the readings shown and a
  few words after a colon: -184, -190, -176, -181: oldest first; -181, -176, -190, -184: newest
  first; -184: the first reading only.
- `fields.words`, `fields.lowest`, `fields.longest`: words on the stack at its deepest, for 5
  readings; R14 then, in hexadecimal; the most readings newest can show.
- `logPrefix`: "Log". `limitPrefix`: "limit". `emptyLog`: "empty".
- `details.colderNewest`: one sentence a failed test adds: the display must show the readings below
  the limit, newest first, from a function that calls itself once for each reading.
- `details.recursionDepth`: one sentence for a wrong answer, with `{actual}` the learner's answer
  (keep the slot): {actual} is not it; each reading's call pushes 2 words, and the stack has 120
  words of RAM.
