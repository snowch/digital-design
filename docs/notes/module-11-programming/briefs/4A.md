## question (about 90 words, above a figure)

1. Lesson 3 ended on a question: what must a function that calls another keep, and where?
2. The figure's program adds both rooms' amounts above their limits with a function, `total`. It
   takes room A's reading in R1 and room B's in R2, and returns the sum in R1. It calls `above`
   twice, keeping words it needs through the calls in R10, a kept register.
3. The main program calls `total` from `008`, then shows R1 on the display and stops.
4. Room A reads -170 and room B -190: each is 10 above its limit, so the display should show 20.

## lostLead (one or two sentences, directly above the figure)

Predict what the display shows, then press "Run to the end".

## lostAfter (about 90 words, shown once the run has ended)

1. The debugger cuts the run off after 5000 instructions. The display still shows 0.
2. The call at `008` put `00C`, the return address into the main program, in R15.
3. `total`'s own calls to `above` wrote R15 too. After the second, R15 holds `034`, the
   instruction after that call.
4. So `total`'s `goto R15`, at `038`, goes to `034`, which adds R10 to R1 again and comes back to
   `038`. R1 grows by 10 each time round, and the run never reaches the main program again.

## motivation (about 140 words, a short list allowed)

1. A function that calls another must keep its own return address where a call cannot write it:
   in memory.
2. It keeps it on a **stack**: words in the RAM that a program takes back in the opposite order it
   put them there. The last word put on is the first taken off.
3. R14 holds the address of the word last put on.
   - A push puts a word on: `R14 <= R14 - 8`, then `word[R14] <= R15`.
   - A pop takes it off: `R15 <= word[R14]`, then `R14 <= R14 + 8`.
4. The stack grows down from `7C0`, the first address past the RAM's last word. A program starts
   with `R14 <= 0x7C0`, so its first push writes `7B8`.
5. The new `total` pushes R15 and R10 when it starts, and pops them in the opposite order before
   `goto R15`.

## p1Question (one sentence)

When `above` starts for the first time, what address does R14 hold?

## p1Explain (about 70 words)

1. R14 holds `7B0`.
2. The program started R14 at `7C0`. `total` pushed R15 at `7B8`, then R10 at `7B0`, taking 8 off
   R14 for each.
3. `above` pushes nothing, so R14 stays at `7B0` while it runs.
4. The debugger shows R14 as 1968, with `7B0` under it in hexadecimal.
