# Brief 2R2: lesson `lists` (Module 11, lesson 2), the walk's lead, after the reading review

Read `00-module.md` (the shared fact sheet) first; it applies here. You may use **assembly**,
**assembler**, **debugger** and **breakpoint** (not in bold). No later term.

The program counts the log's readings warmer than -180 (brief 2R lists it). Its loop starts at
`next` (`014`): `if R2 == R0 goto done`, then `R5 <= word[R1]` loads a reading, a branch skips
`R3 <= R3 + 1` when the reading is not warmer, then `R1 <= R1 + 8` and `R2 <= R2 - 1`, and back.

Key to write: `walkLead` (about 110 words, a short list allowed, directly above the figure).

1. The watch starts with R1, R2, R3 and `word[R1]`. R1 is an address, so the watch shows it in
   hexadecimal first.
2. A breakpoint is set on `next`. At each pause there, R1 already holds the address of the reading
   the next time round will load, so `word[R1]` shows that reading, not the one just counted.
3. So when R3 goes up, the reading that made it go up is the one before: the watch shows it as
   what `word[R1]` "was", and the log view marks the word R1 has moved on to.
4. To add a watch, type a register or `word[...]` with an address and press "Watch".
5. Press "Run to a breakpoint" again and again, and watch R3 go up for each reading warmer than
   -180.
