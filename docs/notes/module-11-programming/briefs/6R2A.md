# Brief 6R2A: lesson `debugging` (Module 11, lesson 6), redrafted after the reading review, part 1

Read `00-module.md` (the shared fact sheet) first; it applies here. You may use every Module 11 term
up to lesson 5's (not in bold). This lesson introduces nothing. Never write "frame".

## Words on this page

- "count" means only the data word `count`, the number of readings in a log. The lesson's program
  is "the counting program"; what it shows is "the number of warm readings". Never call the
  program or its result "the count".
- "pause" only for a breakpoint. Before an instruction that needs a register nothing has set, the
  debugger "ends the run".
- No "task": say what a log "should show".

## The counting program, with its mistake

```
000        R1 <= log
004        R2 <= word[count]
008        R2 <= R2 - 1         // the readings are numbered from 0
00C        R3 <= 0
010        R4 <= word[limit]
014        R0 <= 0
018 next:  if R2 == R0 goto done
01C        R5 <= word[R1]
020        if R4 >= R5 signed goto skip
024        R3 <= R3 + 1
028 skip:  R1 <= R1 + 8
02C        R2 <= R2 - 1
030        goto next
034 done:  word[display] <= R3
038        stop
```

It should show the number of readings warmer than the limit, -180. The line at `008` is wrong.

The opening figure runs it on five logs (limit -180):

| Log | Readings | Should show | Shows |
| --- | --- | --- | --- |
| 1 | -190, -181, -175, -170 | 2 | 1 |
| 2 | -170, -190 | 1 | 1 |
| 3 | -175, -190, -200 | 1 | 1 |
| 4 | -190, -170 | 1 | 0 |
| 5 | -170 | 1 | 0 |

Logs 1, 4 and 5 end with a reading warmer than the limit; logs 2 and 3 do not.

The rest of the lesson runs log 4, two readings, after the program: `count` at `040`, `limit` at
`048`, `log` at `050` (-190) and `058` (-170).

Keys to write: `question`, `resultsLead`, `resultsAfter`, `motivation`, `prediction`, `p1Explain`.

## question (about 70 words)

1. Lesson 5 ended on a question: how do you find the mistake in a program that runs and gives a
   wrong answer?
2. The figure's program counts the log's readings warmer than the limit, -180, as lesson 2's did.
   One of its lines is wrong.
3. On the figure's five logs it runs to its `stop` every time, and on some logs its answer is
   wrong.

## resultsLead (one sentence, directly above the figure)

The figure gives five logs, each with the number it should show: press "Run all" to run the
program on each, and compare.

## resultsAfter (about 70 words, shown once the program has run on every log)

1. It shows 1 for log 1, which should show 2, and 0 for logs 4 and 5, which should show 1. Logs 2
   and 3 are right.
2. Logs 1, 4 and 5 end with a reading warmer than the limit; logs 2 and 3 do not.
3. The wrong answers are the first clue: the last reading never counts.

## motivation (about 140 words, a numbered list of five steps after one sentence)

A method for finding the mistake:

1. Choose a log that fails, as short as you can, so that each run is short. Log 5 has one reading,
   but on it the loop never runs, so there is nothing to step through. Log 4, two readings, is the
   shortest that shows the loop.
2. Say what each part of the program should leave. Before the loop, R1 should hold `log`'s
   address, `050`; R2 the number of readings, 2; R3 0. Each time round, R2 goes down by 1.
3. Set a breakpoint before the part you doubt, here `next`, and run to it.
4. Step and watch. The first value that differs from what you said is next to the mistake.
5. Mend the line, then run every log again, not only the one that failed.

## prediction (about 40 words, above the figure)

1. The figure lists the program with log 4 after it: -190 and -170.
2. The first time the run reaches `next`, 6 instructions have run.
3. Choose an answer and press "Check my prediction". The listing's words then show.

## p1Explain (about 50 words, shown once the learner has answered)

1. R2 holds 1, where the log has 2 readings.
2. Step 2 of the method says R2 should hold 2 when the loop starts. It holds 1, so the mistake is
   in a line that runs before `next`.
3. Do not name the line or say what it does: the construction asks the learner to find it.
4. The next figure runs the program with a breakpoint on `next`.
