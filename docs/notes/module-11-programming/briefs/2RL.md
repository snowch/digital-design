# Brief 2RL: lesson `lists` (Module 11, lesson 2), revised labels

Read `00-module.md` (the shared fact sheet) first; it applies here. Short texts, plain text with no
Markdown. A title or a button's name starts with a capital letter and has NO full stop. A caption
is one short sentence with a full stop that names what the figure shows, never an instruction to
the reader. "Breakpoint" must not appear in `nextReading` or `captions.logInMemory`.

Keys to write:

- `nextReading`: a button's name: go on to the next reading ("Next reading").
- `titles.prediction`: where R1 ends.
- `captions.logInMemory`: today's log as words in memory, with R1 moving down it one reading at a
  time.
- `captions.predict`: the program's listing, with a question about R1.
