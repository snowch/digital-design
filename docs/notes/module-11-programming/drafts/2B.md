construction: A loop can leave early, stopping as soon as it finds what it is looking for. In the challenge, the tests add data after your program: a `count` of how many readings, a `limit`, and the readings themselves at `log`.

firstLead: Write the program, pause it in the loop to check your work, then run the tests.

c1Task: Show on the display the position of the first reading warmer than the limit: 1 for the first, 2 for the second, and so on. Show 0 if no reading is warmer. A reading equal to the limit is not warmer.

Your program must use three words the tests provide:

- `count`: how many readings the log has
- `limit`: the limit to compare against
- `log`: the readings, one word each

Seven tests check your program. Each gives a log and a limit, and checks that the display shows the right position and that your program ends at its `stop`. The starting text shows 0 and stops.

c1Hints.1: Walk the log as the lesson's program does, counting positions. Leave the loop with a branch as soon as a reading is warmer.

c1Hints.2: Leaving the loop when the count reaches 0 can leave the position still in the register. If no reading is warmer, the display must show 0.

c1Hints.3: In the lesson's program, `if R4 >= R5 signed goto skip` compares the limit (R4) against the reading (R5).

c1Hints.4: With the limit in R3 and the reading in R5, `if R3 < R5 signed goto found` leaves the loop when the reading is warmer.

c1Hints.5: 
```
       R1 <= log
       R2 <= word[count]
       R3 <= word[limit]
       R4 <= 0
       R0 <= 0
next:  if R2 == R0 goto none
       R4 <= R4 + 1
       R5 <= word[R1]
       if R3 < R5 signed goto found
       R1 <= R1 + 8
       R2 <= R2 - 1
       goto next
none:  R4 <= 0
found: word[display] <= R4
       stop
```

failureExperiment: In a defrost, a room warms above 0 for a while, so a log can hold readings of both signs. The figure runs the lesson's program twice on such a log: -184, 35, -176, 12, -190. The two programs differ in one word: one compares `signed`, the other `unsigned`.

signsLead: Predict what each program shows, then press "Run the programs".

signsAfter: The signed program shows 3: the readings 35, -176 and 12 are all warmer than -180.

Read unsigned, -180 becomes a very large number, since its top bit is 1. It is larger than 35 and 12, so they do not count as warmer. Two negative readings keep their relative order when read unsigned, so -176 still counts. This is why the unsigned program shows 1.

The readings are signed, so every comparison of readings must say `signed`.
