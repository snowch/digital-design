# Lesson 4: what the building session changed in the drafts

Facts only, by adding or cutting the fewest words.

- 4A `lostAfter`: "each cycle", a word the course keeps out, for "each time round".
- 4B `pushedLead`: the button was named "Run to the breakpoint"; it is "Run to a breakpoint".
- 4B `c1Task`: two wrong facts. "`above` ... returns 1 when it is" above its limit: it returns the
  amount; the clause cut. "With the supplied inputs, it returns 0" for the brief's "Its `both`
  returns 0". The tests' arguments and runs, dropped, put back as the brief listed them.
- 4B `noStartAfter`: "Four instructions ran, starting with `R14 <= R14 - 8`": that instruction was
  the fourth; "the last" for "starting with".
- 4C `explanation`: an added clause, "a group of words that holds that call's own state", cut: it
  is a claim the brief did not make, with "state" in a sense the course keeps for the controller.
- 4L: headings came in lower case; their first letters raised, as every lesson's are.
