edgeLogLead: Choose the log that shows the mistake, say what a right program shows on it, then run the tests.

edgeTask: Each log has the limit -180. Choose one of these four:

1. A log of -190 and -185.
2. A log of -170, -175 and -160.
3. A log of -180 and -190.
4. An empty log.

The question asks two things:

1. Which one log would show the mistake?
2. What should a right program show on the log you chose?

The second question matters because a tester chooses an input and says what the right answer is before the run.

There are 2 tests, one for each answer.
