walkLead: The watch starts with R1, R2, R3 and `word[R1]`. R1 holds an address, so the watch shows R1 in hexadecimal first.

A breakpoint is set on `next`. At each pause there, R1 already holds the address of the reading the next time round will load. So `word[R1]` shows that reading, not the one just counted.

So when R3 goes up, the reading that made it go up is the one before. The watch shows it as what `word[R1]` "was", and the log view marks the word R1 has moved on to.

To add a watch, type a register or `word[...]` with an address, and press "Watch".

Press "Run to a breakpoint" repeatedly. See R3 go up for each reading warmer than -180.
