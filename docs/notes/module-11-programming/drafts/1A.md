motivation: A program written as lines of text is **assembly**: one line for each instruction, written as the transfer it makes. An **assembler** is a program that turns those lines into the words the machine runs.

The assembler places the first instruction at address `000` and each next one 4 bytes on. A name followed by a colon names a line's address: `show:` in the colder-room program names `010`. A branch can say `goto show`, and the assembler works out the constant that reaches it. You never count instructions by hand.

The assembler also refuses a line it cannot turn into an instruction and says why, with the line's number. The table it makes is the listing: each line beside its address and its word.
