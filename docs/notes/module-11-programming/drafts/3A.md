motivation: Lesson 8.5 showed the call instruction. `call above, R15` puts the address of the instruction after the call in R15, and goes to `above`. `goto R15` jumps back to that address.

A **function** is a piece of program that a call runs, and that goes back to the instruction after the call when it is done.

The values a function is given are its **arguments**. The `above` function takes two: the reading in R1 and the limit in R2. It leaves its result in R1: how far the reading is above the limit, or 0 when it is not above.

Before each call to `above`, the program puts the arguments in R1 and R2. After it, the result is in R1.
