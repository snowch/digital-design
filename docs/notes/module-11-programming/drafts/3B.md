construction: Which registers carry the arguments, which the result, and which a function may change is not up to each function. It is an agreement every program on the machine keeps: a **calling convention**. The course's is:

- R1 to R4 carry a function's arguments. R1 carries its result back.
- R5 to R9 are free: a function may change them. A caller cannot rely on what they hold after a call.
- R10 to R13 are kept: a function that changes one puts it back before it returns. A caller can keep a word in one through a call.
- R15 holds the return address.
- R14 has a role lesson 4 gives it. R0 is free.

A function may change its own arguments, R1 to R4, as `above` changes R1.
