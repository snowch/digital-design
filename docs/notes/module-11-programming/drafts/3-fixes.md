# Lesson 3: what the building session changed in the drafts

Facts only, by adding the fewest words.

- 3A `twoWaysAfter`: "Write the check once instead of twice, so a mistake is mended in one place"
  turned the brief's fact (the check now exists once) into an order; put back as "The check is
  written once, so a mistake is mended in one place".
- 3B: the drafts returned the hints as one key with a numbered list; split into the five rungs.
  `construction` and `c1Task` came as numbered lists of the brief's facts; the numbers taken off,
  the words kept.
- 3C: bold on "calling convention" in the explanation, where 3B had introduced it; taken off. Three
  hints lost their rungs' names; added. "A common mistake is comparing unsigned" given the ladder's
  form, "A common mistake: comparing `unsigned`".
- 3L: the title drifted to "How can you run the same code from two places?", with "code" for the
  course's "program"; the brief's own question put back. Full stops on headings, options and names
  taken off; options' first words lower-cased after the colon. `details.twoRooms` said the display
  shows room A's amount "when room A is above -180"; it shows the amount above -180, or 0, so "or
  0" added and "when" dropped.
