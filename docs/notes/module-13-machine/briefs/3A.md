# Brief 3A: lesson `tracing` (Module 13, lesson 3), first part

Read `00-module.md` (the shared fact sheet) first; it applies here. This lesson introduces
**abstraction** (in brief 3C, not here): do not use it in these keys. You may use CPU, machine code
and join (not bold). From this lesson on you may write **trace** for what you do with a value: set
it in bold once, in the motivation, as a plain word, not a term: following one value down from a
line of the program to one gate.

Keys to write: `question`, `freeLead`, `motivation`, `prediction`, `p1Question`, `p1Explain`.

## The figure in every section of this lesson

The whole machine runs the shop's program, recorded edge by edge, with the buttons "Next edge",
"Step back", "Run to the end" and "Start again". Above the drawing: a row headed "Pause before an
edge", with a list of the program's lines, a list of that line's edges ("edge 3, ALU"), and a
button "Go there". Under the drawing: a table "The levels you have opened", a row for each block you
have opened, the outermost first, each with the module that built it and the values on its inputs
and its outputs at this edge; and a list "Parts here that never open". Each part on that list is a
button that shows one bit of the part as the module that built it drew one bit, with the machine's
values on it: a register as Module 5's register bit (D, EN, the flip-flop, Q), a selector as Module
3's, an adder as Module 3's full adder. A sentence under it says what the bit holds now and after the
next edge, or what it gives now. Tables of registers sit below.

## question (about 130 words, above the figure)

1. Module 0's second lesson followed one line of a program down to one wire, through nine levels,
   each named with the module that builds it. The path was chosen for you.
2. Lessons 1 and 2 of this module showed every level of the whole machine at one edge.
3. This lesson's question: can you follow one value of your own choosing, at an edge of your own
   choosing, from a line of the program down to one gate?
4. The figure is paused before edge 28, the ALU edge of `R5 <= R3 >= R4 signed`: the ALU works out
   R3 minus R4, 66 minus 100.

## freeLead (one sentence)

Open the datapath, then the ALU, and keep opening blocks; watch the table of levels grow.

## motivation (about 230 words; a short list allowed)

1. Say what the learner will do: a **trace** follows one value down from a line of the program,
   through every level, to one gate. (Bold once, as a plain word.)
2. The figure gives three tools, as a list:
   - "Pause before an edge" chooses any line and any of its edges;
   - the table of levels records each block you open, with its maker and its ports' values at that
     edge, so you can see the value you follow enter and leave each level;
   - "Parts here that never open" opens the parts the simulator runs whole.
3. Those parts: the register file, the memory, the PC, the IR, the held words, the control
   registers and the controller's state register; and the selectors and adders that take a whole
   word at once. Each one shows one bit, as the module that built it drew it: a register's bit as
   Module 5's, the register file's as one register's bit, a byte of the RAM as one bit of a
   register, a selector's bit as Module 3's, an adder's as Module 3's full adder. Its inputs carry
   the machine's own values at that edge.
4. So every trace ends at a gate or at a flip-flop.
5. A part that only splits a word into its bits or joins bits into a word has no gate. The list
   says so; the trace passes through it.

## prediction (about 50 words, above the figure)

1. The figure is paused before edge 28, the ALU edge of `R5 <= R3 >= R4 signed`. HR holds 100, the
   last result, until that edge.
2. The ALU works out 66 minus 100.
3. No value shows until you commit. Choose an answer and press "Check my prediction".

## p1Question (one sentence)

After the next edge, what does bit 1 of HR hold?

## p1Explain (about 90 words)

1. Bit 1 of HR holds 1. 66 minus 100 is -34, which in binary ends `1101 1110`: bit 1 is 1.
2. HR never opens. In "Parts here that never open", at the datapath's level, HR shows its bit 1 as
   Module 5's register bit: D is 1, EN is 1, since this is the ALU edge, and the flip-flop holds 0,
   bit 1 of 100. After the edge it holds 1.
3. The investigation follows that 1 back into the ALU, to the gate that makes it.
