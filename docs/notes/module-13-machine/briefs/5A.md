# Brief 5A: lesson `capstone` (Module 13, lesson 5), first part

Read `00-module.md` and `5-shared.md` first; both apply. You may use CPU, machine code,
abstraction, join and trace. This lesson introduces no term. It is the course's last lesson.

Keys to write: `question`, `questionLead`, `motivation`, `prediction`, `p1Question`, `p1Explain`.

## question (about 110 words, above the figure)

1. Module 0 began with the machine as a box that runs lines of a program. Lesson 3 traced a value
   of your own choosing down to one gate; lesson 4 had you join the parts into the whole machine.
2. This lesson's question: can you write a program of your own, run it on the whole machine, and
   answer questions about its run that only a trace answers?
3. The figure runs a short program written for this lesson (not the challenge's task): it lights
   CLASH when room B is colder than room A, and shows room A's reading.

## questionLead (one sentence)

Step through the run, or pause before any edge of any line, and open the blocks as lesson 3 did.

## motivation (about 170 words)

1. The challenge asks for a program for the shop: the task in one sentence, from `5-shared.md`.
2. Then five questions about your program's run on the whole machine. Their answers are read off
   the run of your own program, so they depend on how you wrote it. No two programs need give the
   same answers.
3. Each question names a wire, an edge and an instruction of your program: your first set if,
   your first store. Only a trace reaches the answer: the wire is inside a block, at one edge.
4. A wrong answer is told which level to look at, never the value.
5. The figures in this lesson practise the same questions on the figure's program.

## prediction (about 70 words, above the figure)

1. The figure is paused before edge 13, the ALU edge of `R3 <= R2 < R1 signed`.
2. The ALU subtracts R1 from R2: -250 minus -184.
3. The set if writes MET into R3: 1 if the condition holds, else 0.
4. No value shows until you commit. Choose an answer and press "Check my prediction".

## p1Question (one sentence)

After the next edge, what does MET hold?

## p1Explain (about 70 words)

1. MET holds 1: -250 is less than -184, read signed.
2. The ALU gives Y, -66, with MINUS 1 and OVER 0. The condition block takes those flags and the
   job digit, and gives MET.
3. Find MET where it leaves the condition block in the datapath. At the WRITE edge, R3 takes it as
   a word.
