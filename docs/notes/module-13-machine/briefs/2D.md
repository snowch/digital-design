# Brief 2D: lesson `full-path`, the challenge's sentences for a wrong answer

Read `00-module.md` (the shared fact sheet) first; it applies here. You may use **machine code**
(not bold). Do not use abstraction.

Each key is one or two sentences shown when the learner's answer to one field is wrong. `{actual}`
stands for the learner's answer and must appear once, as given. Say which rule or fact the wrong
answer misses. Never give the right word, job or number.

- `pathCode`: the machine code of a set if line. Rule: the eight digits are K, J, A, B, Y, then
  three digits of constant; set if is kind A; its job digit is a branch's condition.
- `pathEdges`: the edges `R2 <= R3` takes. Fact: a register job takes FETCH, READ, ALU and WRITE;
  count from its FETCH edge to its last.
- `pathJob`: the ALU's job at its ALU edge. Fact: read OP2 OP1 OP0 in the table at the ALU edge; a
  register job's ALU code is its job digit.
- `pathYin`: the word register Y takes at its WRITE edge. Fact: read register Y's register in the
  table after the WRITE edge, or YIN on the drawing before it; give it as a decimal number.
- `pathPc`: the PC after its last edge. Fact: an instruction that does not branch, call or jump
  leaves the PC at its own address plus 4; give three hexadecimal digits.
