# Brief V2: Module 13's figure words for the trace (lesson 3 on)

Read `00-module.md` (the shared fact sheet) first; it applies here. These words appear from lesson
3 on, so you may use CPU, machine code and join, but not abstraction. Each key is a short label or
one sentence. A label has no full stop; a sentence has one. Placeholders in braces stay exactly as
given, never in backticks.

## The choice of where to pause

A row of two lists and a button above the drawing.

- `pauseLegend`: its heading: pause before an edge.
- `pauseLine`: the first list's label: the line of the program.
- `pauseEdge`: the second list's label: which edge of that line.
- `pauseEdgeOption`: each option of the second list: edge {k}, {state}. ({k} counts the line's
  edges from its FETCH edge, 1 first; {state} is FETCH, READ, ALU, MEMORY or WRITE.)
- `pauseGo`: the button that pauses the run there: Go there.

## The table of the levels opened

A table with a row for each block opened so far, the outermost first. Each row names the block and
the module that built it, then the values on the block's inputs and on its outputs at this edge.

- `traceCaption`: its title: the levels you have opened.
- `traceLevel`, `traceIn`, `traceOut`: its column headings: level; inputs; outputs.

## The parts that never open

Under the drawing, a list of the parts at the level on show that never open. Each is a button that
shows one bit of the part as the module that built it drew one bit, with the machine's values on
it: Module 5's register bit for a register, Module 3's selector for a selector, Module 3's full
adder for an adder. A part that only splits or joins words, with no gate in it, is listed as a
sentence instead.

- `closedCaption`: the list's heading: parts here that never open.
- `closedOpen`: a button: {part}: show one bit, as Module {module} drew it.
- `closedWiring`: a sentence: {part} only splits or joins words; it has no gate.
- `bitWhich`: the list that chooses the bit: bit.
- `bitRegister`: the list that chooses a register of the register file: register.
- `bitByte`: the list that chooses a byte of the RAM by its address: byte at.
- `bitPair`: the list that chooses one of two held words, HA or HB: word.
- `bitHeading`: the heading over the drawing of one bit: {part}, bit {k}, as Module {module} drew
  one bit.
- `bitHolds`: a sentence under a register's bit: it holds {held} now; after the next edge it holds
  {result}.
- `bitGives`: a sentence under a selector's or an adder's bit: it gives {result} now.
