# Brief 2L: lesson `full-path` (Module 13, lesson 2), titles and labels

Read `00-module.md` (the shared fact sheet) first; it applies here. The labels sit above the
lesson's sections and figures and in its challenge. They may use CPU and join. Only the keys marked
may use machine code; none may use abstraction. A heading names what its section contains, in a
few words, with no full stop. An objective starts with a verb, is plain text with no backticks, and
ends with a full stop. A caption is one sentence describing the figure, ending with a full stop.

Keys to write, each one line:

- `title`: the lesson's question: can you watch one line of a program at every level, edge by
  edge? (It may not use machine code.)
- `objectives.1` to `objectives.4`: work out an instruction's machine code from its line (may use
  the term); say at which edge each stage of an instruction happens: fetch, register read, ALU,
  memory, register write and PC update; read one instruction at every level of the run at one
  edge; explain why the levels agree, and what the comparison with the model shows when the
  machine goes wrong.
- `titles.question`: the final demonstration. `titles.motivation`: from a line to the gates.
  `titles.prediction`: the word a set if becomes. `titles.investigation`: a system call at every
  level. `titles.construction`: one store, worked out. `titles.failureExperiment`: a broken
  signal. `titles.explanation`: one circuit, many levels. `titles.generalisation`: every program
  as machine code (may use the term). `titles.challenge`: one line, every level.
  `titles.reflection`: a value of your own.
- `challengeTitles.c1`: one line, every level.
- `captions.whole`: the whole machine running the shop's program, with the instruction at every
  level.
- `captions.predict`: the shop's program stopped before the FETCH edge of a set if, with a question
  about the IR.
- `captions.call`: the shop's program stopped before its system call, with the control registers.
- `captions.store`: the shop's program stopped before a store to the lamps.
- `captions.faults`: the shop's program with one control signal broken, which you choose.
- `captions.answers`: five questions about one line at every level.
- `faults.bconst`: BCONST held at 1. `faults.set`: SET held at 0.
- `fields.code`: the word of `R5 <= R3 < R4 signed` (may not use machine code; may use backticks).
  `fields.edges`: the edges `R2 <= R3` takes. `fields.job`: the ALU's job at its ALU edge.
  `fields.yin`: the word register Y takes at its WRITE edge. `fields.pc`: the PC after its last
  edge.
- `jobs.add`, `jobs.subtract`, `jobs.copy`, `jobs.or`: the choice's options: add; subtract; copy
  B; OR.
