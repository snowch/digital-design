# Brief 4L: lesson `final-machine`, titles, labels and names

Read `00-module.md` (the shared fact sheet) and `4-shared.md` first. The labels may use CPU,
machine code, abstraction, join and trace. A heading names what its section contains, in a few
words, with no full stop. An objective starts with a verb, is plain text with no backticks, and
ends with a full stop. A caption is one sentence describing the figure, ending with a full stop.
A name of a text or a program is a short noun phrase with a capital first letter and no full stop.

## Labels (each one line)

- `title`: the lesson's question: can you join the parts into the whole machine?
- `objectives.1` to `objectives.4`: write the top module that joins the course's parts into the
  whole machine; run programs on it against the model after every instruction; read a failed
  comparison to find the join it points at; say why a test finds a wrong join only where its
  program reaches it.
- `titles.question`: the whole machine as text. `titles.motivation`: the parts and the joins.
  `titles.prediction`: a timer that counts a trap. `titles.investigation`: which program finds
  which line. `titles.construction`: three ways in. `titles.failureExperiment`: a door that never
  opens. `titles.explanation`: reading a failure. `titles.generalisation`: how a CPU is checked.
  `titles.challenge`: the whole machine. `titles.reflection`: a program of your own.
- `challengeTitles.c1`: the whole machine.
- `captions.course`: the course's text of the whole machine, run on five programs against the
  model.
- `captions.predict`: a text whose timer counts a trap's edge, run on two programs.
- `captions.lines`: three texts, each with one line wrong, run on five programs.
- `captions.door`: a text whose memory never sees the door, run on five programs.
- `captions.lab`: the challenge: your text of the whole machine.
- `texts.course`: the course's own text. Use exactly: "The course's text".
- `texts.tick`, `texts.branch`, `texts.ie`, `texts.call`, `texts.door`: use exactly the names
  `4-shared.md` gives: "The timer counts a trap's edge", "Every branch taken", "Interrupts on in
  system mode", "A call keeps the PC", "DOOR held at 0".
- `programs.shop`, `programs.user`, `programs.timer`, `programs.door`, `programs.rom`: use exactly
  the names `4-shared.md` gives.
- `options.shop`: only the shop's program. `options.timer`: only the timer program.
  `options.both`: both. `options.none`: neither.
