# Brief 2C: lesson `full-path` (Module 13, lesson 2), third part

Read `00-module.md` (the shared fact sheet) first; it applies here, with brief 2A's description of
the figure. You may use CPU, **join** and **machine code** (not bold here). Do not use abstraction.

Keys to write: `explanation`, `generalisation`, `answersLead`, `c1Task`, `c1Hints.1` to
`c1Hints.5`, `reflection`, `modelVsReality`.

## explanation (about 190 words)

1. The levels agree because they are one machine. The line is the only level outside the circuit:
   the assembler turned it into machine code before the run began.
2. From the word down, every level reads the same nets of the same circuit at the same edge. The
   table's fields are the IR's bits read in groups of four. The control signals are the decoder's
   outputs. The values on the drawing, at every level you open, are the circuit's own.
3. So a level cannot show a different value from the one below it. A level can only leave things
   out: the table shows six signals of the decoder's many; the top of the drawing shows three
   blocks, not their gates.
4. When the machine goes wrong, the levels still agree with each other. What disagrees is the
   machine and the model. The comparison names the first instruction where they part, and the
   levels show where: with BCONST held at 1, the word said R2, the signal said the constant, and
   the ALU did what the signal said.

## generalisation (about 110 words)

1. Every program reaches a machine as machine code. Whatever language it was written in, the
   machine runs words like `A7345000`.
2. Each stage of the demonstration is a state of the controller, or the decoder's gates between
   two edges: fetch, decode, register read, ALU, memory, register write, PC update.
3. Inspectable at every step means more than seeing the registers: any wire, at any edge, at any
   level. That is what the drawing gives you.
4. The next lesson uses this to follow one value of your own choosing down to a single gate.

## c1Task (about 110 words; a numbered list)

1. Work out, without running anything: the machine code of `R5 <= R3 < R4 signed`, as eight
   hexadecimal digits. (It is not a line of the shop's program. Set if's job 6 is less, read
   signed.)
2. Use any figure on this page for the line `R2 <= R3`, at `038`:
   - how many edges it takes, from its FETCH edge to its last;
   - the ALU's job at its ALU edge, by OP2 OP1 OP0: add, subtract, copy B or OR;
   - the word register Y takes at its WRITE edge, as a decimal number;
   - the PC after its last edge, as three hexadecimal digits.
3. There are 5 tests, one for each answer.

## c1Hints (five, in this order)

1. The idea: a word's eight digits are its fields in order, K J A B Y and three digits of constant.
   The rest of the answers are on the table "The instruction at every level" at the right edges.
2. A common mistake: reading the table one edge early. The row of control signals shows the signals
   at the next edge, the one the state names.
3. A smaller example: `R4 <= 100` is `25004064`: kind 2, job 5, A 0, B 0, Y 4, constant `064`.
4. Part of the answer: set if is kind A, and `R2 <= R3` is a register job, kind 1 job 5, so it
   takes a register job's states.
5. The whole answer: `A6345000`; 4 edges; copy B; 66; `03C`.

## reflection (about 70 words)

1. You have watched one line at every level at once, and seen why the levels agree: they are one
   circuit.
2. The figures chose what to show: a table of six signals, a drawing opened where you pressed.
3. End with the next lesson's question: can you follow one value of your own choosing, at an edge
   of your own choosing, from a line of the program down to one gate?

## modelVsReality (about 70 words)

1. This machine's memory answers within one edge. A real machine's memory is far slower than its
   CPU.
2. So a real machine keeps copies of the words it used recently in small, fast memories beside the
   CPU, and goes to the main memory only when a copy is missing.
3. Nothing of this is taught here. It is named so you know where this machine stops being like a
   real one.
