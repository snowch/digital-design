# Brief 5B: lesson `capstone` (Module 13, lesson 5), second part

Read `00-module.md` and `5-shared.md` first; both apply. You may use CPU, machine code,
abstraction, join and trace. It is the course's last lesson.

Keys to write: `investigation`, `invLead`, `invAfter`, `construction`, `failureExperiment`,
`failLead`, `failAfter`.

## investigation (about 70 words, above the figure)

1. Same figure, paused before edge 13, the ALU edge of `R3 <= R2 < R1 signed`.
2. Find COUT, the ALU's carry out, at this edge, and compare it with MET.
3. Predict first: does a subtraction whose answer is less than 0 give a carry out of 1 or of 0?

## invLead (one sentence)

Open the datapath and read COUT and Y where they leave the ALU, then MET where it leaves the
condition block.

## invAfter (about 110 words, below the figure)

1. COUT is 0. Y is -66, and MET is 1.
2. Read as unsigned numbers, R2's word is smaller than R1's, so the subtraction borrows; a
   subtraction that borrows gives a carry out of 0.
3. So COUT does not answer "is R2 less than R1, read signed". MET does: the condition block works
   it out from the flags and the job digit.
4. A question about one wire is answered by reading that wire, at that edge. A neighbouring wire,
   or the same wire at another edge, can hold a different value.

## construction (about 200 words; a short list allowed)

How you answer the challenge.

1. Write the program in the editor. It assembles as you type; a line it cannot read is named.
2. The program must do the task (from `5-shared.md`), and use at least one set if.
3. Press "Run my program on the whole machine". The trace figure of lesson 3 opens on your
   program, with room A at -184 and room B at -250. Every question is about this run.
4. Each question names an instruction of your program and an edge of it: "paused before the ALU
   edge of your first set if". Use "Pause before an edge" to choose your first set if and its ALU
   edge, or your first store and its MEMORY edge.
5. Open the blocks to the wire the question names, and read its value. For the PC's bit 4, show
   the PC's bit from "Parts here that never open" and read D.
6. If you change the program, run it again: the answers belong to the run of the program you
   graded.

## failureExperiment (about 60 words, above the figure)

1. The figure's machine holds MET at 0, as if the condition block's output were joined to 0.
2. The comparison with the model runs beside it.
3. Run it, read the first difference, and trace it back to the wire.

## failLead (one sentence)

Choose the fault, run to the end, and read the comparison.

## failAfter (about 100 words, below the figure)

1. The comparison: "After `R3 <= R2 < R1 signed` at `008`, R3 is 0 on the machine and 1 by the
   model."
2. Trace back: R3 takes the word for Y at the WRITE edge. For a set if, that word is MET as a word.
   MET is 0 where it leaves the condition block, though the flags say the condition holds.
3. The comparison named a register and a line. The trace found the wire.
