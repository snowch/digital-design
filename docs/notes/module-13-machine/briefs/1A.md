# Brief 1A: lesson `whole-machine` (Module 13, lesson 1), first part

Read `00-module.md` (the shared fact sheet) first; it applies here. This lesson introduces
**CPU** (in brief 1C, not here): do not use it in these keys. Do not use "machine code" or
"abstraction". You may use trap, handler, user mode, system mode, system call and interrupt (never
bold them).

Keys to write: `question`, `makersLead`, `makersAfter`, `motivation`, `prediction`, `p1Question`,
`p1Explain`.

## question (about 140 words, above a figure)

1. Module 12 ended on a question, which you quote: "Every part was built, but in separate lessons,
   on separate drawings. Can you follow one of the shop's programs through the handler and down to
   the gates of the one machine that runs it?"
2. Module 0 asked the same from the top: the machine was a box that ran lines. Its second lesson
   followed one line down to one wire, on a path chosen for you.
3. This module answers the question with the machine whose every part you have now built. This
   lesson asks which parts make the whole machine, and where they meet.
4. The figure is the whole machine, running the shop's last program (the fact sheet gives it). It
   is Module 0's first program, written for this machine.

## makersLead (one or two sentences, above the figure)

Open each of the three blocks in turn by pressing it. The table under the drawing names each part
at the level on show and the module that built it.

## makersAfter (about 90 words, below the figure)

What the table shows, from the figure:

- At the top level the drawing has three blocks: the control unit (`control`), built in Module 9
  and grown in Modules 10 and 12; the datapath (`datapath`), built in Module 8 and grown in Modules
  9, 10 and 12; and the memory port (`port`), built in Module 9 and grown in Module 12.
- Inside the datapath: the register file (Module 6), the ALU (Module 7), the PC (Module 5), the IR
  (Module 9), the control registers (Module 12).
- Inside the control unit: the decoder (Module 9, grown in Module 10), the controller (Module 9,
  grown in Module 12), the trap logic (Module 12).
- Inside the memory port: the memory (Module 6, grown in Modules 8, 9 and 12).

## motivation (about 240 words; a short list allowed)

1. This is the course's final machine: Module 12's machine of several edges, with its trap
   hardware, and the two instructions you added in your own copy: the call through a register
   (Module 9) and set if (Module 10).
2. What that took: the decoder Module 10's capstone built, which knows kind 9 and kind A; and a
   fourth source for the word register Y takes, MET as a word, 0 or 1, chosen by SET.
3. The machine is built from the course's parts. Each passes the tests your own part passed in its
   lesson. It does not run your own earlier answers: each lesson keeps its own work.
4. A part's tests checked it alone. The machine also needs its parts joined. Name this: a **join**
   is a bus or a wire between two blocks, where one block's output becomes another's input. (Set
   "join" in bold; it is not a rationed term.)
5. Three joins as examples, no more (the challenge asks about others): the control unit sends the
   control bus, CONTROL, every control signal joined into one bus, to the datapath and to the memory
   port; the datapath sends the instruction in the IR back to the control unit, which decodes it;
   the memory port sends FETCHED, the word at the PC, to the datapath, where the IR takes it at a
   FETCH edge.
6. Each wire is driven by one block: its name is on that block's right side, where its outputs
   are, and on the left side of each block it enters.
7. An instruction's words cross these joins edge by edge. The rest of this lesson follows them.

## prediction (about 60 words, above the figure)

1. The figure is the shop's program, stopped after 47 edges. The next edge is the WRITE edge of
   `call R6, R15`, at `02C`: the call through a register, kind 9.
2. The figure shows R6 and R15. No value shows until you commit.
3. Choose an answer and press "Check my prediction".

## p1Question (one sentence)

What does the PC hold after the next edge?

## p1Explain (about 80 words)

1. The PC takes `034`, the address of the line `show:`. A call through a register sends the PC to
   R6 plus the constant, and the constant is 0. R6 holds 52, which is `034`.
2. At the same edge R15 takes `030`, the PC plus 4: the line after the call, `stop`, where
   `goto R15` will return.
3. `02C` is the call itself, and `000` is where the run began.
4. Press "Next edge" and read the line under the buttons.
