# Brief V1: Module 13's figure words (the whole machine, run edge by edge)

Read `00-module.md` (the shared fact sheet) first; it applies here, with one change: these words
appear on every Module 13 page, so use none of Module 13's own terms (CPU, machine code,
abstraction). Each key is a short label or one sentence. A label has no full stop; a sentence has
one. Placeholders in braces, such as `{address}`, stay exactly as given: the page puts a value
there. A line of the program arrives in `{line}` and must stay in backticks: write `` `{line}` ``.

Some keys are fixed because the lessons' text names them. Give these exactly as written:
`nextEdge`: Next edge. `backEdge`: Step back. `toEnd`: Run to the end. `reset`: Start again.

## The line under the buttons

- `atStart`: before the first edge, after the reset: the next edge fetches `{line}`, at
  `{address}`.
- `atEdge`: after edge `{n}`: say that edge `{n}` has run, then that the next edge is the
  `{state}` edge of `{line}`, at `{address}`. `{state}` is FETCH, READ, ALU, MEMORY or WRITE.
- `stopped`: the run stopped at `{address}`, at `stop`.
- `halted`: the machine halted at `{address}` with cause `{cause}`.
- `cutOff`: the run was cut off after `{n}` edges.
- `trapsNext`: added after `atEdge` when the next edge traps: the next edge traps, with cause
  `{cause}`.

## The table "the instruction at every level"

A table of two columns: the level, and what it shows at this edge.

- `levelsCaption`: the table's title: the instruction at every level.
- `level`, `shows`: the two column headings: level; what it shows.
- `line`: the row for the line of the program the edge belongs to.
- `address`: the row for that line's address.
- `machineCode`: the row for the instruction's word as the assembler made it, in the ROM. Write it
  as "Its word in the ROM". (Lesson 2 names this word; this label must not use the term.)
- `inIr`: the row for the word in the instruction register now: the word in the IR.
- `fields`: what follows the IR's word in that row: its fields, each digit named, in this form:
  `K {k}, J {j}, A {a}, B {b}, Y {y}, constant {c}`. Keep the letters K, J, A, B, Y and the word
  "constant" as given.
- `state`: the row for the controller's state: the state the next edge is made in.
- `signal`: the row for a control signal, by its name: `{name}` alone.
- `noLine`: what the line row shows for an address with no line of the program: no line.

## The table "the parts at this level"

- `makersCaption`: the table's title: the parts at this level, and the module that built each.
  The page adds a colon and the block on show after it.
- `whole`: the block on show when nothing is opened: the whole machine.
- `part`, `builtIn`: the two column headings: part; built in.
- `builtModule`: Module `{n}`.
- `builtGrown`: Module `{n}`, grown in `{list}`. (`{list}` is a list of module numbers such as
  "9, 10 and 12".)
- `and`: the word before the last number of `{list}`: and.

## The comparison with the model

Each figure that has it says, under the drawing, whether the circuit and the model agree.

- `agrees`: the circuit and the model agree after every instruction and every trap so far: `{n}`
  of them.
- `agreesNone`: before the first instruction has ended: no instruction has ended yet.
- `differs`: after `{line}` at `{address}`, `{what}` is `{machine}` on the machine and `{model}`
  by the model. (`{what}` is a register's name such as R1 or C2, or one of the `what` keys below.)
- `haltsAlone`: at `{line}` at `{address}`, the machine halts with cause `{cause}`; the model does
  not.
- `stopsAlone`: at `{line}` at `{address}`, the model stops; the machine does not.
- `unknown`: a value with an unknown bit: unknown.
- `what.PC`, `what.display`, `what.lamps`, `what.timer`, `what.waiting`: the names the sentence
  uses: the PC; the display; the lamps; the timer; "waiting".
