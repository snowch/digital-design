# Brief 1D: lesson `whole-machine`, the challenge's sentences for a wrong answer

Read `00-module.md` (the shared fact sheet) first; it applies here. You may use **join** (a bus or
a wire between two blocks; not bold). Do not use CPU, machine code or abstraction.

Each key is one or two sentences shown when the learner's answer to one field is wrong. `{actual}`
stands for the learner's answer and must appear once, as given. Say which rule or fact the wrong
answer misses. Never give the right block or the right number.

- `joinHb`: the block that drives HB. Rule: a bus is driven by the block whose right side it
  leaves, where that block's outputs are; it enters the blocks that read it on their left.
- `joinWaiting`: the block that drives WAITING. Same rule.
- `joinStatus`: the block that drives STATUS. Same rule.
- `joinCausem`: the block that drives CAUSEM. Same rule.
- `joinIrEdge`: the edge at which the IR takes `resume`'s word. Facts: edges are counted from the
  reset; the IR takes an instruction's word at its FETCH edge; read the S lane of the timing
  diagram.
- `joinPcEdge`: the edge at which the PC takes the return point, `040`. Facts: `resume` takes
  three edges, FETCH, READ and WRITE; the PC takes its next value at the edge that ends the
  instruction; read the PC lane.
