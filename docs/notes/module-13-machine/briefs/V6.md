# Brief V6: plain titles for the final machine's blocks

Read `00-module.md` first. The drawing writes each block's kind above it. For these kinds it
writes the code's name today (`control-decoder-set`, `system-jobs-12`). Give each a plain title:
one to three words, lower case unless a name needs capitals, no full stop, no longer than about
20 characters, since it sits above a box on a drawing. Use the names the pages use: the decoder,
the controller, the trap logic, the control registers, the system jobs, the IR, C0, C4, MET, Y.
Where the same kind of block also appears in Module 12's machine, the same title serves both.

- `digits`: splits the IR's word into its fields: K, J, A, B, Y and the constant.
- `mode-bits`: takes C0's two bits apart: user mode, and interrupts on.
- `control-signals-set`: the decoder's control signals, SET among them.
- `kind-check-set`: checks the kind digit: which kinds are instructions, 9 and A among them.
- `job-check-set`: checks the job digit for each kind.
- `decode-checks-set`: the decoder's checks: whether the word is an instruction (cause `21`).
- `control-decoder-set`: the decoder, which knows set if and the call through a register.
- `system-jobs-12`: the system jobs: `resume`, the control-register jobs, `stop`, and user
  mode's refusal of them.
- `state-register-traps`: the controller's state register.
- `controller-next-traps`: works out the controller's next state.
- `controller-outputs-traps`: works out the controller's outputs, the enables.
- `controller-traps`: the controller.
- `trap-logic`: the trap logic.
- `join-control-final`: joins the control signals into one bus, the control bus.
- `widen`: makes the 12-bit constant a 64-bit word, keeping its sign.
- `control-number`: picks the control register a job names.
- `no-handler`: says whether C4 is 0, that is, no handler is set.
- `control-registers`: the control registers, C0 to C4.
- `condition`: the branch condition, MET.
- `yWord-final`: chooses the word register Y takes.
- `next-trap`: chooses the next PC: the handler's address at a trap, the return point at `resume`,
  or the next PC worked out before.
- `count-down`: the timer's count down.
- `memory`: the memory: the ROM, the RAM and the devices.

Write each as `title.<kind>: <title>`.
