# Brief R2-8: labels that no longer match their sections, after the second read

Read `docs/style.md`. Each key is a label: one line, no full stop. A heading's test is whether
somebody scanning the page can tell what the section holds. An objective starts with a verb.

- `whole-machine` `objectives.4`: explain why a join can break the whole machine although every
  part works alone. (Do not say the parts pass tests: the course's parts are not the learner's.)
- `tracing` `titles.motivation`: the section names the four tools the figure gives for a trace (the
  run strip, a pinned wire, the table of levels opened, the list of parts that never open).
- `capstone` `objectives.4`: say at which level each question's wire is drawn, and where a held
  word's value comes from.
- `capstone` `titles.explanation`: the section says the five wires sit at different depths: three
  at the datapath level, one gate four blocks below it, and one held word whose value came from an
  earlier instruction.
- `capstone` `titles.generalisation`: the section says designers trace a failed test on their own
  design the same way, reading one wire at one edge from a simulator's record of every wire.
