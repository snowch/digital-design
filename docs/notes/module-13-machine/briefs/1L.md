# Brief 1L: lesson `whole-machine` (Module 13, lesson 1), titles and labels

Read `00-module.md` (the shared fact sheet) first; it applies here. The labels sit above the
lesson's sections and figures and in its challenge, so no key may use CPU, machine code or
abstraction. A heading names what its section contains, in a few words, with no full stop. An
objective starts with a verb, is plain text with no backticks, and ends with a full stop. A caption
is one sentence describing the figure, ending with a full stop.

Keys to write, each one line:

- `title`: the lesson's question: which parts make the whole machine, and where do they meet?
- `objectives.1` to `objectives.4`: name the three blocks of the whole machine and the module that
  built each part; say what a join is and find the block that drives a bus; follow a load's words
  across the joins, edge by edge; explain why a join can break a machine whose parts each pass
  their tests.
- `titles.question`: the whole machine. `titles.motivation`: parts and joins.
  `titles.prediction`: where a call through a register goes. `titles.investigation`: a system
  call across the joins. `titles.construction`: one load, five joins. `titles.failureExperiment`:
  a broken join. `titles.explanation`: the CPU and the memory. (This heading may use CPU: the
  explanation introduces it.) `titles.generalisation`: testing the joins. `titles.challenge`:
  where the parts meet. `titles.reflection`: every level at once.
- `challengeTitles.c1`: where the parts meet.
- `captions.makers`: the whole machine running the shop's program, with a table of each part's
  module.
- `captions.predict`: the shop's program stopped before the WRITE edge of a call through a
  register, with a question about the PC.
- `captions.timeline`: a timing diagram of signals crossing joins, from edge 57 to edge 68.
- `captions.load`: the shop's program stopped before a load, with the signals of its edges.
- `captions.answers`: six questions about the joins and the edges.
- `captions.faults`: the shop's program with one join held at a fixed value, which you choose.
- `faults.mq`: MQ held at 0. `faults.noHandler`: NOHANDLER held at 1. `faults.cause`: CAUSE held
  at `00`.
- `fields.fetched` ... the challenge's fields, in order: `fields.hb`: the block that drives HB;
  `fields.waiting`: the block that drives WAITING; `fields.status`: the block that drives STATUS;
  `fields.causem`: the block that drives CAUSEM; `fields.irEdge`: the edge at which the IR takes
  resume's word; `fields.pcEdge`: the edge at which the PC takes 040.
- `blocks.control`, `blocks.datapath`, `blocks.port`: the three options of a block field: the
  control unit; the datapath; the memory port.
