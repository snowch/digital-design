A bus or a wire between two blocks, where one block's output becomes another's input, is called a **join**.

The three blocks pass values to each other across joins. Three examples follow. The control unit sends CONTROL to the datapath and the memory port. CONTROL is the control bus: every control signal bundled into one bus. The datapath sends the instruction in the IR to the control unit, which decodes it. The memory port sends FETCHED, the word at the address ADDR names, to the datapath. At a FETCH edge ADDR carries the PC, and the IR takes FETCHED.

A wire's name is written on the right side of the block that drives it, where its outputs are, and on the left side of each block it enters. Two kinds of exception apply. HB, the word a store writes, enters the memory port under another name, D. CLK, RST, DOOR, WARM, SENSORA and SENSORB are the machine's own inputs, and no block drives them. Only CLK and RST are drawn at the machine's left side. DOOR, WARM, SENSORA and SENSORB come in just left of the memory port, the block that reads them.

An instruction's words cross these joins edge by edge. The rest of this lesson follows them.

explanation: The whole machine is its parts and the joins between them. One block drives each join, and another block reads it.

The control unit decides what each edge does. It decodes the instruction in the IR, steps the controller through its states, and sends every control signal on the control bus. The datapath holds the registers, the PC, the IR and the control registers, and does the arithmetic. The memory port holds the ROM, the RAM and the devices, each at its own range of addresses in one map.

Together, the control unit and the datapath work out and run each instruction. That part of the machine is the **CPU**, the central processing unit. The memory port, and everything behind it, sits outside the CPU.

A trap is the whole machine at work. The control unit sees the cause and sends TRAP. At the edge that traps, the datapath's control registers and its PC take their words, and the controller goes to FETCH.

generalisation: A join is tested only by running whole programs, compared with the model after every instruction. The comparison names the first instruction that disagrees: start looking at the joins and the parts that instruction uses.

The CPU and the memory are separate blocks joined by buses. Here there are eight: CONTROL, ADDR and HB go out to the memory port; FETCHED, MQ, CAUSEF, CAUSEM and WAITING come back. Machines far larger keep the same split.
