motivation: The course's final machine is Module 12's machine of several edges, with its trap hardware. It also has the two instructions you added in your own copy: the call through a register, from Module 9, and set if, from Module 10.

Two things were needed. The decoder that Module 10's capstone built knows both new kinds, kind 9 and kind A. The datapath also has a fifth source for the word register Y takes, after HR, HM, PC + 4 and CWORD: MET as a word, 0 or 1, chosen by SET.

The machine is built from the course's own versions of the parts you designed, often wider. Its register file has sixteen registers of 64 bits, where Module 6's had four words of 4 bits. It does not run your own earlier answers: each lesson keeps its own work.

Each part was tested alone. The machine also needs its parts joined. A bus or a wire between two blocks, where one block's output becomes another's input, is called a **join**.

Three joins are examples. The control unit sends CONTROL to the datapath and the memory port. CONTROL is the control bus: every control signal bundled into one bus. The datapath sends the instruction in the IR to the control unit, which decodes it. The memory port sends FETCHED, the word at the address ADDR names, to the datapath. At a FETCH edge ADDR carries the PC, and the IR takes FETCHED.

A wire's name is written on the right side of the block that drives it, where its outputs are, and on the left side of each block it enters. Two kinds of exception apply. HB, the word a store writes, enters the memory port under another name, D. CLK, RST, DOOR, WARM, SENSORA and SENSORB are the machine's own inputs. They are drawn at its left edge, and no block drives them.

An instruction's words cross these joins edge by edge. The rest of this lesson follows them.

generalisation: Every machine is built this way: parts, each tested alone, then joined. A part's tests cannot test its joins.

The joins are tested by running whole programs, compared with the model after every instruction. The comparison names the first instruction that disagrees: start looking at the joins and the parts that instruction uses.

The CPU and the memory are separate blocks joined by buses. Here there are eight: CONTROL, ADDR and HB go out to the memory port; FETCHED, MQ, CAUSEF, CAUSEM and WAITING come back. Machines far larger keep the same split.
