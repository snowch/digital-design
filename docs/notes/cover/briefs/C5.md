## Why

has a badge naming how it counts time. Press it to read how." Module 0 now comes first, and its
figures run the course's simulator with no badge. So the first sentence is no longer true.

## Facts

2. Pressing the badge shows a note on how that figure counts time.
3. Module 0's figures run the course's simulator but carry no badge: there a press runs a whole
   line of a program, and the circuit's timing is not shown.
4. The reader of this page knows binary numbers and everyday arithmetic, and nothing about
   electronics. "Simulator", "figure" and "badge" are used on this page already. Do not use
   "clock", "edge" or "gate" outside the badge names in quotation marks.

## Voice

British English. Direct, plain, active, short. The reader is "you". No em dashes. "Press", never
"click" or "tap".

Rewrite the first sentence so it carries facts 1 and 3 in as few words as it can; keep the second
sentence, "Press it to read how.", unless fact 2 needs other words after your first sentence.
Return the sentence or sentences alone, and nothing else.
