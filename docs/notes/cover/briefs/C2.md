# Brief C2: the summary under a module's name on the front page

Sent to the drafting subagent with `docs/style.md`, on 6 October 2026, when the author asked for
the front page's modules to be collapsed by default because the page had grown long.

## Facts

- The front page lists the course's modules, Module 0 to Module 13. Each module that has lessons
  now shows as one line by default: the module's number and name, and under it a short summary.
  Pressing that line shows the module's lessons; pressing it again hides them.
- The summary says two things: how many lessons the module has, and how many of the module's
  challenges the learner has completed, out of how many there are.
- The page already shows, for each single lesson, "{passed} of {total} challenges complete". The
  summary uses the same words for the challenges, so the two read alike.
- Three cases: a module with several lessons and some challenges (5 lessons, 3 of 12 complete);
  a module with 1 lesson (0 of 2 complete); a module whose lessons have no challenges (3 lessons).
- The front page is read before any lesson, so it uses no term a lesson teaches.

- a: 5 lessons, 3 of 12 challenges complete
- b: 1 lesson, 0 of 2 challenges complete
- c: 3 lessons

Checked: every fact kept, none added; the challenge wording matches the lesson line's. Placed as
