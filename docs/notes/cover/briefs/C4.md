# Brief C4: where Module 0 sits on the cover's path, and the preface's "first lesson"

You are drafting words for the cover at the top of the front page of an interactive course,
*Digital Design: From Bits to a Working Computer*, and one sentence of its page "Before you start".
Read `docs/style.md` in the repository before you write: it is the style checklist, and it applies
to every sentence. Use only the facts here. Where a sentence seems to need a fact you were not
given, write a note in square brackets instead of inventing it. Do not write or change any file.

## Why

Module 0 now comes before Module 1. The cover's button says "Start with Module 0" and names its
first lesson, "What does a computer do?". Below it, the path under the heading "Signals to computer
in five stages" starts at Module 1, so a newcomer cannot see where Module 0 sits. And the page
"Before you start" says the course uses binary "from its first lesson", which was true when
Module 1 came first and is not now.

## Voice

British English. Direct, plain, active, short. The reader is "you". No marketing tone, no
exclamation marks, no rhetorical questions, no filler, no em dashes or en dashes used as dashes.
Numbers as digits.

## Words the cover must not use

A reader meets the cover before every lesson, so item 1 must not use a term a lesson introduces,
nor its plurals or other forms: bit, binary, word, hexadecimal, signed, unsigned, gate, truth
table, Boolean expression, XOR, XNOR, NAND, universal, threshold, noise margin, one-hot, carry,
half adder, full adder, overflow, multiplexer, bus, decoder, demultiplexer, encoder, comparator,
depth, feedback, latch, transparent, edge, synchronous, register, shift register, register
transfer, register file, counter, state machine, state diagram, next-state logic, address, RAM,
ROM, byte, aligned, alignment, memory-mapped, ALU, flag, instruction, instruction set, encoding,
immediate, opcode, program counter, fetch, datapath, branch, control unit, illegal instruction,
instruction register, micro-operation, SystemVerilog. "Program", "line", "machine" and "wire" are
free to use.

## 1. `journeyIntro`: one line under the heading, above the five stages

Facts:

1. It sits directly under the heading "Signals to computer in five stages" and above the list of
   stages, whose first is "Signals, Modules 1 to 3".
2. Module 0 comes before the five stages. It is where the button above starts you.
3. Module 0 has 2 lessons. In the first you run a finished machine: a shop's program, one line at a
   time. In the second you open that machine level by level, down to one wire.
4. In Module 0 you build no part of the machine. The five stages build it, starting from that one
   wire in Module 1.

Write one or two short sentences that carry facts 2 to 4. It is a line between a heading and a
list, so keep it short.

## 2. `preface.need`, its second sentence only

The page "Before you start" says, today: "You need to know how to turn a binary number into
decimal, and a decimal number into binary. The course uses both from its first lesson and does not
teach them. You need everyday arithmetic. ..."

Facts:

5. Module 0's first lesson uses decimal numbers only. Its second lesson reads numbers in 1s and 0s
   (66 is `0100 0010`), so the course uses both conversions from Module 0, its first module.
6. The course does not teach the conversions.

Rewrite the second sentence alone ("The course uses both ... does not teach them."), carrying facts
5 and 6 in no more words than it has now. This page may use "binary", as it does today.

Return two lines: `journeyIntro:` then the line; `need, second sentence:` then the sentence.
