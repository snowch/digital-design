# Brief C6: Module 0's line on the path, and the line above the path

You are drafting words for the front page of an interactive course, *Digital Design: From Bits to
a Working Computer*. Read `docs/style.md` in the repository before you write: it is the style
checklist, and it applies to every sentence. Use only the facts here. Where a sentence seems to
need a fact you were not given, write a note in square brackets instead of inventing it. Do not
write or change any file.

## Why

On 10 October the author asked for the modules to sit inside the five stages of the path, each
stage one line until it is pressed. Module 0 comes before the stages, and it now gets a line of
the same form as a stage's. A stage's line shows its name, the modules it holds, how many of their
challenges are complete, and under them one line on what you do in that stage. Module 0's line
needs that last line too. The line above the path says what Module 0's line will now say, so it
must be cut down, or the page says the same thing twice, one line apart.

## Voice

British English. Direct, plain, active, short. The reader is "you". No marketing tone, no
exclamation marks, no rhetorical questions, no filler, no em dashes or en dashes used as dashes.
Numbers as digits.

## Words the front page must not use

A reader meets the front page before every lesson, so neither item may use a term a lesson
introduces, nor its plurals or other forms: bit, binary, word, hexadecimal, signed, unsigned, gate,
truth table, Boolean expression, XOR, XNOR, NAND, universal, threshold, noise margin, one-hot,
carry, half adder, full adder, overflow, multiplexer, bus, decoder, demultiplexer, encoder,
comparator, depth, feedback, latch, transparent, edge, synchronous, register, shift register,
register transfer, register file, counter, state machine, state diagram, next-state logic, address,
RAM, ROM, byte, aligned, alignment, memory-mapped, ALU, flag, instruction, instruction set,
encoding, immediate, opcode, program counter, fetch, datapath, branch, control unit, illegal
instruction, instruction register, micro-operation, SystemVerilog. "Program", "line", "machine" and
"wire" are free to use.
